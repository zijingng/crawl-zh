# 怪物对白动态参数补齐

补齐 `@foe_god@`、`@Foe_god@`、`@at_foe/around@` 的中文显示，适用于所有走怪物对白参数替换流程的已审 TextDB 条目，不为单条对白硬编码。

- 神祇参数：有名神祇使用现有神名词典；无信仰时按英文规则显示“你”；无名神祇显示“你的神”。大小写形式共用中文结果。
- 目标替代参数：敌人是玩家时采用“周围”；敌人是怪物时采用现有怪物显示名。这个选择与英文 `_replace_speech_tag` 的分支一致。
- 无敌人、名称不可用或参数无法完整处理时保留整句英文。英文替换流程和随机选择顺序不变。

只增加一个独立语法词条“你的神”，数据库正文仍只维护于 textdb.po。没有增加中文 Lua、数据库正文副本或运行时审核信息。

对 mon-util.cc 的审核依赖仅刷新与修改前文件摘要完全匹配的记录，未刷新原本已失效的记录。既有正文译文和英文数据库不变。

测试覆盖玩家信仰有名神、无神、无名神，玩家／怪物目标替代及无目标回退；比较英文原结果、语言切换和随机状态。验证：Tiles crawl.exe 编译成功，32 项 Python 测试通过，161 项原生本地化测试通过，共 1,200,183 次断言。新增分支测试共 46 次断言通过；差异空白检查通过。首次完整测试发生崩溃，补齐测试的怪物槽完整保存／恢复和界面状态隔离后重跑全部通过。未进行 GUI 目视测试。
