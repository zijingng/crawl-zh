# r 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

审查范围为核心源码顶层全部 18 个 r 开头 `.cc` / `.h` 文件，修改其中 3 个有显示适配需要的文件；另在 `spl-book.cc` 接入 r 文件返回的神祇警告。接入、复核 268 条译文。译文清单为 `localization/manifests/source-r-01.json`，逐文件范围、译前术语命中和验收结果分别见 `source-r-01-files.json`、`source-r-01-preflight.json`、`source-r-01-checks.json`。

## 神祇能力、恩赐与信仰

补齐全部神祇能力获得、失去和金币足够时解锁的提示。能力表的 `gain`、`loss`、`general` 原文不变；新增 `god_power::display_text()` 只负责显示，完整句子与“你现在可以……”等外层模板分别校验。复用已经审核的神祇能力说明译文；必要组件缺译时，恢复上游完整英文句子。

覆盖神罚平息、光环与抗性变化、水上行走结束条件、神赐物品与卡牌、维胡梅特的法术恩赐、先祖记忆、属性支持、背教与改信、信仰护身符相关反馈、入教费用和拒绝入教等提示。

维胡梅特的法术列表从原有 `offers` 集合取得法术名；永久可用附注与列表共同回退，不重抽法术或重新发放恩赐。先祖的装备记忆使用原有物品类型和印记，不伪造带强化值的物品。先祖通知沿用原文强制显示已知姓名的边界，使用名称快照，离开视野时也保留已知的先祖身份。

祈祷动作从原有形态／种族接口取得规范动词，中文使用独立表达；原英文的祭坛名、动作与冠词组合保留。神祇选择界面继续接受英文规范名，中文提示明确注明“输入英文名”，默认神祇名称缺译时整条提示回退英文。

`god_spell_warn_string()` 继续返回英文规范警告。在它的实际显示位置 `spl-book.cc`，将法术名、法术容量数值和警告作为同一条确认提示处理；任何一项缺译均回退完整英文。非交互警告独立翻译，不改变记忆法术的判定和代价。

## 远程战斗

补齐胶怪吞吃飞射物、空间失锚、抵抗与不受影响等消息；复用已有的命中、未命中、飞射物与伤害印记显示接口。反射攻击按“具名盾牌／隐形盾牌／未展示盾牌”的原有状态生成完整中文行，盾牌名或投射物名缺译时，整行恢复原有英文，包括反射附句。

投射物规范名、击杀原因、伤害来源、状态来源键以及实际命中、伤害、闪烁和反射机制保留。

## 术语与保留范围

翻译前查询术语表，记录其 SHA-256、逐文件命中、译法和注释；重点沿用“虔诚、赎罪、先祖、防具、鸢盾、塔盾、火焰、寒冰、吸能、反魔法”和项目神祇名称。本批不修改术语表。

`randbook.cc` 的随机书名属于生成后保存的专名，保留既有名字生成与存储逻辑；不从已经生成的英文书名反推学派或再次调用随机生成器。随机引擎、随机变量、射线算法及各类枚举／声明文件中的内部标识不翻译。断言、技术错误、调试和向导诊断保留原文。任意脚本／延迟回调传入的文字保持既有接口语义。

21 个规范接口或生成函数的函数体与本轮基线完全一致，15 个 r 文件全文未改；3 个受影响文件中的 85 处随机调用表达式及顺序一致，见 `source-r-01-preservation.json`。没有解析显示英文来推断实体，没有重复执行随机、恩赐、Lua 或其他游戏效果。
