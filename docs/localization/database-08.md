# database 第八批：歌唱之剑的练习、闲聊与战斗对白

本批逐项校对 `database/wpnnoise.txt` 中 7 个 legacy 键、166 个候选：

- `_singing_no_tension_`：9 个练习音阶等候选。
- `_singing_no-low_tension_`：48 个演唱、演奏等候选。
- `_speaking_no_tension_`：2 个对白引用分支。
- `_common_speaking_no_tension_`：39 个常见闲聊候选。
- `_rare_speaking_no_tension_`：39 个少见闲聊候选。
- `_speaking_low-high_tension_`：22 个战斗对白候选。
- `_weapon_noises_low-high_tension_`：7 个战斗声音候选。

翻译前按完整单词边界查询术语表，记录见 [预查清单](database-08-preflight.json)。英文把 `double` 与公共后缀 `swords` 分开，因此另外查询完整物品名，按术语表使用“双重剑”“短剑”，并将同组的 `triple swords` 校为“三重剑”。其余专名和类别包括歌唱之剑、躯干防具、棍杖、魔窟、海德拉、杰西卡、西格蒙德。普通“生锈”不套用云名“锈尘”，“竞技场”也不强行加上神名。

## 校对内容

逐条核对音乐语境：`canon` 是卡农，`bars` 是小节，`concert pitch` 是标准音高，`counterpoints` 是对位练习。引用的“五声／半音／自然”与上层句子的“音阶”组合，避免重复。

恢复音高练习中“几乎／明显／空选项”和“达到／偏离”两组的原文顺序，其他随机组也按索引逐项对应；不会为中文重新抽取候选。高张力声音中的语气片段在中文里放到动词前，例如“像……一样尖叫”，而英文仍保持原顺序。

闲聊和战斗对白同时校对武器名、双关、成语及中文标点，修复原文缺少闭引号时的中文引号。英文原文完全保留，不回写这些中文排版修正。

## 回退与范围

本批只改译文和目录，没有修改游戏 C++ 或 Lua。译文进入上一批的严格配对显示路径，目录同时依赖原始英文文件和当前渲染源码哈希。遇到缺失正文、未知名称或其他未适配组件时，整条消息使用规范英文。纯引用分支只有所选子条目可用时才显示中文。

英文文件按字节未变；未选中的 58 个键正文保持本批基线。PO、中文数据与 [审核清单](../../localization/manifests/database-08.json) 同步。累计已审 **53／65 键**，仍有 **12 个 legacy 键待审**，包括低／高张力中的 Lua 对白、尖叫、四组歌曲、无神论替代词和四个模式入口。未将其余旧译自动标为已审，也未交给整文件导出器覆盖。

含 Lua 的尚未适配候选仍由原有严格路径执行规范英文一次并整句回退；本批未增加中文 Lua 程序，也未重新执行 Lua 或追加随机选择。四个模式入口即使部分分支已有中文，也不等于整组已审。

## 验证

数据检查覆盖 166 个候选的权重、引用、方括号顺序与数量、源文及译文哈希、PO 一致性、未选条目保持不变，以及源文变化时精确查询失配。原生本地化测试继续对比修改前的武器噪声渲染器，覆盖英文输出、频道、缺译回退、固定神器名称和后续随机状态。

Windows Tiles 编译、工具测试及原生测试结果见 [检查记录](database-08-checks.json)。未进行实际游戏窗口视觉验收。
