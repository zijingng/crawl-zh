# b 开头源码显示文本复核

本批基于 0.34.1，复核 `crawl-ref/source` 中名字以 b 开头的 20 个第一方 C++ 文件，并检查 3 个同名前缀 Lua 测试脚本和 `webserver/webtiles/bans.py`。第三方 contrib、生成依赖与 rltiles 不在本批翻译范围。逐文件清单见 [source-b-01-files.json](source-b-01-files.json)。

## 本批覆盖

本批目录复核 406 项：新增 360 项、复用 46 项。原有译文的来源依赖同步复核，检查摘要见 [source-b-01-checks.json](source-b-01-checks.json)，完整条目与依赖指纹见 [source-b-01.json](../../localization/manifests/source-b-01.json)。

- `beam.cc`：补齐光束出现、地形破坏、流星索束缚、生命献祭与吸血、护盾反射、意志抵抗与反击、空间锚定、魔法污染、牵拉、法术效果、迷魂与隐形、投掷派口味、爆炸视觉与声音、射线阻挡及射击确认提示等显示路径。规范弹体名通过独立显示目录适配，伤害归因与内部名称保留。
- `behold.cc`：迷魂、歌声停止、静默与心智控制解除等消息使用原始生物对象生成中文，不复用英文所有格和代词。
- `branch.cc`、`branch-data.h`：分支短名与全称、入场消息、环境噪声说明、符文说明。分支表本身不改，入场与总览在显示出口翻译。
- `bane-data.h`：14 组名称与简述；独立显示适配器用于变异菜单及厄咒说明标题和简述。浅学者厄咒从原始技能枚举生成完整中文描述。规范名称、查询键、Lua 与原始描述函数保持英文。
- 其余 b 开头 C++ 文件为声明、枚举、算法、书籍法术配置、生成构建信息或 JSON 协议。没有将内部标识及诊断文字当作玩家文案翻译。

共享显示出口按需修改 `stairs.cc`、`dgn-overview.cc`、`mutation.cc/.h`、`describe.cc`、`message.cc`、`fight.cc/.h`，而不把规范数据表中的英文直接替换为中文。总览按显示宽度补齐字段，避免用中文字节长度代替列宽。

## 分支术语

清点 40 个分支条目，包含旧版兼容分支，共 76 种不区分大小写去重后的短名与全称形式。术语表新增 42 项，保留原有 1665 项及备注，现为 1707 项。备注记录规范缩写及用途，缩写继续用于命令、配置、Lua、存档和解析。

沿用已有分支译名，例如地下城、众神殿、兽人矿井、史莱姆巢穴、荒盐之地等；补齐矮人大厅、刀刃大厅、魔法森林、迷宫、奥格瓦如竞技场、血肉熔炉、亡者之城等。全称分别采用“古人灵庙”“冥府铁城”“佐特领域”。Gauntlet 的“竞技场”与奥格瓦如的 Arena 为不同分支，已在新增术语备注中区分。

## 英文回退与行为保护

- 原有英文构造留在调用处，中文完整句子使用原始角色、物品、法术状态和已经选定的随机结果。缺少模板或任何必要组件时，整条消息回退原英文。
- 隐形消息在改变可见性之前保存显示名称；不通过变化后的英文代词推测原对象。
- 投掷派效果、爆炸、伤害及随机动词不额外抽样。中文确认提示使用追踪器已收集的目标，不重复运行追踪或 `bad_attack`。
- 分支名称解析与 JSON 输出、厄咒规范名称与原始简述、构建信息、配置/Lua 键、测试断言与服务器管理诊断保留英文。
- 混沌光束已有的专用英文回退条件保留。外部传入的未知消息、自定义地形、弹体名称或未来新增的确认后缀，沿用整句英文；不会解析已经生成的英文语法来拼中文。
- 本批不代表整个游戏的动态日志或所有分支相关界面已全译；非 b 文件中尚未接入的独立显示路径仍按原逻辑工作。
