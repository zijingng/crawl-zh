# d 开头源码：第四批显示适配

本批继续按“先查术语、再翻译、验证英文回退”的顺序推进。事前查询及源码指纹见[术语预查记录](source-d-04-preflight.json)，32 个新增目录项见[译文清单](../../localization/manifests/source-d-04.json)。武器印记优先复用现有物品显示词条，法杖伤害使用“火焰、寒冷、电击、大地、吸能、毒素、塑能”等对应类型。

## 覆盖

- 怪物攻击表的最大伤害列：基础值、纯火焰伤害、印记附伤、每四次攻击的额外伤害、多段攻击的每次伤害；法杖附伤仍复用原技能和伤害计算结果。
- 投掷攻击名称、白银和箭毒伤害标记、网捕、中毒、减速、致盲、混乱、狂乱及闪现效果；投掷名称和各列按显示宽度计算列宽。
- 取消药水和怪物水银箭说明中的完整效果列表。原规范状态接口及取消效果函数继续返回英文，显示副本验证每个效果；未知动态状态使整条父句回退英文。
- 神祇赠牌后的完整数量消息，包括逃脱、毁灭和召唤牌。牌组统计保留默认英文返回值，通过可选显示参数供父句使用；数量和顺序不变。
- 惩罚套牌的抽牌／出牌消息复用现有完整句子译文，不改变随机选牌。

## 回退与验证

攻击伤害列的必要组件缺译时保留该列原完整英文。中文不重复计算伤害或抽取随机值。取消效果使用同一份原效果序列，保留污染处理、变形和飞行的特殊规则。牌组统计默认接口、卡牌键和存档数据保持英文。
