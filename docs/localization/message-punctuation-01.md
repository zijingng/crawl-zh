# 合并日志的中文标点（2026-10-25）

本轮保留消息原文的标点，只修改同一行中消息之间的显示分隔与中文标点识别。

| 情况 | 示例 |
| --- | --- |
| 完整中文句子 | `你击中了兽人。 兽人倒下了！` |
| 无句末标点的中文片段 | `金币；药水` |
| 中文重复计数后继续显示 | `你闪避了！ x2；你命中了。` |
| 引号包围的完整中文句子 | `怪物说：“停！” 你退后了。` |
| 英文完整句子 | `You hit the orc. The orc dies!` |
| 英文片段，包括中文模式中的纯英文回退 | `Some gold; A potion` |

原 `_ends_in_punctuation` 只读取最后一个字节，认识 ASCII 的 `. ! ? , ; :`。中文模式新增 UTF-8 末尾码点识别，覆盖 `。！？ ，；：、…`，并检查中文引号/括号内已有的标点。物品名的闭引号本身不算句末标点。

`message_join_separator` 集中选择分隔符：已有标点时一个空格；无标点或带重复计数时，中文片段用全角分号，纯英文片段用原 `; `。英文模式保留原 ASCII 标点判定和分隔形式。颜色标签由现有 `pure_text` 处理，不参与末尾标点判定。

中文合并行的长度按实际渲染后的文本计算，包含前一片段所需的分隔符及 `xN`。这同时解决原长度循环误用当前片段而非前一片段的分隔需求、在重复计数附近少算一列的问题。英文长度路径保持原有实现。

没有改动消息生成、译文、重复计数、消息频道、同回合/短消息合并条件或存档格式。目录只复核本次变化的显示基础设施依赖，见 [源码依赖记录](../../localization/manifests/message-punctuation-01.json)。

回归检查直接调用 `mpr` 和 `get_last_messages`，覆盖中文句子/片段/重复计数/颜色/闭引号、39 与 40 列的真实合并边界、英文模式和纯英文回退。另检查空字符串及不完整 UTF-8 字节。
