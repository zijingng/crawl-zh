# d 开头源码显示文本：第一批覆盖记录

本文的 1,705 项与测试数为第一批历史记录。累计清单已随[第二批适配](source-d-02.md)继续扩展，最新累计数量和剩余工作以第二批记录为准。

本批对应 0.34.1，按术语表适配 Windows Tiles 的显示路径。当前登记 **1,705 个唯一译文目录项**；条目数包含标签、短语和完整消息，不代表全部 d 文件已经覆盖。完整条目见 [来源清单](../../localization/manifests/source-d-01.json)，目录和依赖检查见 [验证摘要](source-d-01-checks.json)，顶层 65 个 d 开头 C++ 文件见 [文件清单](source-d-01-files.json)。

## 已覆盖内容

- `describe-god.cc/.h`：神祇面板标题、神衔、好感、赎罪、神罚条件、祈祷技能、能力说明与先祖升级，以及部分神祇的专属数值说明。对照 `religion.cc` 实际使用的 131 条能力一般说明逐条翻译；宗教规则表仍保存英文。
- `describe.cc/.h`：大量物品和怪物固定说明、装备属性、护甲值等数值标签、变形面板、怪物威胁、抗性与易伤、栖息环境、行为特征、当前目标、速度及命中率。随机神器属性表保留规范英文，仅翻译显示副本。
- `describe-spells.cc`：法术书表头、法术名、学派与等级、怪物法术分组及部分效果参数。学派中文根据法术原始学派标志取得；WebTiles 协议学派键保持英文。
- `duration-data.h`：状态灯、状态短名、长说明、结束及即将结束提示。新增独立的状态显示入口，供 `output.cc`、`player.cc`、`tileweb.cc` 使用；原状态接口继续提供规范英文，保留 Lua 和取消效果逻辑对英文状态文本的判断。
- `decks.cc/.h`：多处抽牌、发牌、叠放与选择提示，卡牌名、牌组名、剩余牌数、牌组详情、卡牌所属牌组说明、部分卡牌效果及雷鸣日志。牌组详情复用已有显示适配器；牌序、容量与随机结果使用原数据。
- `delay.cc`：穿戴、卸下、变形、休息、中断、自动拾取、灌注仆从与铭刻武器等活动提示。
- `dactions.cc`、`death-curse.cc`：部分离场、变形、死亡诅咒及神祇消息。随机诅咒结果只选择一次，英文与中文复用同一结果。
- `directn.cc`：多处瞄准提示、目标选择菜单、移动禁区与观察提示；`dgn-overview.cc`：地下城概览、分支、祭坛、商店和楼层注释；`dgn-shoals.cc`：面向玩家的潮汐消息。
- `database.cc`、`dgl-message.cc`：部分加载、缺失帮助和消息查看提示。数据键、外部来信正文、系统错误和技术诊断保留原处理方式。

术语沿用 `localization/glossary.csv`，包括“防具／躯干防具／护甲值”“天资”“沉默”“移动禁区”“牛头人”“叠放五牌”“三抽择一”等；多义条目按语境选词，不将 `/` 显示到游戏里。

## 英文回退与规范数据

英文模式保留原英文构造，包括冠词、单复数、所有格和动词变化。中文动态句子使用同一对象、枚举与数值；缺少必要模板或名称时，整句或整段使用原英文。独立表格标签可以分别回退。

神衔、状态、神器属性、牌组、法术学派等规范数据不替换成中文。Lua、存档、数据查询和名称解析继续使用原数据。命中率显示复用原计算结果，不因中文显示再次构造攻击或额外取随机数；测试使用固定种子及固定序列比较英文输出和随机状态。

译文目录同时校验英文来源与源码依赖指纹。依赖变化但尚未复核的译文应由生成器排除。Makefile 不作为目录自身的源码依赖，避免生成步骤改变 Makefile 后使译文自失效。

## 尚需继续覆盖

**本批并非 d 开头源码全覆盖验收。** `describe.cc` 仍有物品类别、武器和防具比较、变异及部分动态怪物说明；`directn.cc` 仍有地形和怪物装备的复杂组合说明；`describe-god.cc` 仍有部分诅咒装备与佐姆说明；`decks.cc` 仍有其他统计和赠牌组合文案。这些路径需要继续从原始对象建立完整中文消息，不能通过替换英文片段处理。

`dbg-*`、巫师编辑器及地下城生成诊断按用户要求不纳入本轮玩家文案翻译；枚举、协议字段、Lua API、查询键和错误定位信息也不应机械翻译。文件清单中的“已改动”仅记录相对本轮工作区基线的差异，不等于该文件已经完成。
