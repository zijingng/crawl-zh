# 动态名称第一批：怪物与物品

基线 0.34.1，分支 `stone_soup-0.34.1-zh`。

## 实现范围

新增物品及怪物的显示名接口，接入背包、装备、说明标题、商店、获取物品选择、视野物品、已知物品、资料查询列表和怪物列表。英文规范名称继续用于原有消息、脚本、数据库和存档；查询保留英文键与排序，并支持中文过滤。

物品覆盖普通类型、固定神器、已缓存随机神器名、强化值、品牌、数量、充能、诅咒、装备状态、符文、手册、尸体及骸骨等。未鉴定物品仅翻译已知外观，卷轴随机标签保持原文。程序生成专名使用中文模板包裹原名，不额外消耗命名随机数。

怪物覆盖普通及独特怪物，以及海德拉头数、丧尸、冰骸、幽魂、丑怪颜色、龙人、史莱姆大小、变形怪、突变兽和舞动武器等组合。群组继续遵守原有合并规则，不把第一只的颜色、装备或专名误用于整组。

## 英文回退边界

- 英文模式保留原有命名路径。中文条目缺失、原句变化或必要部件缺译时整名回退英文，接口失败不修改输出。
- 脚本自定义怪物名、未收录外观、未缓存随机神器名保留英文；不把中文片段塞进原有英文语法函数。
- 羊皮纸需要对应法术名译文；法术名称目录尚未全覆盖，缺少时整名回退。
- 查询中的地狱之蛇分支别名保留英文，避免丢失分支信息。部分无有效数量的固定神器查询预览也可能回退；真实有效固定神器已做遍历检查。
- 战斗、拾取等动态句子仍使用原英文路径。题词、自定义名及属性缩写保留原文。
