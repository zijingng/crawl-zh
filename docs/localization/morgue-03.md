# morgue 死亡记录与高分榜中文文件

翻译前查阅术语表和现有成绩、笔记、云雾及攻击名称译文，见 [预查记录](morgue-03-preflight.json)。新增的模板复用既有怪物、物品、法术与攻击名称。

## 死亡信息与记录

将死亡显示适配独立为 `display_death_description`，供 morgue 成绩段和死亡笔记复用。继续保留 `death_description`、成绩原始行与英文导出入口。

本轮补齐可确定组件的怪物近战（包括死亡伤害程度）、头槌、碾压、尖刺、投掷、缠绕、中毒、部分远程攻击、解离和云雾死亡，以及武器／攻击方式和伤害量。名称必须命中已审核译文，或与规范类型生成的带冠词名称完全相同。旧成绩中的普通武器仅接受完整规范名称匹配，不根据附魔数字或神器名猜测。

新产生的死亡笔记沿用原英文 `name`，在现有 `desc` 字段内附带带版本前缀的规范 xlog 成绩快照，不存中文译文、不改变笔记存档版本。读取时先验证快照能重建原英文死亡说明，再调用中文显示适配；旧笔记、缺失／不匹配元数据和无法识别的组件保留整条英文。巫师模式逃过死亡的固定记录也已补译。

遇到无法处理的召唤归因、附加攻击描述或致死时的禁锢状态，保留完整英文死亡段，避免漏掉来源和条件。玩家手写记录、脚本消息和历史死亡句子不进行猜译。怪物事件笔记的规范带冠词名称也可复用已有怪物译名。

## 高分榜打开 morgue

中文语言配置下先打开同名 `.zh.txt`，文件不存在或无法打开时读取原 `.txt`；英文配置始终读取 `.txt`。原英文文件及生成路径保留。修改影响新导出的记录，既有 morgue 文件不自动重写。

读取器先重组字节块再处理完整行，替换旧的 200 字节分段读取，防止长中文行在汉字中间被截断并插入换行。文件按纯文本显示，保留空行、未换行的末行和字面量 `<...>`，不会把玩家文字当颜色标签解析。

morgue 滚动窗口显式启用逐行文本操作。Tiles 的可见范围裁剪以格式化操作为单位，按行拆分可以避免一次提交整份记录的汉字。其他滚动窗口保留原行为，不依靠扩大字体缓存掩盖问题。

## 验证

Windows Tiles `crawl.exe` 和原生测试程序编译通过；10 项原生测试共 521 条断言、33 项 Python 本地化检查通过。此前三份英文测试记录逐字节不变。

编译和定向测试结果见 [检查记录](morgue-03-checks.json)。测试包含超过 1600 个不同汉字的长记录、超过旧字节限制的中文行、中文优先与英文文件回退、英文模式、缺译整段回退、规范成绩不变和 RNG 不变。字符缓存检查针对输入操作与裁剪粒度；实际图形界面的滚动效果仍需游戏内复测。
