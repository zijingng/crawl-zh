# q 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

范围为核心源码顶层全部两个 q 开头文件：`quiver.cc`、`quiver.h`。接入、复核 103 条译文，涉及动作栏、备选动作菜单、物品/法术/能力名称、攻击反馈和按键帮助。逐文件范围、译前术语命中与指纹、验收结果分别见 `source-q-01-files.json`、`source-q-01-preflight.json`、`source-q-01-checks.json`；规范接口保留核对见 `source-q-01-preservation.json`。译文及依赖清单为 `localization/manifests/source-q-01.json`。

## 动作栏与名称

物品、远程攻击、近战、投掷、法术和能力行保留原英文构建代码，再从原始对象及状态生成中文。名称复用现有物品、法术、能力和形态显示接口；动作词使用独立显示上下文，`quiver_verb()` 的规范英文返回值不变。

物品快捷键、数量、颜色、坟墓之爪充能数和法术失败率沿用原值。已有启用状态和颜色计算结果用于中文行，法术可用性缓存不因翻译重新初始化。未知名称、动作词、卡牌附注或必要模板缺译时，整行动作描述恢复英文。麦克斯韦法术沿用上游动作栏中的简称 `Capacitive Coupling`，显示为“电容耦合”。

空动作、混乱时的动作词、施法/继续施法、阅读、饮用、使用魔杖、唤发等标签已适配。卡牌能力的下一张牌/牌数从相同的牌堆状态生成；英文回退使用完整英文卡牌附注。

## 日志、目标与菜单

补齐伤势和魔力不足、鲁莽消耗资源、拆解构造物、混乱攻击、受缚无法攻击、攻击地形、长柄武器被阻挡、攻击空地、无目标等消息。怪物和地形名称从原始对象获取；看不见的阻挡者仍使用原来的未知对象提示，不泄露身份。命中率说明使用既有显示适配，原始计算只调用一次。

备选动作菜单补齐物品/法术/能力标题、物品栏和全部法术/能力入口、聚焦模式开关、循环帮助、清空提示、当前备选标记与确认提示。菜单标题与切换帮助按组回退；当前备选标记只在动作行完整翻译时使用中文，避免英文动作行接中文标记。

菜单和命令文档已有的通用用语为“备选动作”，本批沿用。其他文件历史上的物品“箭袋”表述不在本批改写范围。`%` 命令占位符、快捷键、铭文和配置筛选逻辑保持原值；翻译后仍由原有命令插入机制处理。

## 术语与英文保留

译前查询记录包含全部源码命中的术语及术语表 SHA-256。重点按“唤发、混乱、劈斩、魔力值、坟墓之爪、麦克斯韦的电容耦合”等项目约定处理。形态攻击动词属于动作描述，不作为同名法术或物品品牌机械替换。

这两份源码中的存档键，以及动作 `type`/`param`、铭文 `!Q`、`=f`/`=F`、`+f`/`+F` 均保留原值。存档、载入及动作工厂等 11 个函数体与本轮基线一致；`quiver_verb()`、英文名称接口及游戏规则不随语言切换改变。

技术 Lua 错误、内部断言及向导模式的地形建造诊断保留原文。没有全局拦截消息、改写任意脚本文本或解析已经拼好的英文名称；缺少译文或已审核依赖指纹时保留原英文表达。

## 验证

Windows Tiles 的 `crawl.exe` 编译成功。本地化测试 88 项、184,311 次断言通过；Python 工具测试 28 项通过。103 条译文与 PO、生成目录一致，全局源码依赖指纹无过期项，`git diff --check` 通过，详情见 `source-q-01-checks.json`。

新增回归覆盖空动作、三个种族全部形态的主动作、物品动作、法术名称与充能数值、语言切换、规范动作词、序列化字段和随机状态保持不变。

仅构建 Windows Tiles；未进行游戏内视觉验收。
