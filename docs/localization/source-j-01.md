# j 开头核心源码显示审查

基线：0.34.1。日期：2026-10-23。

已排查游戏核心源码顶层全部 9 个 j 开头 `.cc/.h` 文件。译前查询术语表，并对照既有显示入口与生成目录。本批未发现需要新增适配的玩家提示，因此没有修改游戏源码或翻译数据，也没有重新编译。详细文件指纹、术语命中和名称核对见 `source-j-01-checks.json`。

## 逐文件范围

| 文件 | 内容与处理 |
| --- | --- |
| `job-data.h` | 自动生成的背景名称、简称、初始属性、装备配置和技能表。26 个现行背景名全部命中术语表，既有 `display.creation` 译文与术语一致。7 个已移除背景保留兼容数据。装备描述是解析器输入，不替换为中文。 |
| `job-groups.h` | 自动生成的 5 个背景分组标题。实际新建角色界面使用 `newgame.cc` 的分组表，通过 `display.creation.group` 翻译；5 项均已有译文。 |
| `jobs.cc` | 背景规范名、简称、查询、初始装备与技能逻辑。`get_job_name` 保留英文，界面调用者显式翻译；`Unemployed` 是未知背景的规范哨兵。数据自检诊断保持英文。 |
| `jobs.h` | 上述接口声明，无独立玩家提示。 |
| `job-def.h` | 背景数据结构和武器选择枚举，无独立玩家提示。 |
| `job-type.h` | 自动生成的背景枚举，保留顺序、编号和兼容性。 |
| `json.cc` | JSON 编解码、校验与内存处理；语法字面量、结构诊断、致命错误保持原文。 |
| `json.h` | JSON 类型与接口，无玩家提示。 |
| `json-wrapper.h` | JSON 生命周期、类型检查与异常封装，无玩家提示。 |

范围延续前几批的游戏核心源码口径，不包含 `contrib` 内捆绑的 JPEG 等第三方库。

## 术语与回退

26 个现行背景名全部逐项核对，包含“塑能师、猎手、妖术师、修补匠、掠夺者”等。分组标题继续采用已有的“战斗者、冒险者、信徒、战法兼修、法师”。其中分组 `Warrior` 使用“战斗者”，区别于术语表单独名词 `Warrior` 的“勇士”：这里表示包含战士、角斗士、武僧、猎手和强盗的背景类别，不是一个具体背景名。

背景名和分组标题的中文仅在显示端查找；底层规范英文、简称、配置输入和存档枚举保持不变。英文模式与缺译仍由原有 `ui_translate` 回退。没有为了翻译修改随机背景选择、角色初始化或 JSON 行为。
