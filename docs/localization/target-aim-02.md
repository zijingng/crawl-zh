# f／v／z 瞄准行回退排查与修复

翻译前查阅术语表和已有命中率、辅助攻击、目标前缀及怪物状态译文，见 [预查记录](target-aim-02-preflight.json)。新增两条简短命中率模板，其余复用现有译文。

## 原因与修复

1. `describe_to_hit` 的中文显示辅助函数遇到 `verbose=false` 就返回空字符串。投射、近战触及及部分法术的 Aim 描述恰好使用简短模式，因此即使命中率与怪物名称已有译文，整行仍会按要求回退英文。现在简短和详细模式均从同一次计算结果构建中文；覆盖致盲时的距离提示和辅助攻击名称。
2. 回调返回空字符串时，被当成“非空文本缺译”。现在空描述只表示没有这一项，不阻断整行；非空未知描述仍缺译并触发完整回退。
3. 装备描述的态度显示分支逐个查找已拼接状态文字，无法覆盖带代词的呼吸／痛苦联结及动态记忆数量。现在复用 `monster_info::attribute_display_args` 的类型明确显示路径，保持属性顺序与原有英文描述。

将实际使用的怪物瞄准正文构建过程整理为 `monster_target_description`，供方向选择器与测试共用。单元测试可以检查真实的怪物、装备、伤势、状态和回调组合，而非仅向前缀函数传入手写中文。

## 英文回退

英文命中率流、怪物正文、物品名称与内部标识保持原样。没有解析生成后的英文来猜译，没有切换全局语言重放回调，也没有再次计算命中率。中文名称、状态或非空动态描述中任一必要组件缺译，整行仍回退原英文 `Aim` 前缀及正文，颜色标签保留。

空描述本身没有待翻译信息，只在中文显示中省略。规范英文正文仍保持原来的输出。

## 验证

Windows Tiles `crawl.exe` 与原生测试程序编译成功。7 项定向原生测试共 863 条断言、33 项 Python 本地化检查通过。测试覆盖弓、投石、近战、头槌、致盲、两种描述模式、状态表全部条目、不同伤势、动态状态，以及`Stone Arrow`、`Momentum Strike`、`Electric Charge`、`Slow` 与 `Sticky Flame` 的实际法术描述回调。英文内容、命中率数值、RNG 和单次回调保持不变，未知怪物和非空未知描述仍完整回退。

测试使用游戏实际调用的目标正文构建器和描述回调，尚未进行窗口内 f／v／z 按键操作复测。详见 [检查记录](target-aim-02-checks.json)。
