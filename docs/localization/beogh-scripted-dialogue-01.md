# 固定怪物对白的双语传递

比欧弗招降的四条台词及使徒相关对白已有已审 TextDB 译文。原调用先执行 `getSpeakString(key)`，该函数返回普通字符串；包含怪物名等运行时标记的双语对象在替换之前失去中文分支，导致整句英文回退。即使只传入中文模板，普通替换也不能保证中文怪物名与必要组件的完整回退。

相关调用改为只执行一次 `getPairedSpeakString(key)`，将规范 `speech.english` 和同一个 `textdb_speech` 对象交给 `mons_speaks_msg()`。现有替换逻辑在英文和中文分支中处理名字、所有格、目标等标记，最后才选择显示正文。没有新增对白译文或 UI 目录副本，没有新增快照；缺译或必要组件不可用时仍返回完整英文。

覆盖招降的首次提示与后续劝说、兽人援军、使徒认输／离队／脱离深渊、Lua 怪物 speak 接口、召唤问候、逃跑／被逼入绝境、闪现他人后的台词、牵线傀儡结束后的抱怨、谜语回应及精灵双子的死亡回应。空文本与 `__NONE` 保持原来的判断位置；选择对白仍发生在原调用位置，不为中文再次随机抽取。

术语表已核对：Beogh 为“比欧弗”，orc priest 为“兽人祭司”，Wrath 为“神怒”。对白正文继续由 `textdb.po` 单一维护，本轮仅改变数据传递并刷新已审源码依赖。

Windows Tiles `crawl.exe` 和测试程序编译成功。新增的招降／使徒用例覆盖五组对白、每组 32 个随机种子及实际 `mons_speaks_msg()` 输出，验证规范英文、中文名字、通道标记与随机状态。四项原生用例分别运行通过，共 12,283 条断言；32 项 TextDB／目录／源码哈希检查通过；已审译文依赖失配为零，`git diff --check` 通过。

组合运行对白测试时出现测试进程崩溃；不包含新用例的旧测试组合也能复现。各项独立运行均通过，但组合崩溃原因尚未定位，不能将组合运行报告为通过。未执行完整原生套件或 Linux WebTiles 编译。
