# z 开头核心源码显示文本覆盖

基线：0.34.1。日期：2026-10-24。

已审查全部 4 个 z 开头的核心 `.cc` / `.h` 文件：`zap-data.h`、`zap-type.h`、`zot.cc`、`zot.h`。本批仅修改 `zot.cc` 的显示调用；其他 3 个文件全文不变。第三方依赖源码不属于本批游戏显示文本范围。

## 术语与覆盖

翻译前查询 `localization/glossary.csv`，逐文件原文、命中及术语表指纹见 `source-z-01-preflight.json`。沿用“佐特、水晶矛、宝石”等译法；Shatter 作为普通破碎动作按语境表达，不套用法术名“粉碎术”。未修改术语表。

`zot.cc` 接入全部 12 条显示模板：死亡／进入楼层后失去踪迹、佐特力量触及、3 级时钟警告、地面宝石拟态揭露与碎裂、2 级宝石超时警告、持有宝石碎裂，以及回合倒计时说明。

`zap-data.h` 的 145 个非空唯一弹体名称保留规范英文，经既有 `try_ui_projectile_name()` 接口显示。补齐唯一缺少的 `crystal spear → 水晶矛`，其余 144 个复用现有译文。`zap-type.h`、`zot.h` 的枚举、声明与常量保留不变。

本批共登记 13 个译文词条，见 `localization/manifests/source-z-01.json`。

## 英文回退

原英文消息和格式化表达式均保留。中文宝石消息通过原始 `gem_type` 对应的规范物品名查询既有 `display.item` 译文，不解析英文句子，也不向中文句子传入已带英文语法的宝石形容词。缺少宝石名称或整句模板时，整句回退为原英文。

倒计时仍由原有 `(time_left + 9) / 10` 计算；中文模板使用字符串参数，原英文继续保留 `%d` 格式和原有单复数措辞。不会为翻译改变游戏计时、宝石销毁、生命损失、活动中断或随机选择。

存档键 `ZOT_CLOCK`／`ZOT_AUTS`、分支缩写／`Hells`、`gem.lost` 里程碑及笔记原文保持英文。弹体规范名称不变，避免影响数据库、Lua、搜索和伤害来源。

## 验证

Windows Tiles 已编译为 `crawl.exe`。原生本地化测试检查真实 `gem_status()` 的中英文输出、1／10／11／20／21 aut 边界的向上取整、缺少译名／新原文时整句回退、隐藏／碎裂状态、计时与随机状态不变，以及水晶矛的显示接口。另核验全部 145 个弹体名称和 13 个未移除的宝石名称有中文译文。已移除的兽人矿坑宝石 `GEM_ORC` 保留兼容数据，`gem_for_branch()` 不会选择它；缺少其译名时按整句英文回退处理。

生成目录与主清单一致，源码指纹无过期项，笔记／里程碑、游戏效果与随机调用保持不变。测试数量及具体保留检查见 `source-z-01-checks.json`。
