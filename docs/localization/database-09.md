# database 第九批：低／高张力对白与无神论替代词

本批校对 `database/wpnnoise.txt` 中 3 个 legacy 键、53 个候选：低张力对白 15 个、高张力对白 32 个，以及 `_godless_sorter_` 的 6 个替代词。翻译前按完整单词查询术语表，记录见 [预查清单](database-09-preflight.json)。例如 `shatter a wine glass` 是“震碎酒杯”，不使用法术名“粉碎术”；普通的战斗、力量、神等词也按句意处理。

## 校对结果

- 旧中文高张力段有 33 个候选，包含当前上游已删除的“这是……的旨意”。本批按当前英文的 32 个候选重排，避免权重和索引错位。
- 低张力旧译将 Lua 的 `return "my blade"` 改成了中文。本批恢复规范英文程序；两处嵌入式 Lua 的完整程序，包括换行与字符串，都与英文逐字一致。
- `your miss, my kill` 中的 `miss` 是失手，不是思念；`No rest until they move no more` 是直到敌人不再动弹才罢休；`Blade-deep in blood` 是鲜血深及剑身，不是“刀口舔血”。
- `All those pillows!` 保留剑把敌人比作枕头的怪诞说法，不添加“绣花枕头”的评价；`go for the jugular` 译为“直取颈脉”。音乐、血肉与杀戮的双关结合上下句校对，中文引号和标点统一。

## 数据与英文回退

英文文件按字节不变，原键、权重、引用及方括号候选顺序均保留。未选的 62 个键正文保持本批基线。译文同步到 PO 与中文数据库，源文／译文哈希见 [审核清单](../../localization/manifests/database-09.json)。目录继续使用上一批已经接入的严格配对显示及源码依赖保护；本批没有修改 C++ 源码。

两个 Lua 候选的外围中文已校对并保存，但**实际显示继续整句回退规范英文**。程序只执行原有英文版本一次，不运行中文副本，不重新抽取神名或其他候选。不会把英文 Lua 返回值嵌进中文消息而产生中英混排。

累计完成 **56／65 键的数据审核**，另有 **9 个 legacy 键待审**：四组歌曲、尖叫段和四个模式入口。两个 Lua 候选的中文显示适配另行待办；“数据已审”不等于这些候选已经显示中文。整文件导出仍未接管。
