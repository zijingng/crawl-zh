# 玩家种族颜色与可见怪物列表

## 遗留的暂缓条目

先前清单中的唯一未审项是 `combat.fear`／`You attempt to attack %s, but flinch away in fear!`。它是早期直接向翻译模板传入英文 `DESC_THE` 怪物名的遗留占位项，故保留暂缓状态。

实际攻击恐惧提示已经在 `melee-attack.cc` 使用 `combat.fear.actor` 和 `m_actor_arg` 完成中文显示。该路径已有“你试图攻击%s，却因恐惧而退缩！”译文。旧占位项不表示实际游戏还缺这条翻译，也不应直接标为已审而重新启用不安全的英文参数组合。

## 可见怪物列表

`You can see ...` 和 `You could see ...` 已有译文及角色、状态参数，但 `monster_info::to_string` 的显示分支曾明确排除带 `adj` 的名字。友好／中立怪物恰好使用这一参数，因而它们会使整个可见怪物列表回退英文。

现在该分支接受已知态度参数，通过“%s的%s”模板组合“友好／中立”及已翻译的怪物名。被魅惑、召唤物、盟友目标、调整呼吸等状态沿用既有术语与显示路径。未知名字或状态仍使整条英文回退，不截断列表，也不忽略缺失组件。

## 有色龙人的玩家名称

玩家创建／存档／欢迎语及角色描述使用 `display.creation`。八种有色龙人的名称已经存在于其他角色名称目录，却没有进入这个目录，导致 `White Draconian Summoner` 等整条描述回退。

本轮核对术语表和历史译文后，为红、白、绿、黄、灰、黑、紫、苍白龙人补入既有译名；没有更改规范英文种族名、职业名和存档内容。原有玩家显示调用直接复用这些条目，无需修改每个界面。

本轮增加九个已审显示键。已有 morgue 文件及保存的旧消息文本不直接改写；新的可见怪物提示、欢迎语及重新生成的角色描述使用更新逻辑。英文 morgue 与完整英文回退继续保留。
