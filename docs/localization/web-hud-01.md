# WebTiles HUD 与快捷栏

WebTiles 的 HUD 使用网页模板和 JavaScript，桌面 Tiles 的已译标签不会自动传入浏览器。本轮通过已有 options 消息新增 `language` 字段，值为游戏实际生效的 `zh` 或 `en`，同时发送 `ui_text` 显示目录。HUD 的生命、魔力、属性、防御、等级、地点、时间、厄运、污染等标签直接取自现有 `phase3.output`／`o.label` 译文，仅去除桌面定宽布局的首尾空格。

网页不维护另一份中文词典。快捷栏的鼠标提示和设置选项使用 `ui.po` 的 `web.ui` 条目；物品名、动作、空手攻击和预备动作复用已有显示接口。新增文本按术语表及已有译文校对，“巫师”“魔力”等沿用现行用词。

角色称号、种族与神名组合、地点、物品和状态灯使用单独的显示字段。英文种族名、神名、状态文本、物品名、设置值及操作命令继续用于规则判断、排序和筛选。组合字段缺少任一译文时，回退完整英文表达式。英文配置或旧服务端未发送语言／显示字段时，网页保持原有英文。

状态显示接口可接收已经生成的规范状态副本，避免重复生成冲锋指示等动画状态。发送状态时先更新规范缓存，再生成显示副本；首次完整同步也会更新缓存。浏览器对沉默等状态的检查仍使用规范英文文本。

部署需要同时更新游戏二进制和该版本 `gamedata` 中的模板、JavaScript，并重新开始游戏进程、刷新网页。只替换二进制不足以更新浏览器的 HUD 标签。

验证包含真实 AMD 模块的 Node 回归测试、Python 目录检查、标签目录命中和已审依赖检查，以及共享状态接口的 Windows 原生测试。本地环境不能完成 Linux WebTiles 构建或线上浏览器验收，服务器仍需按原有参数重新编译并测试。检查结果见 [记录](web-hud-01-checks.json)。
