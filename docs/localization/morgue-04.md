# morgue 开始游戏与等级记录补译

翻译前核对术语表中的生命值、魔力值、佐特宝珠、种族、背景及模式名称，并参考已有记录与成绩译文。见 [预查材料](morgue-04-preflight.json)。本轮新增 12 条已审模板，不重复维护种族、背景等名称。

## 覆盖

- 开始游戏时“某位某种族某背景开始寻找佐特宝珠”的记录。
- 开始游戏、升级和等级下降时的经验等级、当前／最大生命值、当前／最大魔力值。原有取整、临时形态排除及数值计算保持不变。
- 游戏版本从旧版升级至新版的记录，版本字符串原样保留。
- 巫师模式开始游戏、进入巫师／探索模式、主动进入深渊、通过出口进入深渊、逃离深渊／魔窟、逃入深渊和窥见佐特力量的固定系统记录。

## 实现与英文回退

原英文 `Note::name` 和 `Note::describe` 保留。构造开始游戏、等级与版本记录时，在现有笔记字段中补存带版本标记的规范数据：开始时的种族／背景与角色名、当时的四项生命／魔力数值、前后版本号。没有保存中文译文，也没有改变笔记存档版本。

显示时先验证这些数据能完整重建原英文记录，再调用已有名称译文与中文模板；缺失、损坏、不匹配或缺译时保留整条英文。开始时的种族／背景取自记录快照，角色后续变化不会改写历史。

旧存档中没有这些快照的开始与等级记录继续保留原文，不从英文句子反推动态参数。固定系统记录只按完整已审原句匹配；玩家自写 `NOTE_USER_NOTE` 始终保留原样。版本中的冒号通过已有 xlog 转义处理。

`.txt`／`.lst` 英文生成入口、`.zh.txt` 中文附加文件和高分榜的中文优先／英文回退保持原方案。已有 morgue 文件不会自动重写；开始记录的新显示需要新游戏，已有游戏后续产生的等级记录也会使用新快照。

本轮尚未接管漂泊者／巨灵开局装备与法术清单的历史拼接句，仍按完整英文保留。

## 验证

Windows Tiles `crawl.exe` 与原生测试程序编译通过。11 项原生测试共 623 条断言、33 项 Python 本地化检查全部通过。此前三份英文测试记录逐字节不变。

定向测试覆盖构造时英文一致、中文显示、数值为零和负数、存读往返、角色状态变化、损坏快照、旧记录、手写笔记、实际双语文件、高分榜读取及 RNG 不变。最终结果见 [检查记录](morgue-04-checks.json)。
