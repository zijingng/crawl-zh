# 阶段 3：神祇说明与实体显示名称

基线：官方 0.34.1。遵循工作区根 README 的汉化方针：保留上游英文生成逻辑，中文缺译或来源变化时回退英文；名称仅用于显示，内部标识、查询键和存档语义保持原样。

## 范围

- 新译并逐行校对神祇简介 27 条、神力概述 27 条，累计 TextDB 已审导出 595 条。包含历史兼容的 Pakellas，不表示其为现行可选神祇。
- 神祇文件共 82 个有效键，本批审定 54 个；神罚及武神额外说明等余下 28 个键采用英文回退，不继续加载未经本批复核的旧中文。原中文已归档在 `localization/legacy/0.34.1/descript/gods.txt`。
- 增加已审说明所对应的 63 个法术显示名称。接入施法列表、法术库、详情标题、法术查询结果及施法箭袋标题；未覆盖的法术名继续显示英文。
- 增加 27 个神祇显示名称，专名参照术语表。接入神祇菜单、详情标题和 HUD。菜单及详情中文模式保留括号中的英文名称或全称；神祇动态消息尚未全部汉化。
- UI 目录累计 459 条。法术名未收录在现有术语表的，作为本批可审阅定名存放在 PO 和批次清单，不擅自修改术语 CSV。

## 英文回退与数据边界

`spell_title()` 保持上游实现与英文返回值；新增 `spell_display_title()` 只在界面显示处查询译文。法术库同时接受原英文名称与中文显示名搜索，排序及脚本名称仍使用原英文。

法术查询菜单只有取得不同于原名的中文译文时才更换显示文字；英文模式和缺译时保留上游菜单原标题，避免大小写被内部名称替换。

神祇菜单保留原 `text`、`data` 与 ASCII 快捷键，仅覆盖显示方法；英文或缺译时直接调用原有 `MenuEntry::get_text()`。神祇详情仍使用原函数生成英文全称，包括随机称号；中文标题不会替换用于 TextDB 查询的原名。HUD 保留 Jiyva 原英文后缀生成分支作为英文与缺译回退。

`ui_translate` 按上下文及完整英文匹配，英文改变后旧译文不匹配即回退。TextDB 导出核对完整英文正文指纹，缺译、fuzzy 或来源改变的条目不导出，运行时使用原英文数据库。

本批英文源码文本、神祇和法术数据文件均未替换为中文。详细逐行记录见 [审查记录](phase3-textdb-line-review.json)，名称与新增键见 [批次清单](../../localization/manifests/phase3-static-03.json)，当前缺译键见 [覆盖报告](phase3-coverage.md)。

## 验证

gettext 目录测试 8 项、TextDB 测试 4 项、现有 Lua 执行分支 11 个通过。595 条审查记录与当前英文来源、PO 译文一致，术语表指纹未变，重复导出结果一致。

新增 C++ 测试检查中文法术名、原英文查询、缺译及来源改变回退，并遍历所有有效法术检查英文模式原名。最终本地化测试 6 个用例、588 项断言全部通过，Windows Tiles 程序构建成功。具体结果及程序指纹记录在 [本批检查结果](phase3-static-03-checks.json)。本批尚未进行 GUI 排版验收。

名称接入涉及代码，需要重新编译 Windows Tiles 程序；说明正文由正常构建的 `textdb-zh` 目标导出。运行时使用 `language = zh`，切回 `language = en` 后重启即可恢复原英文。
