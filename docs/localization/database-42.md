## 显示与英文回退

getRandNameString 明确使用英文词库，递归引用也沿用英文；英文生成过程、存档名称和名称长度判断不随显示语言变化。官方 randname.txt、randbook.txt 未修改，没有增加存档属性。

新增显示接口读取配对词库并展开外观引用，按缓存的英文外观精确匹配中文，不执行 Lua，不消耗随机数。字典随数据库关闭清空。只允许已审外观命名空间；遇到缺译、未知结构、歧义、未知词或超出展开上限时不返回部分译文。

未鉴定随机神器的显示从 ARTEFACT_APPEAR_KEY 读取既有外观，匹配中文外观后接基本物品名称。示例：ichor-stained short sword 显示“沾有灵液的短剑”。不读取神器真名来补齐外观，不显示未知属性。无法匹配时仍尝试已有完整外观译文；缺项则由原显示接口整名回退英文。

本批没有翻译完整的随机神器称号、魔法书标题组合、拥有者或随机人名。book_noun 与 _book_noun_on_ 已完成数据审核，完整标题仍待后续显示适配；不能将本批视为全部随机命名的中文覆盖。
