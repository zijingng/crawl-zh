# 阶段 3：道具显示名、操作提示及剩余神祇说明

基线：官方 0.34.1。新增 64 条已审 TextDB 说明，累计导出 659 条；新增 312 条界面目录项，累计清单 771 条，其中已审 770 条，恐惧消息样例仍暂缓。数字表示当前接管范围，不是全游戏汉化百分比。

## 道具显示名称

新增独立的 `try_item_display_name` 界面命名入口。当前目录包含 175 个道具基础名、79 个词缀和 7 个装备/诅咒状态。基础名优先采用 `localization/glossary.csv`；未收录的普通装备、魔杖和法杖名称作为本批译名记录在 [批次清单](../../localization/manifests/phase3-static-04.json)，未擅自修改术语 CSV。`staff` 使用“法杖”，与 `wand` 的“魔杖”及技能“棍杖”区分。

已接入背包与使用普通 InvEntry 的拾取/丢弃列表、物品详情标题/摘要、武器 HUD、角色创建武器选项及旧武器快捷项。物品数量使用 `数量 × 名称`，强化值、已知词缀、魔杖剩余充能、装备/融合/诅咒状态和铭文均保留。HUD 仍依据原逻辑调整腐蚀后的强化值。

英文 `item_def::name()` 及其生成逻辑未替换。显示入口先核对鉴定状态，再读取类型与词缀；未鉴定物品、神器、特殊混沌/复制品、未支持类别或缺少任何所需译文时返回失败，由调用处保留原英文名称。失败不改写输出参数，不透露隐藏类型，不省略未译词缀。

背包 `text`、全名/数据库名缓存和排序键继续保存英文。原有配色规则仍匹配英文，中文显示不使已有规则失效；筛选保留英文并附加中文显示名。用户铭文及原有来源元数据原样保留，其中的命令保护标记也保留。

尚未接入的专用入口包括已知/未知物品大全、商店和获取菜单等派生菜单；神器、法术书、尸体、杂项唤发物等复杂名称也不在本批界面命名范围。动态战斗/装备消息仍可能使用英文名称，未将中文名称塞入已有英文句子。

## 回退与验证

- 英文模式在界面命名入口立即退出，调用原英文生成逻辑；中文缺译同样整项回退。已有动态模板组回退、TextDB 来源/依赖指纹检查和递归英文回退保持有效。
- C++ 本地化测试 9 个用例、1410 项断言通过，包括数量、强化值、词缀、充能、铭文、未知类型保护、未译词缀回退、英文搜索与排序键、派生菜单附加文字的筛选，以及英文模式原有输出。
- gettext 目录测试 8 项、TextDB 测试 5 项、Lua 执行分支 11 个通过。659 条逐行记录与当前来源及 PO 匹配，术语表指纹未变，重复导出结果一致。
- Windows Tiles 已重新编译。使用独立测试角色观察中文背包的战斧/鳞甲/小盾、装备状态、武器 HUD、战斧中文详情和中文创建武器选项；另观察英文背包、原冠词/装备状态与 HUD。没有将这些代表性画面等同于所有新条目的 GUI 全量验收。

检查结果与程序指纹见 [验证记录](phase3-static-04-checks.json)。重启游戏可加载新程序及数据，使用 `language = zh`；改为 `language = en` 后重启恢复原英文。此前审查列出的 19 个未接管旧中文文件仍须后续校对，并不具备全量来源变更失效保证。
