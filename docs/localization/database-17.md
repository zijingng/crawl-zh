# database 第十七批：神祇对白全文件校对与梦羊逃跑消息

本批处理 **196 个键、575 个候选**：`godspeak.txt` 全部 193 键、`monflee.txt` 的 1 键，以及辛对白需要的 2 个 `monspeak.txt` 共享词库。其中 124 键复核并复用此前源码批次登记的佐姆译文，其余条目对照当前英文补译或重校。英文原始数据文件均保持不变。

翻译前逐项查询术语表，含规范神名、种族、怪物、技能和普通词语境，见 [预查记录](database-17-preflight.json)。使用“卢戈努”“奥格瓦如”“阿斯卡亚”“胶怪”“梦羊”“力场长枪”“法则公理”等现行译法；普通 light、pain、spirit 等词不机械套用装备或法术专名。

## legacy 校对结果

- 比欧弗欢迎语改为“向世界展示何为兽人！”，移除旧版“把不信教者淹死在血海里”的过时内容。
- 迪斯姆诺欢迎语按当前英文译为“行于黑暗之地”；奇库巴库哈欢迎语恢复“毁灭与绝望”，不沿用旧版“折磨和黑暗”。
- 补齐比欧弗使徒挑战的三段对白，以及马科列布刽子手的五个候选。
- 统一卢戈努、奥格瓦如、阿斯卡亚等神名；吉瓦死亡消息中的 jelly 使用“胶怪”。
- 伊莱德莱姆努尔非生命死亡消息按“身体消失在暗影烈焰中”重译，移除“化为黑色火炬的燃料”的旧解释。
- 修正佐姆召唤对白中 serve 的含义、礼物句中的遗漏、力场兵团的“原力”误译，以及混用的英文叹号。
- 重新处理佐姆对孩子的戏谑称呼，使“私生子”“继子”“浪子”等候选组合成完整中文；保留其讽刺口吻。鳟鱼候选与现行英文一一对应，补上旧库漏掉的 moist。
- 梦羊使用“咩叫”，保留四条 `VISUAL:` 控制前缀及原权重，不把控制标记翻译成正文。

生成文件由本批正式接管，神祇对白 193／193 键、逃跑对白 1／1 键完成数据审核。与修改前的中文快照相比，神祇文件有 160 个导出条目新增或变化；移除上游已不存在的 `Xom scenery` 和 `Xom draining or torment` 两个旧键。具体范围见 [审核清单](../../localization/manifests/database-17.json)。

## 显示与英文回退

受管理的神祇对白从规范英文库按原权重选择一次，再查询同一正文对应的译文。单独记录受管理的规范键，避免源文改变后，查询又退回旧中文数据库。英文模式及显式请求原文的调用继续使用原先英文路径。

原有比欧弗挑战和诵经结束消息按已选中的完整段落查询，本批同步校对其已有 `g.challenge`、`g.recite.closure` 译文。欢迎、惩戒、死亡消息等沿用原有调用点。梦羊逃跑消息传递配对文本到现有怪物显示函数，同一次选择取得原始怪物及中文名称；缺少参数译文时整句英文回退。

辛的 `_important_subject_` 和 `_axioms_of_law_` 只登记到严格 UI 目录，没有生成局部 `zh/monspeak.txt`。这样不会让尚未审核的其他怪物英文句子，递归取到零碎的中文词组。

`_xom_plaything_` 是按虔诚等级返回称呼的 Lua 程序。本批保持原程序和英文返回值，仅执行一次；涉及它的候选仍整句回退英文。未将旧中文 Lua 直接作为已审程序重新启用。因此，193 个键完成数据审核不等于每个动态分支都已能显示中文。其他不透明身体部位、未审子条目仍遵循整句回退。

原文、权重、段落边界、引用标记和方括号候选顺序均有校验。跨文件颜色、涂鸦及内部称呼的引用记录精确哈希依赖；子条目变化时，其旧译与父句一并停止导出。源码依赖仅刷新与修改前快照精确匹配的记录。

## 验证

新增原生测试遍历全部 193 个神祇键，每键 64 个种子，对照原始英文、后续随机状态和 Lua 执行次数；覆盖不同虔诚等级，以及实际 `getSpeakString` 调用路径。梦羊以 256 个种子覆盖五个候选，核对怪物名、视觉前缀、双语输出和随机状态。另检查过时旧译及缺失引用的回退。

在临时数据副本中修改佐姆孩子词库，确认父级稀有欢迎语、普通欢迎语和无聊消息依次失效，其他神祇欢迎语不受影响。工具测试、Windows Tiles 编译及原生回归结果见 [检查记录](database-17-checks.json)。未进行实际游戏窗口视觉验收。其他 `dat/database` 文件仍需继续审核。
