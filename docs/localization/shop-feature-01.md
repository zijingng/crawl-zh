# 商店发现数量与入口描述

发现日志中的“40处”来自把 `DNGN_ENTER_SHOP` 地形编号存进了显示适配使用的数量字段。现改为实际单店数量 1；多个商店仍沿用已有列表和数量汇总逻辑，英文发现日志不变。

商店入口的中文适配原先只查询固定地形词，无法命中含随机店主名的完整名称。现根据当前位置的真实商店数据复用 `shop_name` 显示参数；保留店主专名，翻译商店类型和后缀。若原始地形描述与商店规范名不一致，或自定义商店类型未翻译，则拒绝适配，整句回退英文，不解析随机店名。

新增测试使用 `Iloema Urghi` 的古董防具商店，实际调用 `found_feature()`、`stop_explore()` 和 `describe_floor()`，检查无伪造数量、中文入口、英文模式、未知商店类型整句回退及随机数状态不变。术语查询与源码依赖记录见 `shop-feature-01.json`；英文商店规范名与配置、存档均保留。尚未进行游戏窗口中的手动复测。

发现日志仅在 `crawl_state.io_inited` 后读取真实窗口列宽，防止无界面日志路径访问未初始化的 Tiles 区域。正常游戏仍沿用原有宽度判断与汇总逻辑。

最终 Windows Tiles `crawl.exe` 编译成功。144 个本地化测试全部通过，共 254,295 条断言；日志为工作区 `.term-audit/shop-feature-01-final-build.log` 和 `shop-feature-01-tests.log`。
