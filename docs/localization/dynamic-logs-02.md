# 动态日志第二批：投射物、法术与发现提示

基线 0.34.1；分支 `stone_soup-0.34.1-zh`。参照现有 1413 条术语表，审核 496 个上下文／英文组合：新增 494 个，更新 2 个。译文与源指纹记录见 `localization/manifests/dynamic-logs-02.json`。

## 覆盖范围

- 光束、投射物的常规命中、未命中、抵挡、偏转与零伤害提示，包括对应的攻击动词、弹药名称和法术效果名称。
- 施法、云雾、自我强化、投掷、休息等流程中的 105 条固定日志，以及 70 条怪物状态事件模板，包含伤口、毒素和身体变化等所有格表达。
- 怪物首次进入视野、休息或旅行中发现怪物、成组怪物计数，以及常规可见装备提示。复核 86 个独特怪物称号，名称优先参考术语表及现有名称目录。
- 多件地面物品列表及其标题，保留原来的颜色匹配、数量和未鉴定物品信息边界。

上述数量包含名称及模板，并不等于 496 条独立游戏事件。具体分类和校验结果见 [检查记录](dynamic-logs-02-checks.json)。

## 英文回退与上游同步

保留原来的英文消息生成路径、规范物品名、投射物名、怪物标识和伤害归因。中文从原始对象生成显示名称；模板、名称、动词或装备组件中任何一项不可用，就使用整条原始英文消息。英文模式不经过中文拼接。

发现怪物的英文回退文本在中文模式下明确读取英文称号库，避免旧版中文 TextDB 污染回退结果。中文称号使用已审核的稳定键，不重新随机选称号。核对了本批 86 个称号及其已有中文对应条目均为单一普通文本候选；仍使用原有的一次随机选择，未额外消耗随机数。英文模式保持原有数据库读取方式。

消息保留频道、可见性、装备筛选、物品颜色和数量判断。未鉴定物品使用外观名称，不暴露真实种类。新增代码依赖指纹随构建核对；源码或称号定义变化后，未经复核的译文停止导出并回退英文。第一批受共享辅助代码影响的条目也已重新核对指纹。

## 验证与剩余范围

Windows Tiles 的 `crawl.exe` 编译通过；本地化 C++ 测试通过 21 个用例、11209 条断言，Python 检查通过 22 个测试。覆盖英文模式、缺译时输出不变、未鉴定外观、列表失败时整条回退、规范名称及随机数状态保持等情况。没有进行本批 GUI 实玩、换行和截断检查。

以下情形仍保留原始英文：混沌光束的复杂命中效果、反射的实体投射物、带盾牌名称的部分光束反射、深渊随机刷怪叙述、特殊装备或自定义怪物无法完整表达的发现消息。怪物吟唱／施法的 SpeakDB 语音、部分辅助近战和背刺、合并物品拾取等也尚未全面覆盖。
