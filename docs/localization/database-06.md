# database 第六批：武器噪声与唱歌剑基础词库校对

本批逐项校对 `database/wpnnoise.txt` 的 20 个 legacy 键、108 个候选，未新增英文键。范围是铜锣盾、`frozen axe "Frostbite"`（「寒噬」冰斧）、三叉圣戟「定罪」的声音，以及唱歌剑引用的 17 组基础词库。翻译前按完整单词边界检索术语表，命中及术语表哈希保存在 [预查记录](database-06-preflight.json)。音乐语境中的普通词不套用装备属性或法术名称。

主要修正：

- 「寒噬」的风声、风暴两组随机选项恢复为原文的 4／3 顺序；「定罪」的吟诵、形容词及其他随机组同样逐组对齐，避免相同随机索引选中不同含义。
- `fountain of blood` 按术语表统一为“血喷泉”；`Barachim` 使用“蛙人”。
- `Aeolian mode` 改为“爱奥利亚调式”，区分旧译所指的伊奥利亚调式；`counterpoint` 为“对位法”，`voice harmonics` 为“人声泛音”，`time` 在音乐语境为“节拍”。
- 补正 `hairy skin`（长毛的皮肤）、`thrilling`（惊心动魄的）、`spanking`（此处为绝妙的）等含义。音阶片段仍使用“五声／半音／自然”，由上层句子提供“音阶”，避免重复。

## 数据与显示边界

译文同步到 `textdb.po`、`ui.po` 和中文 `wpnnoise.txt`；[本批审核清单](../../localization/manifests/database-06.json) 保存每条源文和译文哈希。英文文件按字节保持不变，权重、引用、方括号组的先后次序及各组选项数量均经过核对。其余 45 个键的正文与本批基线一致，其中包括上一批已审的 19 个键。

累计 39／65 个键完成这两批审核，仍有 26 个 legacy 键待审，清单中逐项列出。主要包括唱歌剑的完整对白、歌曲及普通聒噪武器消息；不能把中文文件已有 65 个键当作全量校对完成。本文件仍不交给整文件导出器，避免删除未审条目。

**本批完成数据校对，未完成 `item_noise` 的严格双语显示适配。** 新的严格配对目录保留原文精确匹配和源文件哈希保护，但旧武器噪声调用仍走原有显示路径。后续需要同时处理武器／玩家／神祇／种族占位符、消息频道及原有随机调用，验证缺组件时整句回退英文。17 组片段与尚未审核的上层句子的整体语序，也须在该阶段联合校对；本批不宣称唱歌剑已完整显示中文或整个旧路径已具备严格回退。

## 验证

检查覆盖 20 条 PO 与数据一致性、108 个候选的权重和引用、方括号组顺序、原文变化后的精确匹配回退，以及 20 条依赖哈希失效时全部拒绝导出。另运行翻译工具测试和原生本地化回归测试，并编译 Windows Tiles `crawl.exe`。结果见 [检查记录](database-06-checks.json)。未进行游戏窗口视觉验收。
