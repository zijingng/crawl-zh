# HUD 标签使用全称

共享目录中的 HUD 标签改为护甲、闪避、格挡、等级、力量、智力、敏捷。保留原有英文键和标点结构，英文配置及缺失译文时仍返回原英文标签。WebTiles 继续通过现有 `ui_text` 获取同一份译文，不增加另一份网页中文词典。现行术语表及对应早期审查记录同步更新。

本地标准布局原先按英文标签固定数值列，中文全称可能覆盖数值或在清空旧数值时擦掉相邻的厄运／污染标签。现在按实际显示宽度确定护甲、闪避、格挡和基础属性的数值起点，并限制清空范围。等级行避免末尾空格侵入右侧地点列。英文原有列起点保持不变；既有触屏紧凑布局仍保留其独立布局规则。

验证使用实际 WebTiles 模板、样式、options/player 模块和生成目录，在真实浏览器内核中切换中文与英文。七个标签、三位数防御、等级及进度、厄运和污染均在对应行内，无标签数值重叠。原生测试确认七个全称和英文回退，21 条断言通过。Windows Tiles `crawl.exe` 已成功构建；本地实际游戏窗口显示可继续人工验收。检查数据见 [记录](hud-full-01-checks.json)。
