# h 开头核心源码显示适配

基线：0.34.1。日期：2026-10-23。

本批排查 `crawl-ref/source` 原有的 7 个 h 开头 `.cc/.h` 文件，新增私有显示实现 `hints-display.h`，共接入、校对 216 条译文。译前术语命中和原文件指纹见 `source-h-01-preflight.json`，逐文件范围见 `source-h-01-files.json`，目录和验证结果见 `source-h-01-checks.json`。译文及依赖清单为 `localization/manifests/source-h-01.json`。

## 新手提示

- 新手角色选择、退出和随机角色按钮，以及种族、背景和定位说明。
- 初次看见怪物、物品、祭坛、楼梯、传送门和门的说明或地图标签。
- 休息提醒、技能训练、花费、目标、能力菜单及法术库帮助。
- 返回游戏时的界面检查列表，以及逐出教门、放弃或改换信仰的动态段落。
- 武器、防具、投掷物、魔杖、卷轴、首饰、药水、手册、魔法书、尸体、法杖和杂项物品的操作提示；包含装备能力、抗性、技能建议和瞄准操作。
- 地形、云雾、怪物危险程度、盟友、狂暴、移动禁区和撤退建议。

名称从原始对象、种族/背景/技能/神祇枚举和现有显示适配器取得。快捷键沿用当前命令绑定，不写死替代键。术语按译前命中使用“防具、躯干防具、身甲、盾牌、施法、天资、塑能师、猎手、娜迦、犰狳人、移动禁区”等。

复杂物品、法术库、地形/云雾和信仰提示先执行原有英文构造，中文只读取相同状态生成显示段落，不再次触发事件、游戏效果或随机选择。一个段落缺少任何必要译文或名称时，丢弃中文候选并保留完整英文。静态怪物说明和初遇怪物说明也按组检查，避免半段中英混排。

## TextDB 参数与回退

`getHintString` 新增可选的原文请求和实际所选语言回报，原有调用方式保持有效。数据库别名最终回退英文时，会报告实际采用英文；怪物名、神名等参数随后选择相同语言。英文模式可以绕过已打开的翻译库。正文只查询、展开一次，不为生成双语重复执行嵌入 Lua。

已有 hints/tutorial TextDB 继续使用原数据库键与中文目录。本批未用源码覆盖这些数据。

## 高分界面

原生高分菜单和结束画面显式请求显示版本。默认 `hiscores_format_single`、`hiscores_format_single_long`、`hiscore_line` 仍保留英文，命令行输出、分数文件、日志字段、里程碑和 Lua 语义不改。

显示层覆盖标题、空列表、角色种族/背景/称号、信仰、常见环境结局、通关与离开地下城、符文/宝石统计、地点、日期、游戏时长及回合数。称号由记录中的技能等字段重新取得候选，并核对是否仍与记录的英文称号一致；无法核对时使用完整英文回退。

**历史高分记录的限制：**凶手、武器、部分法术、召唤链和自定义地图说明保存的是已经拼好的英文，缺少重建中文所需的原始对象和类型信息。因此这些完整杀因或地点段落仍显示英文；本批没有从英文冠词、所有格或句子中反推实体，也没有为了显示中文删去凶手、武器、伤害或召唤来源。短行中的角色和分支缩写仍作为原有记录标识保留。若后续需要让这些历史动态杀因全部显示中文，需要另行设计可持久化的类型元数据。

- Python 本地化工具测试：27 项，全部通过。
- 本批 216 条译文与 PO、生成目录及清单一致；全局依赖无过期指纹。
- `git diff --check` 通过。

新增回归覆盖提示快捷键、切回英文、提示事件和随机状态不变、缺少名称时的整段回退、TextDB 别名实际语言、高分默认英文接口、旧杀因完整保留，以及符文和宝石数量。

本批未做游戏内视觉验收，只构建 Windows Tiles。调试与技术诊断、配置键、枚举标识和序列化字段保持英文。
