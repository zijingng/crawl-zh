# 天资表与游戏手册

本轮覆盖游戏帮助中的 `?%` 技能天资表和 `?*` 游戏手册。手册正文 A–N、附录 1–6 全部翻译，包括种族、背景、技能、按键、题词和冲刺模式；保留配置项、可输入的英文搜索示例、网址和规范缩写。

翻译前查阅当前术语表，并对照已有游戏模式、技能名称、帮助菜单目录和按键译文。预查记录包含 296 条原文命中和 39 条既有翻译参考，见 [预查记录](manual-aptitudes-01-preflight.json)。沿用“地下城冒险”“选择地图种子”“地下城冒险教程”“提示模式”“备选动作”“自动战斗”“题词”等现有用词；技能天资按术语表使用“技能天资／天资”。

天资表翻译说明、种族名和表头，短标签在前文解释其完整技能名，并保留对应英文缩写。按中文显示列宽排版，逐行对照原表，105 行、1,155 个数值与顺序全部不变。手册最长 78 显示列，天资表最长 76 显示列，并处理中文标点落在行首的问题。

## 英文回退与维护

英文 `crawl_manual.rst`、生成的英文 `crawl_manual.txt` 和 `aptitudes.txt` 保持原样。两份文档沿用已有 `help.document` 整文匹配机制，译文只维护在 `localization/zh_CN/ui.po`；`help-documents.json` 登记已审原文，由现有工具导出 `crawl-ref/docs/zh/` 文件，不另维护第二份人工译文。

选择英文时直接显示英文。原文变化、缺译、fuzzy 或未审时，整份文档回退英文，导出工具也会以当前英文覆盖过期导出物。没有按句替换英文，也没有改动配置、搜索或存档的规范键。

原帮助界面在读英文时记录章节行号，替换整份中文后仍使用英文位置。本轮改为从最终显示的文档提取章节位置，语言切换继续清理缓存；目录和正文使用相同的 A–N、1–6 按键，20 个章节都可正确跳转。

编译还发现手册的 `??` 按键示例会触发 C++11 三字符转义。目录生成器现在对问号作 C++ 字符串转义，保留原始字节，避免整文键匹配失效，并覆盖全部九种三字符序列的回归检查。
