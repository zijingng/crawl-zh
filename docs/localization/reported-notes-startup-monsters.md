# 初始配置、动态怪物及入口 note 补全

初始装备／法术记录的两条生成路径现在提供事件时中文回调，复用现有物品、已记忆法术及法术库显示接口。玩家名保持原样；任一必要名称缺译时整条回退英文。英文正文及其生成顺序不变。

遇见、击败和盟友死亡记录使用事件中的 `monster_info(..., MILEV_NAME)` 生成名称，保留海德拉头数、亡灵形态和专名；魔窟领主继续使用已审角色模板。击败事件不能使用会检查当前可见性的通用日志接口，否则死亡怪物可能被误显示为“某个东西”。变形事件在变形前生成旧名称的显示值，在记录时组合新名称；不持久化怪物快照。已知变形怪的附加身份也使用既有名称译文。尚无完整短传记显示适配的玩家幽灵遭遇记录仍整条回退。

低 HP 记录补充固定 beam 原因“钻心剧痛”“心灵爆破”“恶意献祭”“燃烧吐息”，并对有限的规范小写法术标题使用既有法术译名，覆盖驱散亡灵、吸血等来源。未知来源继续完整英文回退。入口名称增加术语表已有的“通往市集的忽隐忽现的入口”，复用原有 `set_terrain_seen()` 事件回调；没有新增 TextDB 重复正文。

这些修复只影响新事件。旧 note 已保存的正文不重译，也不恢复旧快照兼容。

Windows Tiles `crawl.exe` 与测试程序编译成功；16 项定向原生用例、2,121 条断言通过，包括真实海德拉击败、市集入口发现、低 HP 原因、双语记录保存与死亡记录回归。已审译文依赖失配为零，`git diff --check` 通过。未执行完整原生套件或 Linux WebTiles 编译。
