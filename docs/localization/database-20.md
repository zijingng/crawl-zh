# database 第二十批：溶解者、唐纳德与尤夫补充对白

新增 **58 个键、572 个候选**，完整接入本段唐纳德的分支、信仰、通用及特殊对白，并补齐疯子尤夫和溶解者。本文件累计已审 **287／731 键**，剩余 444 键保留英文。

翻译前查询术语表，另查复合专名及单数形式，记录见 [预查清单](database-20-preflight.json)。沿用半人牛、水银龙、尖啸折光体、诅咒头骨、诅咒脚趾、武剑会等译名。分支 Tomb 使用“灵庙”，普通 mausoleum 使用“陵墓”；神话中的美杜莎不套用水母形态名称。唐纳德的抱怨、反话及双关按上下文翻译，保留随机选词和语气。

本段此前没有可用的已审中文，依据当前英文补译。旧版信仰 Pakellas 等条目仍存在于当前原文，保留规范键并翻译对白；不因机制已退出游戏而删除。此前 229 个已审条目逐键、逐正文比较，全部保持不变。没有启用未审 legacy 覆盖层，也没有把尚余 444 键标成已审。

复用既有双语配对选择与参数替换，本批没有修改英文数据库、选择器或参数替换源码。中文仍单独存放于 PO 和生成的语言目录；英文模式继续使用原逻辑，译文、原文指纹或依赖不满足时回退英文。候选数量、权重、引用、消息前缀和随机选项结构均保持一致。

累计 287 个键的 PO、导出正文和实际 SQLite 英文正文均已校验。临时修改唐纳德的共享通用对白，确认该键及引用它的分支、信仰、友好对白全部拒绝旧译，其他独立条目保持有效。原生测试覆盖每键 64 个种子，并新增唐纳德、溶解者的实际对白选择回归，比较英文结果及后续随机状态。
