# 动态日志第一批：战斗、物品与法术

基线 0.34.1；分支 `stone_soup-0.34.1-zh`。按当前 1413 条术语表审核，保持 README 中“英文原文与生成逻辑保留，缺译时整句回退”的方针。

## 本批覆盖

- 玩家与怪物的近战命中、零伤害和未命中；使用已经选好的攻击动词、程度、远距离、武器与附加电击状态生成中文，不额外抽取随机攻击动词。
- 玩家击杀、摧毁和炸飞目标；怪物死亡、受伤程度及常见状态消息，保留原来的可见性条件、消息频道和伤害参数。
- 常规新物品拾取、实际丢弃数量、单件地面物品提示、书籍和手册拾取，以及怪物放下物品。库存拾取日志保留栏位字母。
- 施法预告、失败风险与施法失败，另覆盖伤害、召唤、位移等文件中的一批常见过程与结果日志。
- 从术语表导入源码中的全部 511 个法术显示名，补齐此前只在术语表里、尚未接入显示目录的名称；怪物专用、内部和旧版兼容名称仍不等于玩家可学习法术。

## 英文回退与状态保护

1. 英文模式继续使用原有命名、冠词、动词变化及句子生成分支。中文名称接口不写回物品、怪物、法术的规范名称，也不参与数据库、存档及脚本查询。
2. 中文整句需要模板、实体名称及必要的动词／程度全部可用；缺少任一部分则执行原有英文分支。不会把中文名称塞入原有英文冠词或所有格表达式。
3. 近战命中与未命中的中文和英文分支共用实际英文格式模板；伤害、距离、附加电击等沿用相同游戏状态，怪物随机攻击动词只选一次。原有攻击类型和伤害结算不变。
4. `simple_monster_message` 只对已审核的完整事件模板和标准名称描述启用中文。所有格、特殊描述及未知事件继续英文；原有可见性判断和消息频道保留。
5. 中文掉落名使用带实际数量的物品副本，不修改原物品数量、鉴定标记、充能或装备状态。未知药水等仍只显示已知外观。
6. 复杂日志除了英文键匹配，还记录相关 C++ 源码依赖指纹。代码发生变化时，目录生成器不导出该条，保留英文分支直到重新审核。Makefile 已将依赖源码列入目录生成目标，确保修改代码会触发指纹复核。这个保护采用文件级指纹，可能保守地让同文件中更多日志回退。

译文保存在 `localization/zh_CN/ui.po`；[批次清单](../../localization/manifests/dynamic-logs-01.json)记录英文、中文、来源、分类及代码依赖。[检查记录](dynamic-logs-01-checks.json)保存实际验证结果。

## 尚未覆盖

本批并非全部动态文本。远程投射物与光束的复杂命中句、附加攻击、潜行背刺、格挡、特殊神器及部分变形的专用动词、带参数的怪物施法与技能日志、自动合并拾取的数量／充能变化、多个地面物品的汇总标题等仍可能显示英文。自定义怪物名及未支持物品外观也可使整句回退英文。

本批未进行游戏窗口逐屏试玩和日志换行排版验收。
