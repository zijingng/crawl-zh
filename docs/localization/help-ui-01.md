# 游戏内帮助补齐第一批

此前只接入了独立文档中的快速入门和宏指南；`dat/database/help.txt` 的上下文帮助也不等于 `?` 帮助菜单和主手册。此前“帮助已翻译”的表述范围过宽。

## 本批内容

- 帮助首页、主手册目录、页面标题和常见问题标题。
- 普通模式与提示模式的按键列表。
- 查看周围和选择目标的按键说明。
- `T` 的 Tiles 操作文档全文，含移动、物品、角色外观和性能设置。

新增 160 条 UI／整文档译文，优先沿用术语表的技能资质、导航点、变形护符、棍杖和佐特宝珠等译法。原文及译文记录在 [批次清单](../../localization/manifests/help-ui-01.json)，译文源为 [ui.po](../../localization/zh_CN/ui.po)。独立文档导出到 [tiles_help.txt](../../crawl-ref/docs/zh/tiles_help.txt)。

## 接入与回退

`command.cc` 在填充实际按键绑定之前查询帮助模板译文；`%` 是游戏自身的按键占位符，保留数量和顺序，不当作 printf 格式处理。保留字符版专用标记、颜色标签、地图字形和方向示意图。英文模式仍使用原文和原有按键填充逻辑。

整文档继续按完整英文原文匹配；原文发生变化时整篇回退英文。帮助缓存增加语言变化后的失效处理，避免在同一进程切换语言时沿用上一种语言的文档。

## 验证与剩余范围

Windows Local Tiles 编译成功。C++ 本地化测试 15 个用例、9258 项断言通过，Python 回归测试 18 个通过。核对本批 160 条译文与原文哈希，确认三个原有帮助生成函数的英文字符串未改动；整文档测试覆盖快速入门、宏指南和 Tiles 三份文档的整文匹配及英文回退。见 [检查记录](help-ui-01-checks.json)。

实机已观察到中文帮助首页和目录；其他页面尚未完成逐屏视觉检查。

**尚未翻译完整正文：** `*` / A–N / 1–6 对应的 `crawl_manual.txt`、`&` 对应的 `options_guide.txt`，以及 `%` 资质表中的英文图例。目录翻译不代表这些正文已翻译。Wizard 调试专用瞄准帮助及版本、诊断细节仍为英文。

测试时应重启更新后的 `crawl-ref/source/crawl.exe`，使用 `language = zh` 的配置。游戏内按 `?` 打开帮助，帮助页再按 `?` 查看命令，按 `T` 查看图形版操作说明。
