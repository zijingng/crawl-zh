# 第 6–17 项漏译反馈

翻译前核对现有术语及 UI／TextDB 词典。正文继续只维护在 textdb.po；本轮新增 13 个类型参数或 UI 提示，未复制怪物对白或施法正文。术语预查及代码来源见 reported-06-17-preflight.json。

| 项目 | 原因与处理 |
|---|---|
| 6 卡珊德拉尸体 | 原来将尸体姓名一律视作自由文本。现在仅当 orig_monnum 为已知独特怪物，且尸体名严格等于该怪物的规范英文名时，调用怪物名显示接口。自定义姓名、玩家姓名及尸体属性不变。 |
| 7 One-of-a-Kind Rings | 增加自定义店类 One-of-a-Kind 及 Rings／Books 后缀参数；店主 Oxtytz 保留规范拼写，店名显示为独一无二戒指店等。未知店类或后缀仍回退英文。 |
| 8 力场长枪击退 | 补齐 a.knockback.cause 的 lance of force 参数，复用既有完整击退句式。 |
| 9 横冲直撞进入火焰云 | p.move 缺少 rampage 参数；按术语表补为横冲直撞进入，仍使用原有火焰云确认模板。 |
| 10 沼泽传送陷阱 | 调用了没有条目的 display.branch；改为实际维护的 b.branch.name，覆盖同类恶意力量提示。规范分支名及陷阱逻辑不变。 |
| 11 鬼火召唤沼泽幽光 | 补齐共享召唤提示使用的 marshlight 参数，依 Marshlight 术语译为沼泽幽光。 |
| 12 沼泽树精喷射木屑 | 补齐施法短名 splinters 和 metal splinters。通过已有共享怪物施法替换器显示，不按怪物名称添加特例。 |
| 13 森林停止活动 | 现有译文放在 m.ui，实际 forest_message 查询 s.forest；补齐正确上下文，并覆盖森林平静及开始活动的提示。 |
| 14 冰龙鳞可穿戴 | 掉落提示发生在正式鉴定标志写入之前，完整物品显示可能因未鉴定外观缺项回退。提示现在只使用已经可见的基础防具种类，不改变鉴定标志，也不提前显示附魔值。 |
| 15 摇曳的毁灭之球 | 补齐完整投射物名 wavering orb of destruction；继续由共享命中、动词及中文标点路径输出。未知投射物仍完整回退英文。 |
| 16 玛格丽双眼发光 | 当前 _Margery_common_ 和 _spell_colour_ 已有已审译文。实际配对读取、颜色展开及 do_mon_str_replacements 测试可输出玛格丽的中文双眼提示，本轮未复现该片段自身缺译，未重复添加正文。需以本次生成的可执行文件实机验证。 |
| 17 地狱象吐息 | 补齐共享施法短名 flames 为火焰，覆盖使用此短名的其他怪物，不只对地狱象单独修补。 |

## 保持英文回退

不改写怪物、尸体、物品、商店和投射物的规范英文名称；尸体姓名、店主名、鉴定属性及随机状态保持不变。必要模板、参数或类型信息缺失时，仍返回完整英文。新词只加入 UI 类型参数，不将未审内容写入 TextDB。

## 验证

Windows Tiles crawl.exe 编译成功。32 项 Python 工具测试、5 项相关原生回归通过，共 197 次断言，约 0.13 秒。

覆盖卡珊德拉尸体与同名自由文本的区别、特殊商店及未知后缀回退、击退与云确认、分支名、龙鳞不泄露 +7 附魔值、毁灭之球命中和未知投射物回退、玛格丽眼睛消息、英文切换、物品身份与随机状态。原有怪物正文仍导出 731 键、施法正文仍导出 262 键。没有运行耗时的全部怪物对白随机矩阵，也没有做游戏窗口实机目测。结果见 reported-06-17-checks.json。
