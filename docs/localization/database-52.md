# database 第 52 批：随机主题及佐姆书名显示

本轮接入 random_book_title 和 Xom_book_title 的显示程序，共 19 个顶层加权候选；没有新增或重复维护译文。翻译与适配前核对术语表和已审 TextDB，见 database-52-preflight.json。英文及中文 randbook.txt 字节均与本轮开始时相同，仍为 72／72 键数据已审。

## 接入内容

普通随机书名支持植物、动物、职业、数量限定词、哲学与科学、奇异防具词组、命运、地点、魔法、物质和力量等主题。佐姆书名额外支持混沌、游戏、政治、苦难与无为、武器不适词组，以及当前玩家姓名加 killer_name 的称号。

仍由上游英文路径生成一次完整名称并保存。显示时按已审英文模板匹配缓存名称，中文词组从对应 TextDB 候选读取，不重新执行随机选择，不修改名称、物品属性或保存身份。重复引用按出现顺序处理。

普通主题可用于无作者或已知作者的 Book of 形式；佐姆专属主题只在作者为 Xom 时启用。玩家姓名称号只接受当前玩家的规范拼写，后缀译文来自已审 killer_name，不猜译其他人的姓名。既有学派主题的完整匹配仍优先。

未知主题、未知作者、缺少已审子条目、无法唯一匹配以及递归或工作量超限时，保留完整英文。没有把书名中的任何片段做全局替换，也没有把神器专用语法放宽成任意书名语法。Annotations on 等非随机书名结构不因此接受普通随机主题。

## 展开核对与集中测试

离线展开全部已审引用：普通主题有 7,545 个不同英文名称，佐姆主题在测试玩家名 Ceneedgh 下有 7,683 个，均未发现同一英文名称对应多个中文结果。佐姆数量包含普通主题，不能将两者相加作为新增条数。没有将该展开表加载到运行时；它仅作为开发核对记录。

Windows Tiles crawl.exe 编译成功。32 项 Python 工具测试和 5 项相关原生回归全部通过，共 26,092 次断言，原生测试约 2.234 秒。

原生测试覆盖全部 19 个顶层候选、动物与植物引用的首／中／尾样例、所有玩家姓名后缀、作者限制、实际魔法书显示、缓存英文名称、英文模式和后续随机状态；同时回归固定等级和学派书名。没有对全部离线展开名称逐个运行原生矩阵，也没有进行 GUI 目视测试。

详见 database-52-checks.json 和 database-52-expansion-checks.json。规范随机作者姓名仍保留英文；未知作者的整本书名仍回退英文。dat/database 的数据审核覆盖不等于所有上层调用及复杂神器组合均已接入，后续应继续按实际游戏显示缺口检查。
