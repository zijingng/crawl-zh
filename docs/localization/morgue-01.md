# morgue 双语生成与英文回退

本轮接入中文 morgue 的实际文件生成，并继续覆盖角色记录显示。翻译前查阅术语表与已有 `c.dump`、技能、形态、神祇、物品及记录译文，新增 46 条已审消息：34 项神祇行为标签、死亡记录措辞、文件提示、地点与记录表头。预查材料见 [术语与历史译文](morgue-01-preflight.json)。

## 输出路径

中文模式下，原本生成 `morgue-名字-时间.txt` 的操作，现在同时生成：

- `morgue-名字-时间.txt`：保留原路径的英文生成结果。
- `morgue-名字-时间.zh.txt`：UTF-8 中文记录。
- 原来的 `.lst` 物品清单继续沿用原路径与英文生成方式。

手动导出角色记录时，同样是 `名字.txt` 和 `名字.zh.txt`。输出目录仍由现有 `morgue_dir` 配置决定；不新增目录配置。英文模式只生成英文文件。C++ 的 `dump_char(..., localized=false)` 可以明确只生成英文文件；`character_dump_text()` 继续返回英文，显式传入 `true` 才返回本地化展示。

中文附加文件写入失败会报告错误，已经生成的英文记录仍保留，英文导出成功的返回值不受影响。

## 本轮覆盖

复用既有显示适配，而非另写一套物品或怪物翻译：

- 标题、种子、角色属性与抗性、地点、信仰、金币、探索次数。
- 物品类别、名称、装备标记、来源及神器说明。
- 技能、已知法术、法术库、学派及剩余法术容量；补充死亡时态，并区分容量为零的“无法再记忆”。法术名或学派缺译时，整行使用英文生成。
- 当前形态、变异、击杀、地下城概览、死亡成绩和可见怪物；使徒使用已有显示接口。
- 回合、经验、击杀、虔诚与行动统计。地点列、行为列、记录续行按显示宽度排版。
- 历史变形次数仅按已记录的形态类型显示静态名称，不读取当前形态的临时加成。

## 英文路径与状态隔离

`_get_dump` 的默认路径继续生成英文，并在作用域内暂时切换英文语言和 TextDB 语言选择。退出后恢复原配置。它覆盖嵌套的角色概览、变异、怪物、笔记等函数，避免中文界面渗入英文生成路径；记录正文的英文路径使用 `Note::describe`，中文路径才使用 `display_describe`。

英文和中文使用相同角色数据、鉴定状态及 `full_id` 条件。原本只允许死亡后或特殊情况下导出的信息，继续遵守原有条件；不修改物品身份、能力键、法术键、统计计数、分支键或存档内容。

中文文件直接写 UTF-8，不经过用于终端字符集转换的 `OUTS` 宏。原英文文件仍沿用原来的写入逻辑。

自定义 Lua 段落先按原顺序执行并缓存结果，中文附加文件复用结果，避免执行两遍。即使同一回调在 `dump_order` 中出现两次，也保留原有两次调用，而非增加到四次。

缺少模板或必要的动态名称时，保留相应原英文表达。不从已拼接的英文句子反推中文。

## 历史文本边界

消息历史中已经保存的文字、自定义笔记、Lua 返回值及密室技术标识原样保留。若历史消息当时已经以中文记录，不能仅靠切换导出语言恢复其英文原句，因此英文文件在这些存储字段中也可能包含中文。这里保留真实记录，不猜译、不改写旧存档；英文生成路径指可重新生成的字段仍走原英文逻辑，并不意味着能逆转所有历史文本的语言。

## 验证

本轮运行本地化 Python 检查，以及 morgue 文件、角色预览、种子、物品来源和神器说明的定向原生测试。包含实际英文与中文文件、UTF-8、英文专用调用、Lua 调用次数、死亡措辞、形态历史、物品名称与鉴定标记、统计和 RNG 不变、缺项回退等检查。实际结果及文件摘要见 [检查记录](morgue-01-checks.json)。
