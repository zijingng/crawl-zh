# 怪物名与卡牌名术语校对

本轮先提取名称并查询原术语表，再确定统一译法及修改引用。逐项记录包含原术语命中、采用译法和修改前后文本，见 [校对明细](monster-card-names-01.json)；生成结果见 [检查摘要](monster-card-names-01-checks.json)。

## 范围与数量

- 核对 `display.monster` 的 672 个怪物显示名称；其中覆盖当前生成的 `mon-data.h` 中提取的全部 667 个名称，其余为显示别名或辅助名称。包含当前数据表中的兼容和内部占位项，相关术语注明用途；不把这一数量解释为正常可遭遇的怪物种类数。
- 按 `decks.cc::card_name()` 核对 21 个有效卡名，同时统一 21 个对应的“××牌”术语。已删除卡的占位返回值和错误占位名不作为有效卡名新增。
- 新增 513 条术语；更新 208 条既有术语的译名或来源、语境备注。术语表合计 2,268 条。备注补充不等于译名发生变化。
- 修正 64 个 UI 或 TextDB 条目的显示译文，涉及能力/法术名称、召唤物、怪物说明、物品说明、分支说明和日志。

## 主要统一结果

| 英文 | 统一译法 | 处理 |
|---|---|---|
| ufetubus / ufetubi | 乌费图布斯 | 收录复数变体；Summon Ufetubus 改为“召唤乌费图布斯”，修正法术说明残留英文 |
| wraith / the Wraith | 怨灵 | 怪物和同名卡牌统一；the Wraith card 为“怨灵牌” |
| Exile / Exile card | 放逐／放逐牌 | 按原卡牌术语统一显示名 |
| battlesphere | 作战球 | Iskenderun's Battlesphere 为“伊斯肯德伦的作战球” |
| mana viper | 法力蝰蛇 | 对应法术为“召唤法力蝰蛇” |
| Hell Sentinel | 地狱哨卫 | 对应法术为“召唤地狱哨卫” |
| clockwork bee | 发条蜜蜂 | 法术名、生成物和状态说明一致 |
| walking alembic | 行走蒸馏器 | 完整法术名采用同一实体名称 |
| monarch bomb / bomblet | 帝王炸弹／子炸弹 | 生成物与锻造、发射法术及投射物名称一致 |
| soul wisp | 灵魂幽火 | 怪物、灵魂分裂说明和状态说明一致 |
| Pikel / Arachne / Cerebov | 皮克尔／阿拉克涅／瑟雷波夫 | 清理相关日志和说明中的旧译 |
| Dispater | 迪斯帕特 | 神器名 orb of Dispater 同步为“迪斯帕特宝球” |

其他修正包括杜维莎、玛姬、门纳斯、乌鲁格、斯诺格、溶解者、万变始祖、皇家胶怪、守卫蛇、巨石甲虫、深地巨魔、人鱼、奥克罗布植物等相关说明。

卡牌术语保留英文规范名里的冠词，中文名称不另译冠词。“Pain”继续按语境区分法术“痛苦术”和卡牌“痛苦”；其他普通词、引言、作者姓名、比喻及 Lua 标识不能仅凭字符串命中就替换。TextDB 的 `<...>` 和 `[[...]]` 查询/引用键保持英文。本轮没有把一般译文中的所有候选命中都判作错误，也不声称全库一般文案已经穷尽校对。

## 回退与验证
