# t 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

审查核心源码顶层全部 103 个 t 开头 `.cc` / `.h` 文件，修改其中 25 个，新增 `t-display.h`，78 个原文件全文不变。另在 `directn.cc` 接入瞄准失败原因的显示接口，在 `describe.cc` 接入融合装备列表的显示接口。接入、复核 476 条词条，见 `localization/manifests/source-t-01.json`。

逐文件范围见 `source-t-01-files.json`。翻译前查询的术语表 SHA-256、逐文件命中、译法及注释见 `source-t-01-preflight.json`；本批不修改术语表。复核统一“格鲁布里亚通道、分散陷阱、冰骸、锻造术、天资”等译法。按完整词和语境处理命中：吸血蝙蝠不是吸血鬼；普通动词 shatter、形容词 elemental、石质形态和黑暗环境不机械套用同名怪物或法术的译名。

## 瞄准、投掷与地形

覆盖方向选择、视线／范围／障碍提示、挖掘、穿墙、先祖转移、心火、解构、毒气、束缚灵魂、重力方向、影子、腐化及锻造构装体等瞄准限制。`targeter::why_not` 保留规范英文；新增的显示缓存独立保存，失败时刷新，直接改写原因或切回英文时不会误用旧缓存。来自其他验证接口的原因在显示处查询已有词条，缺译保持原原因。

投掷、射击、怪物魔法投射与被网／蛛网束缚时的限制从原物品、怪物及规范飞射物键取得中文组件。原投射物名、伤害／命中、消耗、练习与行为统计保留。

覆盖史莱姆墙、冰墙及寒气伤害、落水／熔岩、地形交换和出口崩塌。地形移动按同一位置、视野和原介词状态生成中文，相关地形名、人物和位置关系缺译时整句回退；规范地形描述与介词接口仍返回英文。

## 陷阱、定时效果与变形

覆盖陷阱进入／触发／消失、暴君／大法师／丑角／吞噬者陷阱、强化怪物列表、警报、捕网与蛛网、恶意力量、隐藏竖井提示，以及魔法污染、胶怪分裂、银墙消退、束缚印记、符文封印和燃烧记忆等定时消息。

丑角陷阱的 TextDB 随机选择及嵌入 Lua 仍只执行一次。显示适配只接受选中结果对应的已审词条；任意新增或脚本结果沿用完整原消息回退，不再次抽取英文版本。

覆盖现行形态的开始／结束消息、变形安全与生命上限确认、武器光辉、融合／脱落装备、太阳余烬、巨口和凝视反馈。原虚函数仍返回英文；中文适配复用其一次生成结果。石像形态的随机草坪摆件笑话不会再抽取一次。电鳗手、菌丝和龙人变龙使用身体部位及怪物类型；未知部件整句回退。两个旧存档兼容形态没有有效变形描述，保留原不完整英文回退，不虚构新描述。

## 自动探索、旅行与 Tiles

覆盖探索完成／未完成原因、拾取失败确认、关闭自动拾取、打断探索／旅行、禁区／门阻挡、绕路确认、分支和祭坛菜单、路标操作，以及发现物品、商店、祭坛、传送门、楼梯、传送器和符文门等列表。

探索发现从原对象保存临时显示信息，保留原名称、数量、分组、去重和路径寻找。自定义地图描述及脚本消息不从英文反推对象；缺乏可靠显示信息时整行保留原文。地图标记的原查询结果用布尔值记录，避免为了翻译再次查询可能执行 Lua 的属性。

Tiles 覆盖能力／法术／技能行、记忆容量、物品和地牢鼠标提示、标签标题、消息记录按钮、纸娃娃编辑器的模式／类别／操作帮助。命令键占位符仍交给原 `insert_commands()` 处理；名称与数值行共同回退。标签的 `name()`、分支／神祇快捷键和旅行目标缩写保留规范英文，中文只用于实际显示。系统命令描述继续复用已有 TextDB 语言机制。

断言、存档修复、HUP、字体／窗口／网络等技术诊断保留原文；任意外部公告正文、TextDB／Lua 消息和自定义地图文字沿用既有边界，不作全局拦截。

新增回归覆盖瞄准原因的规范值、显示缓存失效、各形态的开始／结束消息、已选陷阱文案、未知飞射物／列表成员整句回退、技能行、切回英文和随机状态不变。尚未进行游戏内视觉验收；WebTiles 专属路径未单独构建。
