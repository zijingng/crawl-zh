# u 开头核心源码显示文本审查

基线：0.34.1。日期：2026-10-24。

已审查核心源码顶层全部 13 个 u 开头 `.cc` / `.h` 文件及 106 条源码字符串候选。本范围没有需要新增汉化的独立英文文案，新增译文为 0；13 个文件均与本轮审查前逐字节一致。没有为增加翻译数量而改动通用 UI、Unicode 或恢复操作机制。

译前术语表查询结果、SHA-256、逐文件命中、译法及注释见 `source-u-01-preflight.json`；本批不修改术语表。逐文件范围见 `source-u-01-files.json`，字符串候选的保留理由见 `source-u-01-literals.json`，批次记录见 `localization/manifests/source-u-01.json`。

## 显示内容与保留范围

- `ui.cc` / `ui.h`：通用文字、输入框、滚动区、弹窗、进度条及事件。标题、正文和状态文字由业务调用方传入，原有中文或英文直接交给控件显示。`%s`、`%*s` 是通用格式占位符；`X`、`[ ]`、进度动画和颜色标记是符号。WebTiles 的 `title`、`text`、`status`、`widget_id`、`generation_id` 等是协议字段，不是待译界面标签。`Region(x=...)` 和不可达事件类型属于技术描述。
- `ui-scissor.h`：裁剪区域栈与几何操作，无独立文案。
- `uncancel.cc` / `uncancel.h` / `uncancellable-type.h`：恢复因强制保存而中断的三抽择一、叠放五牌、哥萨戈交互、武器／防具强化等操作。具体提示来自原业务函数；本文件只有调试消息和内部操作枚举，不另造一套显示名称。
- `unicode.cc` / `unicode.h` / `unicode-wrap.h`：编码转换、字符宽度、编码标记检测、文件读取和既有中文换行／标点边界。文件模式、BOM 字节和编码诊断保留；不将编码数据当作文字翻译。
- `undead-state-type.h`、`unique-creature-list-type.h`、`unique-item-status-type.h`：内部状态枚举，不含显示名称。
- `unwind.h`：动态作用域值恢复工具，无显示文本。

## 英文回退与行为保护

没有在通用 `Text`、输入框、进度条或渲染入口全局拦截文字。中文翻译继续在原业务文本来源处完成；英文模式、缺译回退、调用方提供的自定义文字和格式均保持原行为。恢复操作仍调用原业务函数，未增加执行、随机抽取或 Lua 调用。

13 个文件的原始／当前 SHA-256 一致，因而 UI 逻辑、保存恢复、枚举、协议、编码和换行算法均保持不变。既有中文显示支持也未重写。
