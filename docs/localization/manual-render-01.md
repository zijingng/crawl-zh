# 中文手册字形错乱修复

中文手册共有 1,496 种字符，Tiles 字体纹理缓存最多同时容纳 1,023 个有效字形。此前整份中文译文转换成一个格式文本操作；帮助窗口切换页面时直接提交该操作，滚动控件只能按操作裁剪，因此会一次提交整本手册。后续字符占用的纹理位置覆盖尚未绘制的前面字符，表现为部分汉字正确、部分字形错误或位置异常。

`help_document_display` 现在按换行符将译文拆成独立的格式文本操作，每行包含完整 UTF-8 字符，滚动控件因而可以只提交可见行。实际手册任意连续 50 行最多 436 种字符（包含换行符）。没有扩大全局纹理，也没有改动字体设置或译文。

英文模式、未翻译和原文更新时返回原始格式文本，保留英文回退。最终文本的字节、换行和章节行号不变，A–N、1–6 仍对应当前显示文档。

新增原生回归用例检查五份帮助文档的实际显示适配、译文字节一致、每个操作不跨行、UTF-8 完整、长手册超过字形缓存容量的复现条件、章节位置，以及英文／法文／原文更新后的原始操作回退。

Windows Tiles `crawl.exe` 已重新编译，33 项 Python 本地化测试与手册、章节定位、搜索定向原生测试通过；未实际打开游戏窗口进行视觉复核。构建与验证状态见 [检查记录](manual-render-01-checks.json)。
