# database 第十五批：涂鸦基础词库与颜色引用

本批补译 `database/graffiti.txt` 的 **13 个键、87 个候选**，全文件共有 58 个键，剩余 45 个键尚待审核。范围包括书写形态、文字类型、书写样式、涂鸦类型、颜色图案引用、图像、生死评价、爱憎动词、商品品质、大师课、信仰比较及 `any_graffiti` 的入口句式。

翻译前的词汇命中、复合词／复数对应规范名查询及术语表哈希见 [预查清单](database-15-preflight.json)。使用“地精”“狗头人”“斯普利根”“豺狼人”“食人魔”“鬼人”“地底精灵”“巫妖”“天狗”“猫族”“蚁族”“徒手格斗”等既定译法，区分普通图像与实际对象标识。

## 数据及句式

书写形态、颜色与文字类型按中文顺序组合，例如“棱角分明的红色字符”，不直接拼接英文冠词。图像候选保留原先的怪物选择及顺序；课程描述区分挖掘、辱骂、巨型木棒用途和徒手格斗。

`any_graffiti` 的入口模板完成本批审核，但其中多数作者、传闻、签名、宗教及粗俗内容子条目尚未审核。没有据此把整个涂鸦库标为已审，也没有把其余旧引用替换为中文键。生成清单登记为 `reviewed_subset`，仅导出 13 个已审键。

## 复用颜色与显示回退

核对第二批已经审核的 9 个 `colourname.txt` 键的源文哈希、PO 及结构后，将这些完整正文登记到严格配对目录，使颜色和图案引用可用；没有重新翻译这 9 个键。

同时补齐颜色文件自身的引用依赖，以及涂鸦到颜色的跨文件依赖。源颜色子条目变更后，其旧译、组合颜色、书写样式及依赖入口会一并拒绝导出，而无关的已审条目仍可使用。

本批复用现有装饰消息显示路径，未修改游戏 C++ 或 Lua。简单的颜色／文字涂鸦现在可以在喷泉消息中完整显示中文。选到未审作者、传闻或其他不可用子条目时，整条消息保留英文；随机名字仍只生成一次，不为翻译再次抽取。

运行时两个正文存在末尾换行差异，已从实际英文缓存核对后登记精确形式，并绑定原始文件及显示源码哈希。没有改成宽松匹配。英文涂鸦和颜色文件均按字节保持不变。

## 验证

新增实际 TextDB 原生测试，13 个涂鸦键各使用 128 个种子，对比完整英文、中文和后续随机状态；`any_graffiti` 同时检查确有中文分支及整句英文回退分支。另对三类喷泉入口各用 256 个种子，确认涂鸦确实能在最终喷泉消息中显示中文。

数据检查逐项核对 PO、权重、引用和方括号结构。隔离修改颜色子条目后，确认依赖链跨文件失效，且课程等独立分支不受影响。

Windows Tiles 编译、工具测试及原生回归结果见 [检查记录](database-15-checks.json)。未进行实际游戏窗口视觉验收。整个 `dat/database` 尚未全覆盖。
