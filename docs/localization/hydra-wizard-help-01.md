# 海德拉单／双头及巫师怪物帮助窗口

按反馈将中文怪物名称中的一头海德拉、二头海德拉分别改为单头海德拉、双头海德拉。仅在最终中文多头名称参数中处理一、二这两个值；其他头数仍沿用中文数字转换。头数本身、攻击次数、规范英文名称和英文切换路径不变。词汇依现行术语表的 hydra（海德拉）及 wizard mode（巫师模式）。

巫师模式 &m 后输入 ? 打开的 wiz-monster 帮助原先使用 FS_PREWRAPPED_TEXT，按最长原始行决定宽度。中文长段落因不换行而撑大窗口。现将此页与 stash-search.prompt 共用现有自动换行路径；合并帮助页中包含上述任一页时也启用换行。其余预排版帮助继续沿用原逻辑。

scroller.cc 的既有实现会在未设置 FS_PREWRAPPED_TEXT 时启用文字换行，并为本地 Tiles 容器设置 80 个 CRT 字符宽度的上限。没有改写帮助正文、英文怪物生成语法或解析器。

Windows Tiles crawl.exe 编译成功。32 项 Python 工具测试通过；现有海德拉中文数字测试更新单／双头预期后通过，共 87 次断言，覆盖其他数字边界、规范英文名、英文切换、无效头数与随机状态。帮助窗口的标志分支及 scroller 宽度上限已核对，尚未进行实际游戏窗口目视验证。具体结果见 hydra-wizard-help-01-checks.json。
