# o 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

已排查核心源码顶层全部13个 o 开头 `.cc/.h` 文件，接入、校对194条译文。译前术语命中和源码指纹见 `source-o-01-preflight.json`；逐文件范围见 `source-o-01-files.json`；形态徒手名称的补充术语查询见 `source-o-01-unarmed-preflight.json`；最终验证见 `source-o-01-checks.json`。译文及依赖清单为 `localization/manifests/source-o-01.json`。

## 受伤与宝珠反馈

`ouch.cc` 补齐元素伤害、寒冰防护消散、流星索束缚、吸能程度、等级变化、受伤召唤、痛苦与血液变异、死亡变形和神祇保护/死亡评价等消息。中文使用原有伤害种类、既有召唤数量和原始怪物/神祇对象，没有重复掷骰、召唤或应用效果。

`orb.cc` 补齐佐特宝珠的尖啸、闪光、位移相关反馈、魔窟领主警告及神祇干预。明确列出已审核的完整原文；未知自定义消息原样显示，来自调用者的既有中文消息仍原样传递。章节状态和宝珠相关规则不变。

共享的 `player.cc` 腐蚀提示仅在输出完整消息时查询已审核来源，保留原来的来源参数及持续时间/随机计算。其他未知来源继续完整英文。

## HUD 与角色概览

`output.cc` 补齐金币、生命/魔力、属性、防御、等级进度、地点、噪音、厄运、污染、抗性、再生、法术槽、额外生命等标题和数值说明。紧凑HUD使用“甲／闪／挡”，完整概览使用“护甲值／闪避值／格挡值”。数量、颜色、百分比和抗性刻度沿用原值。

角色称号从技能、等级、种族和神祇信息取得既有显示译文；称号、种族/背景和时间组成的概览标题先检查必要组件，再按实际显示宽度计算布局。HUD种族与信仰一行也按组回退。

装备行使用原始物品显示适配器，保留快捷键和颜色；补齐已融合、未装备、不可用及被占用的装备槽。槽名查询继续使用 `equip_slot_name` 返回的规范键，`equip_slot_by_name` 的配置解析不变。

被动效果从现有状态和数值生成完整条目，使用统一的翻译组；缺少组内译文时恢复原来的英文列表。状态说明复用既有接口，补齐移动速度与空状态提示。符文名称从符文类型取得，缺少任一必要名称时完整符文行回退英文。

## 徒手名称与怪物列表

共享的 `transform.cc/h` 新增显示接口，从形态定义、原始身体部位和品牌类型取得徒手攻击译文。普通解剖特征、石像/风暴/电鳗等特殊形态均保留原规范接口；中文不解析拼好的英文名称或括号后缀。

怪物列表先生成原来的完整英文，再从同一份怪物快照生成中文，保留分组数量、态度、状态及现在/过去时区别。修正中文名称前仍被添加英文 `a/an/the` 的问题。未知名称或状态导致完整列表句回退英文。

拥挤状态灯改为按完整UTF-8字符截取，并检查显示宽度。紧凑布局的地点字段直接使用分支和层数，避免解析已经翻译的地点文本。触控端相关修改未进行独立平台构建。

## 保留范围与回退

`outer-menu.cc/h` 是通用文本、交互和序列化层，不拦截任意调用者文字。其他头文件的对象类别、选择器、操作类型、配置键和内部断言保持原值。技术诊断、向导调试信息、杀因/毒素来源、笔记规范内容与TextDB查询键保持英文。

英文模式继续原有英文生成逻辑。缺少必需译文、对象名称或源码指纹过期时，恢复完整英文句子/独立条目。源文及共享依赖指纹随本批复核，没有改写任何存档标识。

按术语表使用“佐特宝珠、魔窟、披风、胶怪、时间扭曲之血、凝结护盾、偏斥飞弹、守护之灵、施法辅助、魔力灌注”等。`agony` 在受伤感叹中不是法术名；紧凑HUD缩写与完整概览标签按空间分别处理。语境复核见 `source-o-01-term-review.json`。
