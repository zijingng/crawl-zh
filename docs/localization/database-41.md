显示时解析已存的英文名称，组合已审前缀、形容词、部件名和原有型号。兼容单词内部前缀、外加前缀、前置字母数字型号，以及末尾 Mk.／Ver. 型号。保留序列号字面值，不另抽一次随机名称。

实例：automatic capacitor 显示“自动电容器”；aerocapacitor Mk.7 显示“气电容器 Mk.7”；AB-20 aerocapacitor 显示“AB-20 气电容器”。当完整英文单词与词缀拼接结果重合时，优先采用完整词译名，如 automatic 和 transformer。

未知词、未知语法、歧义解析或中文词库不可用时，显示接口返回不可用，调用处保留完整英文物品名或英文预告。英文模式不走中文解析。字典缓存随 TextDB 关闭清空，不存运行时审核信息。
