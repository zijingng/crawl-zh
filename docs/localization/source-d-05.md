# d 开头源码：第五批显示适配

本批继续检查 d 开头源码的显示输出和共用接口。修改前查询了 2,268 条术语，源码指纹和命中记录见[事前查询](source-d-05-preflight.json)，新增的 405 条译文见[本批清单](../../localization/manifests/source-d-05.json)。技能头衔另做[逐名称命中检查](source-d-05-title-glossary-hits.json)，共 30 个精确命中；确认译法后才接入显示代码。

## 本批覆盖

- **物品使用限制**：永久无用、暂时无法使用和使用无效的完整说明；51 个固定原因或模板，包含阅读、饮用、唤发、治疗、魔力、变异和传送限制。原规则函数保留英文返回值，中文使用同一份选中原因；原因或类别缺译时回退完整英文。
- **物品来历和位置**：发现、商店购买、获得、发明、神祇赠予、从怪物身上取得、制服舞动武器、异层物品所在位置。分支、层数、来源和赠予神祇均来自原字段，不从英文句子反推；来源标记、存档和规范 `origin_desc()` 不修改。
- **幽灵和幻象**：姓名、称号、经验档次、种族、背景和信仰的完整说明；观察菜单也可显示完整幽灵说明。新增 249 个技能头衔或模板，补齐种族形容词／属名、移动方式和重量级组件；无法识别的自定义存档头衔保留完整英文。
- **常用面板**：复用已有装置名称译文并修正标签列宽；爆炸和流星伤害、噪音标签、佐姆好感说明、怪物法术说明图例；观察菜单的地形名称及“未到访”后缀；书籍页的法术选择与操作列表完整提示。

术语命中后统一使用“世界扭曲者、海妖、铁巨魔、铁魔像、不死军械库、缚狱者、空间大旋涡、极地涡流、皇家木乃伊、岩石史莱姆、狂笑头骨”等既有名称。“Fighter”与“Warrior”分别采用术语表的“战士”和“勇士”。前批施法限制中误用的“静滞”修正为“稳态”；聪慧药水也采用现有术语。

## 英文与共用接口

`get_item_description()` 被界面、Lua、角色记录和工具共用。本批增加显式显示参数：默认完整英文，界面主动请求显示副本；Lua 调用保持原默认参数。中文状态不再进入默认物品说明返回值。`skill_title_by_rank()` 保留原规范返回值，只通过可选参数提供头衔显示副本。

原英文措辞、冠词、所有格、单复数和原始选择分支保留。头衔的 `@Adj@`、`@Genus@`、`@Walker@`、`@Weight@` 等模板从原种族和属性填入，英文替换表不改写。组件缺译使完整头衔或幽灵说明回退，而不是丢弃称号或背景。

中文说明复用同一份原因、数值和物品来源，不增加随机抽取。怪物法术图例中的百分号与颜色标记保留；操作列表缺译时，前缀也和列表一起回退英文。
