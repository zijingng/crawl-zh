# 高分榜双语死因

死亡、退出或获胜事件在 `ouch()` 构造高分记录后调用 `capture_death_text()`，利用仍在场的攻击者和实际武器生成完整英中死因。进入巫师／探索模式的日志入口同样显式生成；普通 milestone 构造高分元数据时不生成死因。生成中文使用临时语言作用域，即使事件发生时配置为英文，也会保存可用的中文，随后恢复原语言。

`scorefile_entry` 删除 `display_death_description()` 和 `translated_death_body()`。相关翻译只用于事件生成；高分榜、中文 morgue 和死亡 note 使用已经完成的文本，不在显示或读取历史记录时查询现场怪物、武器或玩家临终状态。`display_hiscore_line()` 保留人物、地点、日期等排版职责，移除现场攻击者参数。低 HP 受伤记录的 `display_damage_description()` 属于独立的受伤事件路径，保留。

## 保存及回退

按现有五种详略格式保存完整英文正文和可用的中文正文，分别写入 xlog 的 `death_en_0` 至 `death_en_4`、`death_zh_0` 至 `death_zh_4`。`DDV_LOGVERBOSE` 继续使用英文，保留既有日志消费者所需的英文 `tmsg`／`vmsg` 和规范字段。新增字段只包含完成的文本，不保存怪物、物品或玩家状态快照。

反斜杠、换行和回车在文本字段中转义，冒号仍由既有 xlog 层处理。高分文件改为分块读取完整行，避免原先 1,499 字节上限截断双语记录。记录复制、赋值和重载均保留完成后的双语文本。

默认 `death_description()` 返回英文；显式请求本地化且语言为中文时才选择已保存中文。未知名字、未知效果或缺失必要组件时，中文正文不写入，整条回退已保存英文。旧高分没有这些字段，沿用原英文生成路径，不补译、不恢复旧快照，也不附加当前角色的临终状态。

## 验证

Windows Tiles `crawl.exe` 与原生测试程序编译、链接成功。20 项定向原生用例、2,605 条断言通过，覆盖死亡 note、附魔武器、召唤链、临终状态、语言切换、复制与重载、转义、旧记录和未知内容回退，以及 morgue、低 HP 记录和物品显示回归。17 项翻译目录／源码哈希／Python 兼容性检查通过。

实际运行新版 `crawl.exe -scores` 读取测试高分文件：一万字节的死因及其后下一条记录均完整输出。已审译文依赖失配为零；未执行完整原生套件及 Linux WebTiles 编译。
