# d 开头源码：第三批显示适配

本轮在译前查询现有术语表，保留了源码指纹和命中记录，见[事前术语查询](source-d-03-preflight.json)。逐条译文、相关术语及源码依赖见[本批译文清单](../../localization/manifests/source-d-03.json)。术语命中仅供按语境核对，不作机械替换。

## 覆盖内容

- **地形与操作**：固定地形名称、宏生成的石梯、门的尺寸和状态、地形覆盖状态、楼梯／传送门／转移装置说明，以及祈祷、进入、离开等操作列表。自定义地图标记不能完整翻译时保留原说明，不丢弃作者命名。
- **怪物观察**：装备、双持武器、随身物品、态度、伤势、状态标签、云雾和环境后缀；混乱和召唤精灵的几率、变形目标及阻挡射线的地形。装备与观察的必要组件缺译时回退完整英文；缠绕等外部动态说明尚不能完整翻译时也回退。
- **怪物说明**：由原哈希结果生成的恶魔外貌、翅膀、头部、气味和其他特征；变异野兽特征；狐火和流星伤害、木乃伊死亡诅咒、召唤性质和收益、楼梯限制及可制成防具的兽皮说明。
- **技能说明**：训练一级或精通技能的护甲值、闪避值、格挡值变化；神力与祈祷或其他技能的关系、神祇反对训练某技能的说明。
- **法术说明**：等级、学派、失败率、威力、伤害、命中率、射程、噪音；施法失误的魔法污染、伤害类型和特殊后果；作战球的触发法术、仆从施法、白金典范武器、召唤上限、神祇态度及坟墓之爪次数；64 条固定施法限制原因；怪物活体法术、召唤上限、无光提线偶限制和突破意志的几率。

沿用“防具／躯干防具”“护甲值／闪避值／格挡值”“施法失误”“魔法污染”“无名恐怖”“殉难幽影”等术语。原因说明中的法术、能力名称经过再次命中检查，使用“冰霜壁垒”“巨龙呼唤”“堡垒冲击”“铭刻武器”。犬神名称沿用现有术语。

## 英文回退与规范接口

原英文名称、元数据、状态标签、规则函数和数据库查询键保留。地形描述、怪物装备描述的原接口继续返回英文；新增显示接口返回可用性，缺译时不写入输出。

`player_spell_desc()` 同时供 Lua 和界面使用。本轮让默认接口明确保持英文，只有界面显式请求显示版本；原有 Lua 调用不需要改动。施法限制规则仍输出规范英文，显示层使用完整原因和完整父句；不拆解已渲染的英文去猜测法术、物品或怪物。

组合说明先验证必要名称、属性和模板。缺少任一必要组件时回退对应整句或整段英文，独立数值字段可以分别回退。仅含标记或参数的包装不作为“中文译文”伪装入目录，直接包装已经验证的显示组件。

中文复用原选择、哈希结果、几率、召唤上限和防御预览结果，不增加随机抽取。法术数值标签按终端显示列宽对齐。状态标题的显示翻译不改变 TextDB 查询键。
