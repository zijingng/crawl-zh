# v 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

已审查核心源码顶层全部 10 个 v 开头 `.cc` / `.h` 文件及 249 条源码字符串候选，修改其中 3 个文件，7 个文件全文不变。接入 11 条译文，见 `localization/manifests/source-v-01.json`。

译前术语表查询结果、SHA-256、逐文件命中、译法及注释见 `source-v-01-preflight.json`；逐文件范围见 `source-v-01-files.json`。沿用“地下城、众神殿、玩家、怪物、物品、云雾”等译法。本批不修改术语表。

## 图层菜单与地图

`view.cc` 补齐显示图层选择和恢复提示。Tiles 与 Console／WebTiles 分别使用完整的原英文模板，中文保留 m、p、i、c、w、h、a 快捷键及原颜色参数。没有修改图层枚举、切换状态、怪物武器／生命显示逻辑或退出后的恢复行为。

`viewmap.cc` 补齐地图帮助、清除／抹除、恢复记忆地图、没有记忆地图和无法注释本层的反馈。

地图标题新增 `viewmap_display_level_name()`，从原 `level_id` 的分支枚举、深度与分支层数生成中文，复用 `b.branch.name` 已审分支名。多层分支显示“第 N 层（分支名）”；单层分支显示分支名。原 `level_id::describe()` 不变，缺少分支译名或模板时恢复完整原英文标题。标题仍使用既有字符显示宽度和截断接口，没有用 UTF-8 字节数计算中文长度。

## 保留范围与英文回退

`version.cc` / `version.h` 的版本号、构建名称、版权、错误报告地址及编译诊断保留规范值。版本历史的英文记录写入存档，也用于崩溃报告；本批不解析旧记录的英文前缀或改写存档内容。版本信息界面的外围提示继续使用已有翻译，历史记录正文沿用既有英文边界。

`viewchar.cc` / `viewchar.h` 的字符映射名称是配置与内部标识，不能当作界面名替换。`viewgeom.cc` / `viewgeom.h` 是视图坐标和几何操作，没有独立待译文案。递归视图等技术诊断保留原文。

19 个规范接口／操作函数的函数体与本轮基线一致；图层菜单从输入处理到状态更新的代码段完全一致。7 个文件全文不变，9 处随机调用的表达式、次数及顺序一致；见 `source-v-01-preservation.json`。没有新增随机、Lua、规则或保存操作。
