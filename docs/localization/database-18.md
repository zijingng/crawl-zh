# database 第十八批：通用怪物对白与配对选择链

本批补译 `monspeak.txt` 前 **100 个键、340 个候选**。覆盖祭司、雇佣守卫、巫师、友善和敌对小鬼，以及类人生物的友善、同族、混乱、逃跑、沉默对白；还包括猎犬、昆虫、蛛形生物、蜈蚣、象蛞蝓及部分字符类别的通用表现。全文件有 731 个键，剩余 631 个键尚未审核。

翻译前已逐项查询术语表，见 [预查清单](database-18-preflight.json)。沿用“巫师”“宝珠”“地面”“猎犬”“象蛞蝓”“触角”等译法；普通 mayhem 依句意译作混乱、浩劫，不套用同名游戏机制的专名。原文三个伪咒语保留其胡言乱语的音节，只翻译外围句式和标点。

## 旧译与数据管理

该文件在本批开始时没有启用 `zh/monspeak.txt`，也没有位于 `localization/legacy/0.34.1/database/` 的同名参考副本。因此本批以现行英文为准逐条补译，不将“没有旧文件”记作 legacy 已校对。本批生成文件只含 100 个已审键，清单标为 `reviewed_subset`，不将全文件标记为已译。

继续保留原英文规范键、控制前缀、`__NONE` 哨兵、权重、段落和方括号候选。`VISUAL:`、`SOUND:` 是控制标记，不作为中文正文翻译。重新接入后的怪物对白在中文模式使用严格目录，未审正文和缺失子条目不会重新使用不受管理的旧译。

本批当时未适配 `@foe,@` 称呼标记，相关候选回退英文。原记录将它误称为失效引用；第十九批复核引擎后确认它是有效标记，已补齐中文适配。英文始终保持不变。

## 配对显示与英文回退

将同一个配对文本传递到原有前缀选择链。精确名字、前缀简化、三项／两项／单项组合、字符类别和身体形态回退沿用原顺序；原有随机判断、十次重试、无效消息过滤及 `__NONE`、`__NEXT` 判断保留。中文选择链根据规范英文判定消息是否适合当前状态，避免译文改变这些判定。

英文路径继续从规范英文库取值；中文路径只进行一次相同的英文随机选择，将配对译文一起传到现有 `mons_speaks_msg`。没有从已经生成的英文句子猜测怪物名称，也不为翻译重新抽取候选。

补齐对话对象 `@to_foe@`／`@at_foe@`、双手、玩家族类、地面及小写神名称呼的显示参数。使用实际怪物、实际对话对象、当前种族和地形取得译文；参数不可用时整句回退英文。中文的“朝你喊道”“对你说”等语序由完整模板决定，英文原来的介词及省略规则不变。

## Lua 边界

四个键含有 Lua 候选：`_suck_up_adj2_`、`_suck_up_noun_`、`friendly hound`、`friendly shoals hound`。其普通候选已译；Lua 程序、规范种族／变形键及返回值保持英文，选到 Lua 时执行原程序一次并整句回退英文。没有把返回的英文族类、方向或形容词拼进中文。

## 验证

- 对全部 100 个键检查 PO 正文、引用、权重、控制前缀和每组方括号选项数量。
- 每键使用 64 个种子，对照原始英文渲染、后续随机状态、Lua 调用次数和消息前缀。
- 在实际 `mons_speaks` 路径中，对祭司、巫师、半人马、猎犬及普通／逃跑状态进行双语随机序列比较。
- 逐项撤销新增的配对传参后，选择器代码与修改前快照完全一致，验证原控制流没有夹带改动。
- 临时修改祭司子条目的英文，确认该子条目和父级旧译被拒绝导出，守卫等独立条目继续可用。
