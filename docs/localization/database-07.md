# database 第七批：普通武器声音与严格双语显示

本批逐项校对 `database/wpnnoise.txt` 的 7 个 legacy 键、122 个候选：`noisy weapon`、`_weapon_chatter_`、`_rare_chatter_`、`weapon_noises`、`_instrumental_noises_`、`weapon_noise` 和 `singing sword silenced`。翻译前的完整单词术语命中及术语表哈希见 [预查记录](database-07-preflight.json)。使用“佐特宝珠”“歌唱之剑”等既定译名；普通动词及声音按本句语境翻译。

## 校对

重新核对对白含义、声响与乐器名称、中文标点，并恢复旧译中变动的候选边界及方括号选项。原文的空选项在中文中仍为空，不额外添加“声音很轻”等限定。每个随机组的先后顺序和选项数量与英文一致。

本批英文文件按字节保持不变，其余 58 个键的正文与本批修改前一致。PO、中文数据与 [本批审核清单](../../localization/manifests/database-07.json) 同步。累计完成 46／65 个键的数据审核；仍有 19 个 legacy 键待审，主要是歌唱之剑的完整对白和歌曲。整份文件仍不交给整文件导出器。

## 双语显示与英文回退

普通聒噪武器和歌唱之剑改为从规范英文库选择一次，再用严格审核目录匹配中文；不再从 legacy 中文覆盖文件独立抽取。相同随机选择用于英文和中文的权重候选及方括号选项。消息频道、响度、噪声触发、歌唱之剑的张力和攻击逻辑保持原有流程。

新的渲染器在原位置执行神名形式的随机抽取：原代码即使没有神名占位符，也会进行这次抽取，因此保留该行为。武器、玩家姓名、神名和种族占位符使用对应数据生成显示，不解析已拼接的英文句子。已知强化值保留；武器名中文复用物品显示逻辑，专门排除铭文、装备备注和自动属性说明。

缺少已审正文、名称或其他所需组件，消息频道不符，或存在未解决引用时，整句使用原有英文。未审的歌唱之剑正文不会借用陈旧 legacy 译文；纯引用分支只有选中的子条目均完成审核时才允许中文。原有 Lua 仍只执行规范英文程序一次，尚未适配的返回内容整句保留英文。

源码依赖采用精确哈希保护。只刷新与本批基线或本批已生成中间版本一致的依赖，不解除其他历史失效项的保护。

## 验证

原生测试使用独立数据库缓存，直接对比修改前 `item_noise` 的测试副本：9 类消息键 × 128 个种子 × 3 种信仰，检查英文逐字输出、消息频道及后续随机状态；同时检查中文没有残留占位符，未审内容整句回退。固定神器另用 128 个种子验证歌唱之剑的名称、沉默频道和随机状态。还覆盖未知引用、缺译、频道不匹配和空消息回退。

数据检查逐条比对 PO、源文／译文哈希、权重、引用及随机组结构，并验证未选条目保持不变。编译、工具测试及原生测试结果见 [检查记录](database-07-checks.json)。未进行实际游戏窗口视觉验收。
