# database 第二十四批：罗克珊至泽娜塔与兽人信仰词库

新增 **71 个键、324 个候选**。与本轮前两批合计 **190 个键、873 个候选**；`monspeak.txt` 累计已审 **598／731 键**，尚余 133 键保留英文。

本批涵盖罗克珊、鲁珀特、圣徒罗卡、西格蒙德、斯诺格、僧正坊、索尼娅、斯普罗兹、特伦斯、乌鲁格、瓦莎妮娅、威格拉夫、扎克克里克西斯、克塔华、泽娜塔的本段完整对白组，并补齐圣徒罗卡所依赖的兽人信仰常用／罕见对白、发声与异教徒称呼词库。没有把依赖词库留给未审 legacy。

翻译前查询术语表，见 [预查记录](database-24-preflight.json)。使用变形护符、犰狳人、哈耳庇厄、跳蛛、幽灵蛾、太阳蛾、帝王蝎、愤怒之蛾、法老蚁等既定术语。僧正坊的兵法引语采用贴合原文的汉语表达；已知对应原文如“兵者，诡道也”“善战者，致人而不致于人”予以复用，不补入英文没有的整段内容。斯普罗兹的百分数是对白字面文本，目录明确标记 literal_percent，并保留百分号数量检查。

## 英文回退与 Lua 边界

只在中文参数显示层补充 `@Subjective@`、`@Foe_genus@`，保留英文生成主体、英文数据库与选择器。增加四种玩家族类下的大小写参数对照测试；中文参数不可用仍整句回退英文。

以下六个键含 Lua：`sprozz`、`sprozz triumphant`、`_terence_rare_`、`_saint roka rival_`、`_hostile_orc_beogh_believer_speech_common_`、`xak'krixis`。原程序、规范字符串和返回文本保持不变；选到不透明 Lua 时只执行一次原程序，整句使用英文。斯普罗兹的两个底层词库已翻译，但含 Lua 的主入口仍受此边界限制，不能将数据审核数量等同于实际全中文显示数量。

## 校对与验证

本轮前 408 个已审正文精确保留。legacy 参考目录仍只有 help、godname、FAQ，没有 monspeak 历史译本；新段依据现行英文补译，保留旧版兼容键，没有启用未审旧库。

598 个键均检查 PO、导出正文、权重、候选数、引用、控制前缀和随机选项形状，并核对实际 SQLite 英文正文的精确目录匹配。在临时副本中只改变施法颜色词库，玛格丽与西格蒙德的跨批引用均拒绝旧译，娜塔莎、罗克珊、哈罗德等独立条目不受影响。

连续生成时，代词与地形的 9 个辅助组件也依赖审核键集合头文件。本轮按精确重建的中间头文件指纹更新依赖，并检查最终目录确实含有全部 9 个组件；没有绕过指纹校验或整体放行失效依赖。

原生回归逐键使用 64 个种子，比对规范英文、随机状态、Lua 调用次数及消息前缀；实际选择测试新增本轮 42 种怪物。对六个 Lua 键额外测试人类／犰狳人、低／高技能、未记忆／已记忆启动发条蜜蜂的分支组合，验证英文一致和单次执行。
