# dat/database 译文只维护一份

`dat/database` 的译文统一维护在 `localization/zh_CN/textdb.po`，由 `textdb-phase3.json` 指定审核范围。运行时直接读取生成的 `dat/database/zh`，不再从 UI 目录查询数据库正文。不生成运行时校验表、来源副本或指纹头文件。

## 审核发生在导出前

只有 `review_status=reviewed`、PO 非 fuzzy、原文与依赖匹配的条目才能导出。未审、缺译、来源变化或依赖失效的条目不写入中文 TextDB；每次重新生成完整受管文件，清除旧产物中的失效条目。中文目录中出现不在清单管理范围内的数据库文件时，构建直接报错，避免未审核文件混入游戏。

现有原文 SHA-256、引用依赖及代码依赖检查保留在构建导出阶段。运行时不重复判断审核状态，也不加载 legacy 参考目录。上游更新后先重新导出；缺失中文条目走英文回退。

## 运行时

随机消息先从英文选择一个候选，中文使用同一次选择，再同步展开引用。缺少任一需要翻译的子条目、候选形状不符或动态参数不可用时，保留整句英文。英文路径及随机次数不变。

用于拼接英文句子的片段显式调用 `getSpeakString(key, true)`。本次补齐种族辱骂、拟态怪笑声和无名氏回忆处的规范英文查询，避免加载中文数据库后将中文片段混进英文句子。

普通怪物对白、神祇对白、施法、喊声、武器噪声、失误消息、喷泉、涂鸦和杂项等共用这一路径。帮助、FAQ、称号、颜色和其他普通 TextDB 内容同样以已审中文导出为唯一数据来源。

19 条此前已审的 Lua 返回文本也移入 `textdb.po`，使用 `textdb-lua:database/...` 上下文。只有对应父条目实际通过审核并导出时，返回文本才会随同导出。它们作为普通中文文本存放在保留的 `__lua_display__` 命名空间中，不含校验信息。程序仍只执行原始英文 Lua 一次；结果没有完整的已审译文就回退英文，不再维护另一份中文 Lua 程序。

## 迁移范围

- 移除 `ui.po` 及 UI 清单中 1,545 条数据库专用重复记录，涉及原来的七个正文／Lua 上下文。
- 对照发现两份现行译文没有冲突，迁移保持现有用词。另将七条原本已审、仅通过 UI 目录显示的数据库条目归入 TextDB 清单，未新增未审译文。
- 删除不再使用的怪物／神祇手工审核键列表，新增译文不再需要修改 C++ 键名单。
- 独立界面文字及角色、物品等动态参数词典仍由 `ui.po` 管理。
- UI 编译器拒绝再次添加旧数据库正文上下文，防止后续脚本重新引入两份维护。

## 验证

工具测试覆盖未审、原文变化、代码变化、Lua 父条目失效及未受管中文文件拒绝；原生测试直接读取已审 TextDB 导出，不再依赖 UI 内嵌正文。回退测试使用导出过滤后缺失的中文行；不再要求运行时识别不应进入产物的未审旧数据。

另检查所有现行数据库全文在 UI 清单中的非空重复为零、译文内容保持一致、Lua 单次执行、英文结果和随机状态。构建及回归结果见 [检查记录](textdb-single-source-checks.json)。未进行游戏窗口视觉验收。
