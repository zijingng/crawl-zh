翻译前查询术语表中的佐特宝珠、符文、宝石及相关专名，并复用已有地点译名。`garden patch` 按既有 TextDB 说明使用“花圃”。本轮增加四个界面键，其余复用已有译文。

## 显示补漏

`If you return without finding the Orb of Zot, so far below, it's all over!` 来自开局目标库 `welcome_spam`，不是楼梯退出确认。原有已审译文因为 `main.cc` 的旧依赖哈希而没有导出。复核目标提示调用及游戏模式选择后，重新限定三组欢迎语和三个关联词库的依赖；未知或未审条目仍不导出。随机权重、选择及递归引用沿用英文路径。

花圃名称加入地形显示目录，复用 `There is ... here.`、`x` 查看及地形记录的既有显示模板。

## morgue 记录

- 新的收藏品／神器拾取记录保存物品快照，沿用已有鉴定记录的序列化结构。显示时先验证快照能重建原英文物品名，再显示中文；不修改原名、鉴定标志、物品来源或宝石剩余时间。
- 对旧记录，枚举规范的全部符文、宝石和佐特宝珠，只接受完整英文名称精确相等的匹配，不拆解英文物品名。未知旧神器名保持整条英文。兼容旧版的 glittering gem 补为“璀璨宝石”。
- 随机魔窟领主的发现／击败记录由已有怪物类型确定称谓，专名按原记录保留，翻译事件和“魔窟领主”称谓；其他未知怪物名仍保持整条英文。
- 地图 Lua 的 `crawl.take_note` 支持可选的地点类型和规范英文名。三个调用点覆盖巫师实验室、秘藏和四位固定魔窟领主的领域；英文记录及里程碑原文不变。
- 新地点记录保留参数并验证原英文整句。旧记录对 27 个现行实验室／秘藏名及四位领主的领域做完整精确匹配，再复用 `lua.portal.name` 或怪物名称目录。未知地点、人工修改的记录和不匹配的参数回退整句英文。

记录格式版本号、原英文 `Note::describe`、英文 morgue 文件名及生成路径均保持不变。现有存档中的可识别旧记录会在下次生成 morgue 时使用新显示逻辑；本轮不改写磁盘上已有的 morgue 文本。
