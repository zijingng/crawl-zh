# 反馈 0–3：记录、喷泉、腐蚀与换戒指

翻译前查阅术语表及现有记录、地形、物品、身体部位和腐蚀译文，见 [预查材料](reported-four-gaps-01-preflight.json)。沿用 eveningstar → 昏星锤、rust devil → 锈蚀魔鬼等现有术语。新增三条显示模板，喷泉正文仍只维护在已审 TextDB。

## morgue 发现地形与鉴定物品

发现地形时记录类型、陷阱类型和规范原始名称。商店额外记录店主、店铺类型、后缀、位置和名字种子，以便后续导出时按原数据重建名称。自定义且未审的地形名称不猜译。

鉴定物品时保留原英文名称及来源说明，并把物品快照写入笔记现有的 `screen` 字段；只有用户手写笔记会把该字段当截图显示，因此不会把物品快照写进 morgue 正文。快照使用已有物品序列化，保留神器属性、名字、铭文、鉴定状态和来源。副本中的位置／物品栏字母只作序列化规范化，不修改实际物品。快照按当前存档版本读取，版本不匹配、过大或不可用时保留英文。

显示前验证快照生成的规范英文名称与记录相符，再使用现有物品显示与来源适配。物品后续附魔或改变不会改写历史。特殊祝福等来源说明若还不能完整重建中文，保留整条英文。旧的无快照笔记也保持原文。

## 喷泉

原先 `@your_weapon@`／`@your_hands@` 无条件标为不可译，因此已审的奥卡瓦鲁喷泉正文也会回退。现在实际行走触发路径提供武器的规范数据库名称与身体部位的中文备选，再用“你的%s”组合。英文参数、随机候选、Lua 执行与姓名替换仍走原路径一次；未知参数或未审正文继续整句英文。

## 腐蚀

原先玩家腐蚀函数忽略传入的攻击者，仅查固定来源词表。现在先查酸液、锈等固定来源；只有来源文字与传入攻击者的完整规范名称相符时，才使用该攻击者的显示名。玩家和怪物受腐蚀共用此适配，不通过剥离冠词或扫描英语前缀猜怪物。

不改变腐蚀强度、持续时间、抗性和随机判定；不可见来源仍按已有可见性规则处理。自定义攻击说明和不匹配的来源整句回退英文。

## 换戒指

快捷替换行原先直接调用英文 `item.name(DESC_INVENTORY)`。现在完整行使用已有物品显示适配，包括物品栏字母、属性与“已装备”标记，并翻译连接词。`<`／`>` 及其他快捷键、转义、选择顺序与实际装备操作保持原样；任一必要组件缺译时保留整行英文。

## 验证

包含地形／商店笔记、普通／随机神器／固定神器鉴定与来源、笔记存读往返、物品后续变化、实际双语 morgue、用户给出的喷泉条目、动态怪物腐蚀的数值与 RNG 一致，以及两个已佩戴戒指的快捷选择行。最终结果见 [检查记录](reported-four-gaps-01-checks.json)。

未进行实时游戏窗口操作；原生测试调用实际显示、腐蚀、笔记序列化和 morgue 导出路径。

Windows Tiles `crawl.exe` 编译通过；18 项原生测试（78,212 条断言）和 33 项 Python 检查通过。三份既有规范英文导出样本 SHA-256 保持一致。
