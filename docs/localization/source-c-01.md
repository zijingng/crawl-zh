# c 开头核心源码显示文本复核

本批沿用前两批的核心源码范围，面向 Windows Tiles：复核 `crawl-ref/source` 顶层 c 开头的 42 个第一方 C++ 文件，并记录自动生成的 `compflag.h`。辅助构建、测试、GDB、服务器及前端代码另列说明；第三方 Catch2、contrib、rltiles 不作为游戏文案翻译。逐文件清单见 [source-c-01-files.json](source-c-01-files.json)。

## 覆盖

本批共核对 **432 个目录项**，新增 270 项、复用已有帮助等译文 162 项。完整条目和来源依赖见 [source-c-01.json](../../localization/manifests/source-c-01.json)，验证摘要见 [source-c-01-checks.json](source-c-01-checks.json)。

- `cloud.cc/.h`：云名短名及详细形式、林火蔓延、雨水积深、恶臭、诱变、眩晕与静风提示。云层吞没、沐浴、蝙蝠围攻和雨中冒汽／嘶响消息使用原始角色及云类型生成中文整句。
- `command.cc`：版本、种子、功能列表、终端和色板说明、错误提示、装备概览；复核已有帮助菜单及说明的译文入口。装备配色继续依据原英文匹配，中文从原始物品和槽位生成。中文计算显示列宽，英文保留原排版路径。
- `chardump.cc/.h`：为游戏内角色记录查看建立独立显示入口。覆盖标题、探索统计、金币收支、地点、信仰与赎罪、佐姆关系、法术容量、法术表、物品、技能、动作统计标签和表格说明、图文记录标题、种子及导出提示。原来的导出调用默认关闭本批显示适配；自定义 Lua 段落和其他模块提供的内容仍使用各自原有路径。
- `clua.cc`：持久化文件无法打开写入的提示。Lua 参数名、异常、API、代码和其他技术诊断保留英文。
- 其余 c 文件为输入基础设施、颜色与命令解析、尸体算法、坐标、枚举、声明、构建配置、测试或崩溃诊断，没有将这些内部标识或开发输出当作玩家文案替换。

为使云名实际显示，本批同步修改 `describe.cc`、`directn.cc` 和 `lookup-help.cc`：覆盖云层标题、当前位置描述、目标格子说明、云名查询菜单和透明度／离开视野后的消散说明。查询菜单保留原英文数据键及英文筛选文本。共享的 `skills.cc/.h` 导出函数增加显式显示参数，默认维持原行为。

本批范围不是整个角色记录、帮助文档或网页客户端的全量重译。其他源码模块、外部更新记录、用户笔记、自定义 Lua 和未知组件按现有语言加载与回退机制处理。WebTiles 前端的登录、聊天、账号管理等独立网页文案未纳入本批 Windows Tiles 适配。

## 云名术语

按实际 `cloud_data` 表清点 **40 种云、49 种唯一名称形式**，包含短名、详细名称和兼容旧版条目。术语表新增 48 项，复用已有的 Gloom，并补充云类型与来源备注，总计 **1,755 项**。完整对应关系见 [cloud-names-01.json](cloud-names-01.json)。

示例：火焰／熊熊烈焰、恶臭烟雾、冰冷蒸气、毒气、黑烟、薄雾、钙化粉尘、黑暗瘴气、诱变雾气、魔法凝雾、酸雾、雷霆／雷暴、爆裂微灵／不稳定火花、磁化碎片、蝙蝠群、锈尘。短名与详细名是不同英文词条，术语表继续保留上一批已有的多义词 `/` 约定。

`cloud_type_name()`、`cloud_struct::cloud_name()` 和规范云表仍返回上游英文。新增 `cloud_display_name()` 与失败时不改输出的 `try_cloud_display_name()` 仅用于显示。Lua、TextDB 查询、名称解析、伤害归因、存档及枚举不使用中文名。

## 英文回退

- 原英文句子的单复数、动词变化、所有格、时态和拼接保留。中文消息通过相同的对象、枚举与状态取参数。
- 云名或角色名不可用时，整条云层消息回退原英文，不产生半句中文夹英文名称。
- 角色记录中的探索段落与金币段落先检查所需模板及名称；有缺项则保留对应完整英文段落。
- 游戏内角色记录显示使用受限作用域。英文模式和原导出调用保持原路径，作用域退出后不会污染后续导出。未知 Lua 返回文本不按英文语法作替换。
- 功能表、云表、动作枚举和命令表的规范数据保留英文；固定显示词从独立目录取得译文。
- 本批条目关联英文及源码依赖指纹。更新上游后，依赖不匹配的译文继续被生成器排除，回退英文。
