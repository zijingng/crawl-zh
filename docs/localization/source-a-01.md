# a 开头源码显示文本：第一批完整范围复核

本批针对 `crawl-ref/source` 中名字以 a 开头的第一方 C++ 文件（不含 contrib、rltiles），共 34 个文件。逐文件记录见 [source-a-01-files.json](source-a-01-files.json)，机器检查见 [source-a-01-checks.json](source-a-01-checks.json)。这里的覆盖范围是这些文件的玩家显示路径，不代表整个游戏的动态日志已经全译。

## 本批交付

- 复核 1106 个目录项，新增 1105 项，复用 1 项。覆盖能力菜单、消耗与说明、深渊与获取物品提示、调整菜单、光环、竞技场显示、束缚与碰撞、攻击效果、神器触发日志等。
- 能力显示名称与内部英文名分离；术语表新增 138 项（129 个名称及 9 个接受印记变体），总计 1552 项。动态使徒名称从原始对象生成，生成的人名保留原样。
- 逐项检查生成神器表中的 179 个铭文、词缀及说明字段，共 176 个唯一文本。生成表原文不改，玩家查看物品时翻译；规范英文铭文与自动铭文接口保留。
- 补齐调整法术菜单动作和净化之焰确认提示；对应共享显示边界随同修改，避免在 a 文件中只翻译半句。

## 英文回退与同步

原有英文消息先按原逻辑构造，中文完整模板从原始角色、物品和状态取参数。模板或任一必要名称缺译时，返回整条原英文。内部能力名、TextDB 查询键、配置与 Lua 键不改。翻译清单保留英文内容哈希及相关源码依赖，依赖变化后未复核的译文不进入生成目录。

显示层新增或扩展的共享接口涉及 i18n、物品名称、描述、消息、卡牌、神祇能力与使徒、射击和确认提示模块。这些修改均以显示为边界；例如使徒攻击统计只计算一次，神器对白只选择一次，不为翻译额外抽取随机数。

## 保留英文的范围

- 枚举、规范名称、配置/解析器/Lua 键、生成的人名与玩家输入；竞技场示例保留可直接执行的英文语法。
- 断言、调试信息和面向开发者的技术诊断。
- 铭文中 AC、EV、Str、Int、Dex、rF 等结构化属性符号。其完整说明使用中文，结构化符号继续供既有规则和用户配置识别。
- actor 中供其他模块使用的英文语法辅助函数保留原样；相应整句消息在显示出口翻译。未接入中文出口的外部调用仍走原英文。
- 外部 TextDB/SpeakDB 内容使用已有语言加载与回退机制；本批不是对所有怪物对白的重新校对。

- C++ localization 测试：25 个用例、13619 次断言通过；包括英文模式、缺少参数或模板时的整句回退、能力名称、卡牌、神器显示与规范铭文，以及随机状态不变。

- 34 个文件注释外的随机调用顺序与本批基线一致；生成神器表、规范神器数据等保持原文。全部本批英文来源哈希、依赖哈希和术语表哈希匹配。
