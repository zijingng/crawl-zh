# 随机神器显示名去重（2026-10-25）

报告示例：`-1 披风「cloak "Kittixae"」`。

`ARTEFACT_NAME_KEY` 存储的是上游完整命名记录，例如 `cloak "Kittixae"` 或 `cloak of Kittixae`。原中文显示层把该记录当作单独专名，又加了一次中文基础物品名。

本轮只调整已鉴定随机神器的显示适配：根据原始物品类型取得 `get_artefact_base_name`，严格验证缓存记录的对应前缀，再读取生成器的引号式或 `of` 式名称组件。不是从已经渲染的背包字符串或日志中识别物品。输出变为 `-1 披风「Kittixae」`；引号内部本来属于专名的 `of` 不会被删除。

未修改名称生成器、英文名称缓存、存档、强化值、属性、铭文或固定神器目录；没有重新生成名字或额外调用随机数。无法识别的自定义命名、引号不完整、基础类型不匹配或缓存缺失时，整个物品名回退原英文。未鉴定物品仍只读取可见外观，不读取隐藏专名和强化值。

术语“披风”“神器”沿用现有术语表，[译前查询](randart-name-01-preflight.json)记录当前术语表哈希。没有新增译文或修改通用 `%s named %s` 模板；[源码依赖复核](../../localization/manifests/randart-name-01.json)同时关联名称生成器与显示适配。

Windows Tiles 的 `crawl.exe` 已重新编译。123 项本地化测试通过（192,217 个断言），覆盖引号式/`of` 式/数据库式标题、专名内的 `of`、原名称与铭文不变、英文切换、未知格式整项回退、未鉴定信息边界、缓存缺失与随机状态不变。`git diff --check` 通过。
