# M 流派、Ctrl+F 地点与动态战斗标点

翻译前查询术语表及现行已审译文，保留 85 条相关术语参考与 118 条显示翻译参考。本批复用已有翻译，不新增重复词条，另对照现有学派简名以保留菜单列宽。见 [预查记录](reported-school-place-punctuation-01-preflight.json)。

## M 法术库

法术库的流派列此前直接使用英文 `sortable_spell.school`。现在显示时复用角色记录中的 `c.dump.school` 中文简名（如“塑能/火系”），避免全称挤占失败率和等级列，中文搜索也使用该显示标签；英文的流派字段、排序依据和搜索名称保留。缺少任一必要学派名称时，该标签整体回退原英文。英文与其他未支持语言仍显示原英文标签。

## Ctrl+F 地点

结果的地点列此前把 `level_id::describe()` 当作无需翻译的字面文本。现在地点显示按分支类型取得已审中文分支名，并保留层数、底层 `$`、单层分支省略层数的规则。方括号、当前位置与路径点提示继续沿用原有逻辑。

保存和传递的 level_id、搜索结果身份、排序、旅行目标，以及物品属性中的英文地点键不变。地点名缺译时，整条结果继续使用原英文，不把未知英文名称混入中文模板。

## 动态标点

共 46 处参数从 `ui_literal_arg` 改为既有 `ui_attack_punctuation`，覆盖缠绕及隐蔽缠绕、碰撞、推撞、触电、光束、死亡诅咒、伤害反弹、酸液、神力惩击／处决、法术伤害、闪电放电、固定神器特效与冰冻地形等。

只转换完整中文消息的末尾标点参数；`attack_strength_punctuation` 及生成英文原句的代码保持原样。伤害强度对应的感叹号数量不变，“但未造成伤害”继续使用既有完整中文子句，所需名称或标点缺译时整句回退英文。

另审查了 UI 译文以单个或两个英文句点结尾的情况，共 5 条：一条宏按键示例 `A:.`，四条状态进度后缀。它们属于可输入内容或状态标记，予以保留。

## 验证

新增定向回归覆盖所有有效法术的流派显示与列宽、各类分支地点及层数、中文战斗标点、英文／其他语言回退，以及规范名称和随机状态不变。Windows Tiles `crawl.exe` 已生成；21 项定向原生测试共 3,885 条断言、33 项 Python 检查通过。构建与测试结果见 [检查记录](reported-school-place-punctuation-01-checks.json)。
