## 修复

- 本地 Tiles 怪物头顶标签原先直接调用 `proper_name`。改为显示专用的 `display_name_tag`，固定怪物类型复用既有怪物显示名；玩家幽灵仍只显示玩家名，自定义专名保持原样。英文规范名称、怪物身份和标签隐藏条件不变。
- 特殊商店原先缺少 Firing／Range 等组成部分。补齐当前地图文件中 204 个 `type:`／`suffix:` 字面名称组件，沿用原有 `shop_name` 显示参数和通用入口模板。`Lemm's Firing Range` 显示为“Lemm的射击场”；不解析完整店名猜店主或类别，未知动态组件仍整名回退英文。
- `!!` 注释分支选择器中的小型分支列表原先另用英文短名排版。改为复用 `b.branch.name`，按显示列宽补空格，保留四列布局和原有分支快捷键。英文配置逐字符保留原排版。
- `E` 界面的 `Play time` 原先直接输出英文流。改用显示模板“游戏时长：%s（%s回合）。”；时间仍由原先的 `handle_real_time` 和 `make_time_string` 计算一次。
- 符文锁原有模板已接入翻译，但缺少 `gossamer`、`elven`、`mossy`。补齐三项，按已有完整符文物品名称统一六个旧译，核对全部 19 种符文，包括仅在冲刺中出现的种类。插入顺序、随机状态、锁的机制不变。

共新增 200 条已审显示词条（196 个特殊店名组件、3 个符文名及 1 个时长模板）。既有商店组件继续复用，不重复建立整名译文。
