## 独立帮助文档

已完整翻译并接入游戏帮助界面的 Quickstart（`^`）和 Macros（`~`）页：

- [快速入门](../../crawl-ref/docs/zh/quickstart.txt)
- [宏与键位映射](../../crawl-ref/docs/zh/macros_guide.txt)

原始英文 `crawl-ref/docs/quickstart.txt` 与 `macros_guide.txt` 均保留。`command.cc` 在原有逐块读取、末尾空白处理之后，以完整英文全文查询 `ui_translate("help.document", ...)`。只有已审全文完全匹配时才替换显示；英文模式、未审、缺译或英文正文变化时，保留原有 formatted_string 及其内容。没有改动英文页的快捷键扫描和加载流程。

译文维护在 `localization/zh_CN/ui.po`；`crawl-ref/docs/zh/` 为可单独阅读的生成副本，不是游戏加载时的英文替代文件。运行时仍先读原英文，再查编译进程序的目录，因此直接更新英文文件后，旧中文也不会覆盖新正文。首次使用本批功能需要更新可执行文件。

`tools/localization/build_help_documents.py` 依据 [文档来源清单](../../localization/manifests/help-documents.json) 检查英文指纹与 PO，生成中文副本。缺译、fuzzy、未审或来源变化时，该副本输出当前英文，不保留旧中文。正式构建的 `textdb-zh` 目标也执行此步骤。逐段审查记录见 [文档校对记录](phase3-help-document-review.json)。

宏定义中的 `M:`、`K:`、`K1:`、`K2:`、`K3:`、`A:`、数字键码、反斜杠、命令序列及示例注释逐行保留。中文正文按不超过 76 个显示列预换行，便于原有帮助页阅读。上游指南自身仍有历史按键、种族概括及文件引用；本轮忠实翻译，没有借汉化改写原文建议。后续若纠正文档，应单独修改英文来源并重新审译。

## 引用与英文回退

三种宝石说明保留 `[[gem]]` 引用，并登记共享正文的英文及中文指纹。导出器先准备所有候选输出，再针对本次输出校验依赖，循环撤销已失效子条目的父译文。这样既能一次完成新依赖的首次导出，也能在同一次导出中撤销引用了缺译或已变更正文的父译文，避免读取上次生成文件造成一轮滞后。未接管的外部引用仍按磁盘上的实际来源检查。

原英文物品与法术文件未改动。中文缺译及来源变化继续走既有英文回退；英文语法、对象查询键和游戏规则不变。
