# 数据库对白第 28–30 批

本轮新增 46 个审核条目、161 个随机候选（含引用和空操作分支）。monspeak 累计 699/731 个审核键，剩余 32 个。原有 653 个中文导出条目逐条比较不变，英文源文件未改。

- [第 28 批](database-28.md)：热能发电机、折磨者、哭泣头骨、奥术师、秘术师、牦牛及善神对白。
- [第 29 批](database-29.md)：神圣生物安抚、兽人说话词、敌对比欧弗信徒和不信者的引用组。
- [第 30 批](database-30.md)：友好比欧弗兽人、祭司与术士引用组、归信和投降对白。

翻译前的原文及术语命中保存在 database-28-preflight.json。采用“比欧弗、辛、光明神、艾利维隆、奥术师、秘术师”等术语；普通语义的 pain、agony、holy、forge 不机械替换成法术或装备词条名。

译文仅维护于 textdb.po，经过审核清单过滤后导出。保留英文规范键、候选次序、随机权重、方括号选项结构、通道和引用标记。未添加 UI 正文副本或运行时审核表。

本轮没有修改 C++ 或 Lua 实现。现有渲染器尚不支持的 @foe_god@、@Foe_god@ 和 @at_foe/around@ 参数仍触发整句英文回退；不会显示中英混杂或残留标记。因此审核键覆盖数不代表所有运行情境都已显示中文。这些参数的显示支持现已在[动态参数补齐](database-dynamic-parameters-01.md)中完成；以上为本批初次交付时的限制。

验证：Windows Tiles crawl.exe 编译成功，32 项 Python 测试和 160 项原生本地化测试全部通过；差异空白检查通过。未进行 GUI 目视测试。
