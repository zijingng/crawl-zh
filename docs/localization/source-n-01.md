# n 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

排查核心源码顶层全部20个 n 开头的 `.cc/.h` 文件。本批接入、校对120条显示译文；沿用此前已接入的角色选择、武器和危险原因译文。译前术语命中与文件指纹见 `source-n-01-preflight.json`，逐文件范围与变更见 `source-n-01-files.json`，本批译文及依赖见 `localization/manifests/source-n-01.json`。

## 角色创建与启动

补齐随机组合确认、角色姓名界面的开始/退出操作、种子选择提示、每日种子、剪贴板提示、预生成选项，以及教程和冲刺模式地图名称、默认地图选择与地图缺失反馈。

角色说明、欢迎语和不兼容组合反馈从种族、背景及用户姓名生成中文，所需名称缺译时使用完整英文。`newgame_char_description` 保持规范英文；显示调用显式使用独立接口。角色选择值、地图标识、种子数值、随机流程、名称验证和命令键不变。地图图标和排序仍用原名，自定义地图没有译文时保留原标签。

`ng-input.cc` 补齐开场欢迎与配置读取状态。版本、版权和实际文件路径保留；服务器环境仍只显示原先允许的文件名部分。共享的 `startup.cc` 接入“上次组合”快捷入口，并按完整提示进行回退。

## 附近危险

补齐怪物附近公告及危险原因的直接公告，复用已有的 `i.danger` 对象名称和原因适配。用于配置/Lua和调用者判定的规范原因继续英文，只在输出边界使用中文。云雾名称从原云类型取得，未知名称时完整回退英文。复生和过度体弱的消息按术语校对。

没有新增危险判定、随机选择、Lua调用或额外游戏效果。

## 冒险笔记

新增 `Note::display_describe`，用于笔记界面和角色转储；原 `Note::describe`、存档字段和里程碑接口保留英文。

显示模板覆盖生命/魔力、等级、楼层、法术、信仰与赎罪、赠礼、物品获取与购买、技能、怪物相遇/击败/变形、变异、厄咒、麻痹/恼咒、使徒与先祖、宝石、复生、烙印及无界超立方体等事件。能从记录中的ID取得的法术、技能、神祇、变异和宝石名称，通过对应类型查询译文。

历史笔记中的物品、怪物、原因等部分字段仅有英文字符串快照。仅接受已审核的精确键；不从拼好的英文中反推物品、怪物或语法。任一必需字段无法本地化时，完整事件说明回退英文。因此，接入所有事件模板不表示任意旧笔记都能恢复出中文对象信息。

用户手写笔记、任意脚本消息和不透明死亡说明保持原内容；内部错误、调试补充信息与服务器里程碑保持原格式。中文显示不写回任何规范记录，重新载入后仍可切换英文。

## 其余文件

`ng-init*` 的分支入口、神庙生成及地图标签，`ng-setup*` 的初始化与内部属性，`ng-restr*` 的限制判定，`ng-wanderer*` 的技能/物品生成，以及 `noise.h` 的噪声接口均已排查。这些文件没有待接入的普通界面文字；生成器技术失败、诊断和调试文本保留英文。

## 术语与验证

按术语表使用“种族、背景、地下城、索尼娅、孟卡拉、费德哈、神塔、佐姆、辛、赎罪、魔力值、体弱、梦晶项链、无界超立方体”等。`pieces` 在金币数量中是量词，`will` 在种子说明中是助动词，`max` 在数值说明中表示上限，未机械套用其他语境译法。

最终构建与验证结果见 `source-n-01-checks.json`。新增回归覆盖角色说明切换、规范选择值、未知名称/历史快照整行回退、用户和脚本内容不变、笔记显示前后存档字节一致，以及随机状态不变。

本批构建 Windows Tiles 的原 `crawl.exe`，未进行游戏内视觉验收。
