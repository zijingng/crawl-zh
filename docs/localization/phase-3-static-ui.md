# 阶段 3：静态内容和常用界面

基线：官方 0.34.1。此记录描述阶段 3 的核心路径批次，不表示全部物品、法术、神祇和风味文本均已译完，也不表示阶段 5 发布验收已经完成。

后续进展：[第二批静态说明](phase3-static-02.md) 新增 181 条，累计 TextDB 已审导出 541 条。下文的范围与验证数字保留为首批记录，最新累计覆盖见 [覆盖报告](phase3-coverage.md)。

## 本批范围

- 创建角色：启动菜单、种族/背景显示名、分组、选择提示和常用选项；种族与背景短说明整文件校对。
- HUD：生命、魔力、力量/智力/敏捷、噪声、时间/回合等静态标题。AC、EV、SH、HP、MP 等缩写和内部状态标识保留；角色称号、装备名称等仍沿用英文生成。
- 背包/装备：分类页标题、装备栏位计数、类别小标题、丢弃提示；39 项常用装备、投掷物、药水和卷轴说明。
- 技能：29 项技能显示名和正文整文件校对；训练栏、开关、目标提示、主要帮助和技能说明标题。保留英文技能查询键。
- 法术/能力：施法与法术库页面标题、主要提示、模式切换、能力菜单与使用提示；12 项起始/常见法术、27 项种族或常用能力说明。名称组合、失败原因的全部动态表达留待阶段 4。
- 检查描述：39 项云雾、20 项被动效果、38 项常用状态说明；说明/引文切换与部分属性标题，资料查询菜单与类别名称。
- 帮助：95 个有效命令键的说明，拾取/丢弃、已知物品、技能管理、法术库和跨层旅行/注释共 8 个帮助主题。手册全文、巫师调试帮助等未纳入本批。

完整数字、逐键英文回退列表及未审文件见 [覆盖报告](phase3-coverage.md)。不能把目录数量当作全游戏汉化百分比。

## 校对方法与主要修订

本批 TextDB 对照当前英文逐条、逐段检查；原英文的每一正文行（含 Lua）及行号、旧中文、校对后中文、来源 SHA-256 保存在 [逐行校对记录](phase3-textdb-line-review.json)。英文硬换行只是源文件排版，中文允许重新组织行和句子，校对以信息、条件、否定、数量和因果不丢失为准。

统一参照 `localization/glossary.csv`：战斗、锤与连枷、棍杖、塑能系魔法、妖术系魔法、位移系魔法、锻造术、唤发、变形术、变形护符、法术强度、护甲值、魔人、藤蔓人、佐特宝珠、天谴、法术火花仆从等。术语表没有收录的起始法术名在背景说明中附上原英文，供检索与后续定名；未擅自改写术语 CSV。

确认并修正的旧译问题包括：

- 投掷技能删除当前英文已不存在的“增加回旋镖返还几率”，恢复命中率与伤害含义。
- 武器交叉训练表述为提高相关武器效能，不声称直接提高另一个技能等级。
- 召唤说明保留“装备与召唤物一样临时存在”，不误写为击杀后没有装备这一独立机制。
- 灯灵施法说明与普通种族分开，普通施法技能保留“略微”；修正旧译重复“和”。
- 祈祷保留“与施法只采用较高魔力加成”；唤发不添加魔力储备加成。
- 使用当前人类探索恢复、地底精灵魔力恢复、犰狳人翻滚、山地矮人、骚灵和还魂者说明，不沿用历史种族机制。
- 加速是速度提高 50%，减速是耗时增加 50%，未混为同一个数值意义。
- 法术逐条保留当前护甲穿透、1.5 倍耗时、暂时生命损失、重复施放间隔等约束；药水和卷轴保留取消传送、强化上限等条件。
- 标枪 Lua 中的 `Kobold`、`Spriggan`，以及技能中的 `Djinni` 均保持英文程序值。

上游 `commands.txt` 对 `CMD_EXPLORE_NO_REST` 定义了两次；遵循原解析器“后者覆盖前者”，只导出有效正文，未修改英文或命令键。

## 单一编辑来源与回退

正式编辑来源为 `localization/zh_CN/ui.po` 和 `textdb.po`。中文 TextDB 文件由 `tools/localization/build_textdb.py` 生成，勿手改生成 TXT。`make TILES=y` 会检查并重新导出 TextDB；无需联网，游戏运行时不需要 Python 或 gettext。

导出必须同时满足：清单标记已校对、当前英文正文 SHA-256 匹配、PO 存在有效译文且非 fuzzy、引用/格式标签与 Lua 保护检查通过。没有合格译文时从生成文件移除该键，由现有 TextDB 回退英文。来源变更不会自动批准旧译文。`python3 tools/localization/extract_textdb.py` 会按当前英文刷新全部受管理文件的 POT，并将来源变化/新增未审/移除记录写入 `textdb-source-changes.json`，不改动 PO 或审核清单；可随后用 msgmerge 或 Poedit 更新译文。非法程序标记会使构建失败，要求先修复译文。

11 个受管理的中文文件已替换为只含本批已审条目的生成文件。旧版本参考副本存放在 `localization/legacy/0.34.1/`，来自当前上游基线 HEAD，不参与运行时加载；逐行记录另保存本次实际读到的旧条目。部分覆盖文件中未审旧译不再混入生成结果，因此可能比旧版看到更多英文，这是明确的英文回退范围。

未管理的其他旧中文文件暂未改动，覆盖报告单独列出，不能声称已经过本批审核。包括 `roll passive` 引用的 `rollpage mutation`，本次另对照了该引用的中英文正文，确认其条件和两级恢复效果一致，未修改该文件。阶段 5 打包前仍需全局清理未审资源。

## 验证与后续检查

- Windows MINGW64 本地 Tiles 构建。
- C++ 回归：语言选择、英文/缺译回退、显示名与内部技能键分离、中文标题截断与列宽、文本缓冲区、五组后备字体配置。
- Python 回归：PO 导出、fuzzy/缺译/未审/来源变更过滤、移除陈旧输出、重复键解析、可重复生成、格式标记与 Lua 控制代码保护。
- 使用当前 contrib Lua 库执行灯灵/普通种族施法与祈祷、狗头人/斯普利根/人类标枪说明，共 7 个分支。
- 像素文本补上 CJK 字符间换行，不拆 UTF-8 字节，并避免常见中文闭标点出现在行首、开标点留在行尾；英文仍按空格断词。法术标题和技能名改用现有显示列宽函数。
- 实际窗口与未完成的场景检查见 [检查记录](phase3-runtime-checks.json)。没有将未执行的场景写成通过。

复查操作：

```bash
cd crawl-ref/source
make -j4 TILES=y
make -j4 TILES=y catch2-tests-executable
./catch2-tests-executable.exe '[localization]'
python3 ../../tools/localization/test_textdb.py
python3 ../../tools/localization/test_catalogue.py
python3 ../../tools/localization/report_phase3.py
./crawl.exe -rc ../settings/zh-local-tiles.rc
```

实际游玩仍需检查窄窗口/不同 DPI、目标设置、保存读取、分页和搜索；英文名称查询键保持原语义，未增加中文名称搜索。Console、WebTiles、其他系统不在本批验证范围内。

正文检索仍有上游部分翻译数据库的限制（`getLongDescBodiesByRegex` 只搜索当前译文库）；本批未扩展中文名称搜索或改写该检索机制。

Lua 分支检查可用本机同版 contrib Lua 库复现（从 `crawl-ref/source` 运行）：

```bash
g++ -Icontrib/install/x86_64-w64-mingw32/include ../../tools/localization/lua_check.cc contrib/install/x86_64-w64-mingw32/lib/liblua.a -o /tmp/dcss-textdb-lua.exe
python3 ../../tools/localization/test_lua.py --lua /tmp/dcss-textdb-lua.exe
```

更新 UI 模板：从仓库根目录运行 `python3 tools/localization/extract_ui.py`，抽取实际 C++ 字面量调用，并合入清单中已知的动态显示名；不会自动批准译文。
