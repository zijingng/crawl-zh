# morgue 地下城概览补译

本轮先查阅术语表的 65 项命中及 103 项历史译文，再补齐结构化概览字段，复用已有分支、神祇和怪物名称。只新增两条已审界面模板，未复制维护名称译文。见 [翻译预查](morgue-02-preflight.json)。

## 覆盖内容

- 已发现和未发现分支的名称、入口地点和深度范围；中文列宽按显示宽度处理。
- 商店、传送门、注释和密室清单的地点列。
- 佐特守卫说明、佐特计时标签。
- 由独特怪物元数据生成的备注，如 Kirke → 喀耳刻。
- 概览祭坛中的神祇显示名称，包括英文规范键以小写 the 开头的光明神。

中文 morgue 使用导出布局，不再附带交互概览的按键提示。密室地图技术标识和巫师标记保持原样。

## 英文回退

原 `.txt`、`.lst` 路径和英文生成入口继续保留；中文配置另外导出 `.zh.txt`。默认 `dump_vault_maps()` 继续返回英文，只有中文导出显式请求显示名称。默认角色记录生成仍在英文作用域执行。

缺少分支行所需名称时保留该行英文；缺少佐特守卫名称时保留整段英文；独特怪物备注有未知名称时保留整个原备注段。规范分支键、怪物键、地图标识及存档数据不变。

玩家自写备注、传送门备注和已经存储的历史文本保留原样。本轮没有通过解析英文历史句子猜译这些内容，也不保证所有历史文本都能还原成英文。

## 验证

Windows Tiles `crawl.exe` 和原生测试程序编译通过。7 项定向原生测试共 166 条断言、33 项 Python 本地化检查通过。测试实际生成英文与中文概览文件，并检查未知名称回退、原英文入口、地图标识、语言恢复及 RNG 不变。此前三份英文测试记录逐字节不变。详见 [检查记录](morgue-02-checks.json)。
