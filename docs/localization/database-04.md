# database 第四批：miscname 缺译与 legacy 全文校对

## 覆盖与术语

`database/miscname.txt` 全部 10 个现行键完成补译和逐条校对，共 151 个文字候选，另校对英文 Lua 原程序的两种返回结果。翻译前匹配术语表，记录见 [预查清单](database-04-preflight.json)，含术语表和源文哈希。

本批同时处理了 legacy 问题：

- 旧中文使用失效键 `SHT_int_loss`，当前英文键为 `summon_horrible_things`。已按新键补齐 28 个候选，并移除生成文件中的失效旧键。
- 补齐 `harlequin_trap_lines` 的 4 个句子片段，连接时使用完整中文模板；组件缺译时整句回退英文。
- 校对欢迎语、深入地下模式、万圣节欢迎语及其形容词／生物引用，补上旧译遗漏的形容词候选。
- 完整校对地狱效果的安静与有声消息，补上旧译遗漏的末条哀号等候选。
- 修正旧译中的语义偏差，例如 cyclopean cityscape 指庞大的巨石城市，而非“独眼巨人城市”；whinny 是嘶鸣，不是嗡嗡声；突现地下城的是玩家，而非巫婆的笑声。

术语使用“地下城”“佐特宝珠”“传送门”“鼻涕虫”“蠕虫”等。普通深处不套用“地底”分支名，普通痛苦不套用“剧痛术”，地狱喧嚣不套用能力名“不谐狂响”，空气也不套用装备属性“空气强化”。各匹配的原始术语与语境说明保存在预查清单及本记录中。

译文保存至 `localization/zh_CN/textdb.po`，由审核清单生成 `dat/database/zh/miscname.txt`。现行英文键、原始英文文件、权重、候选顺序与原始 Lua 块均不变；原 legacy 文件已保存在工作区本批基线中。

## 显示适配与英文回退

新增 `misc-display.h` 中的 `getPairedMiscString`，复用现有严格双语配对查询。欢迎语、地狱效果、召唤恐怖生物提示和丑角陷阱前缀都从英文库选择一次，再用对应的审核译文显示。递归形容词和万圣节引用不重抽；原有触发条件、效果、噪音和消息频道不变。

丑角陷阱先保留英文前缀与英文怪物列表，以供完整回退；中文模板只有在前缀和怪物列表均可显示时才使用。

地狱消息的 `you.can_smell()` Lua 程序保持英文原样，只执行一次。只有完整原始程序已命中审核目录、选中的中英文程序完全相同，且返回值属于两个已审核的完整原文时，才使用相应中文结果。未知程序或返回值仍输出该次英文结果，不执行中文程序、不再次调用原程序。其他 Lua、配置和命名接口不变。

源文正文变化或编译时发现相关代码依赖哈希变化后，相应 UI 译文被排除；缺少任何引用或组件时整句回退英文，旧覆盖文件不参与这个严格查询入口。

## 验证

新增原生测试实际加载英文与中文 TextDB，使用独立缓存 `.term-audit/database-04-runtime/`，不访问玩家存档。对 10 个键分别使用 256 个种子，覆盖能嗅闻／不能嗅闻两种 Lua 条件，比较：

- 原始 `getMiscString(..., true)` 与新路径的英文结果和后续随机状态。
- 中文完整性、递归引用、占位符与切回英文。
- Lua 回调次数与原始路径相同，单次消息最多调用一次，且两种结果均实际覆盖。
- 失效旧键、未知新键、含未审核正文的父条目、陷阱组件缺译的整句回退。

结果见 [检查记录](database-04-checks.json)：29 项翻译工具测试通过；149 项原生本地化测试、366,242 个断言全部通过；Windows Tiles 的 `crawl.exe` 编译成功。日志位于 `.term-audit/database-04-python-tests.log`、`database-04-build.log` 和 `database-04-tests.log`。尚未进行实际 Tiles 窗口视觉验收。
