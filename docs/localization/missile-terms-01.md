# missile 与 projectile 术语统一

按语境统一，不对英文作一对一替换：

| 语境 | 译法 |
|---|---|
| 飞行中的物理或魔法攻击载体 | 投射物 |
| 当前背包、拾取、帮助中的 Missiles 类别 | 投掷物 |
| 明确的配套消耗物资或旧版武器弹药 | 弹药 |
| 具体实体 | 箭矢、弩矢、弹丸、尖刺等 |
| throwing items 动作 | 投掷物品 |

“魔法飞弹”专名保留。泛称“飞射物”和非专名“飞弹”改为“投射物”；法术名统一为“偏转投射物”“传送投射物”，被动效果为“偏斥投射物”。手铳弹丸、金属弹丸、阴影弹丸等具体名称不变。

同步修正界面、日志、装备效果、法术名、怪物状态、帮助和 TextDB 正文。术语表修订 5 条现有译法，并新增 `missile`、`projectile`、`Missiles` 分类和 `ammunition` 4 条词项，注明多义语境和专名例外。`missile` 的“投射物/投掷物/弹药”是语境备选，不直接显示斜杠串。

英文消息、源码标识、TextDB 查询键及配置值保留；只改译文，不改游戏机制。导出后检查所有原有 TextDB 键仍然存在，并验证泛称残留与“魔法飞弹”例外。相关查询与逐条前后对照见 `missile-terms-01.json`。巫师说明中的实际配套弹药保留；备投栏自身的命名不属于本轮术语范围。

共修改 60 条 PO 译文，更新 10 份 TextDB 导出。143 个现有本地化测试全部通过，共 254,279 条断言；最终 Windows Tiles `crawl.exe` 编译成功。两处帮助分类的末轮校对另经 TextDB 导出校验。构建、测试日志位于工作区 `.term-audit/missile-terms-01-*`。尚未进行游戏窗口复测。
