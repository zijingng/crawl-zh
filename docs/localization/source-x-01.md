# x 开头核心源码显示文本覆盖

基线：0.34.1。日期：2026-10-24。

审查了全部 4 个既有 x 开头核心 `.cc` / `.h` 文件：`xom.cc`、`xom.h`、`xp-evoker-data.h`、`xp-tracking-type.h`。新增的 `x-display.h` 仅声明纯显示接口。第三方 contrib 源码不属于本批游戏显示文本范围。

## 覆盖范围

- `xom.cc`：佐姆的兴趣、愉悦程度、信徒身份变化、探测、礼物、怪物和武器变化、蛛网燃烧、环境与门变化、强化效果、混乱、召回真言、楼梯移动、末日、魔力流失、复活、潜行及少量巫师交互提示。
- 复核当前 `godspeak.txt` 的全部 120 个 `Xom ...` 条目，以及数字、舞蹈、杂技和稀有鳟鱼修饰语 4 个关联条目。原文全文模板、权重和递归引用作为 `x.speech` 词条登记；重复的全文模板共用词条。这里使用的是替换对象名称之前的原始模板，不解析已渲染的英文句子。
- `xp-evoker-data.h`：6 条有声／无声充能模板已由 `item-prop.cc` 的 `i.evoker` 适配覆盖，本批保留原始数据及充能键。`xom.h` 与 `xp-tracking-type.h` 只含规范接口、状态与枚举，不改标识。

本批登记 247 个 UI／模板词条，其中 242 个进入中文目录，5 个相同原译文的纯引用由递归子条目提供译文。登记与源码指纹见 `localization/manifests/source-x-01.json`。

## 术语查询与校对

沿用“佐姆、稳态、地下城、深渊、混乱、麻痹、正在石化、疾速、召回真言、恶魔植物、毒蘑菇”等术语；普通词与法术、能力专名按语境区分。未修改术语表。

原始源码的术语命中及术语表指纹见 `source-x-01-preflight.json`，对白条目的逐项来源、选项数量与术语命中见 `source-x-01-speech-review.json`。校对时修正了旧译将 Abyss 译成“地狱”、漏译随机选项及“地下城／战狂／折磨”等不一致用语。

## 英文回退与随机行为

保留原始英文数组、信徒身份生成、对象名称、冠词、所有格、动词变化和单复数表达。中文动态消息从原始怪物、物品、地形、附魔状态和计数取得参数；缺少任何必要译文时，整句使用原英文。

`database.cc` 新增成对白取值接口：只按英文权重选择一次，中文使用同一个权重位置；递归引用也共用同一次选择。中英文同时保留，物品、地形和身体部位占位符分别替换。`[a|b]` 子选项沿用英文的随机索引；译文权重／选项不一致或组件缺失时，使用保留的英文副本。已有 `getSpeakString()` 及其他神祇的调用路径保持不变。

佐姆原始模板使用当前源码指纹校验，原文变化后不会重新启用旧版中文 TextDB 中的过时译文。只含引用的模板没有额外的句子译文，但仍要求所选子条目完整可译。

嵌入 Lua 只执行原程序一次；不透明的 Lua 返回值、未审查的共享子条目及未知身体部位会使整句保留英文。含动态涂鸦名称的消息也保留英文，避免猜译生成后的名称。这些属于明确的回退边界。

环境与强化效果的中文列表从实际计数和实际施加的效果构造，不解析英文列表，不重新施加效果。笔记、神祇／事件规范名称、伤害来源标识、巫师统计文件和技术诊断保留原英文。

## 验证

Windows Tiles 已编译为 `crawl.exe`。本地化原生测试覆盖英文模式、中文模式、缺失参数／递归子条目、过时随机选项、当前 120 条源模板实际命中、源模板变更后的旧译屏蔽及随机状态一致。具体测试数量与保留检查见 `source-x-01-checks.json`。

另外核对了 6 个规范接口、58 个笔记调用、17 个文件输出调用及 18 个效果创建调用保持不变，其他 3 个既有 x 文件全文不变。未进行游戏内视觉冒烟测试；Console／WebTiles 未单独编译。
