# database 第 51 批：固定等级随机书名

本轮处理已经通过数据审核、但尚未接入显示的书名结构；没有把旧译文重复计算为新增翻译。翻译和适配前查阅术语表及 15 组相关词库，记录见 database-51-preflight.json。

## 显示范围

接入 starting、easy、moderate、difficult 四档书名及 _difficult level book owner_ 共享模板，共 86 个原始加权候选。包括初等魔法、入门课程、进阶指南、最终著作、档案与赠书等格式。

匹配缓存英文书名时复现上游首字母大写，以及作者存在时移除 The／A／An 的规则；等级 One 至 Nine 作为有界数字参数显示为中文数字。已知作者、神名和当前玩家姓名继续复用既有显示词典，个人玩家名保留原拼写。赠书目标只接受当前玩家的规范姓名，不猜译其他名字。

译文、模板、书籍名词和魔法主题均来自已审中文 TextDB，不在 C++ 中再维护一份正文。显示层不重新生成名称、不执行随机选择、不修改书籍属性或存档。原有学派主题书名仍优先走既有路径。

## 校对与英文回退

统一 _book_magic_ 中 Magical Power 的直接译文为“魔法的力量”，与 Magical 形容词加 Power 的展开保持一致。此前两条路径分别为“魔法之力”和“魔法的力量”，会被严格词典判为歧义并回退。本轮仅改这一键；精确同步五处旧译文匹配的构建依赖，其他 71 键译文不变。

未知作者、未知魔法主题、无效卷数、赠书目标不符、缺少任何已审模板或子词库、无法唯一完整匹配时，保留原英文书名。十卷及阿拉伯数字卷号不作为当前上游一至九等级生成格式接受。英文模式保持原输出。
