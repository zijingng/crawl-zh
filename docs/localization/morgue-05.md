# morgue 冻死等死因与受伤记录补译

翻译前核对术语表中原生胶体、冰冻、灼烧、吸能、腐烂、离散术等条目，并复用已有怪物、攻击名称和固定死亡译文。见 [预查记录](morgue-05-preflight.json)。本轮新增 21 条已审模板／短标签。

## 死亡信息

原实现只翻译了没有来源与附加说明的固定死因。例如 `Frozen to death` 已有译文，但 `Frozen to death by an endoplasm` 因带怪物来源而整段回退。

本轮补齐带来源的冻死、焚烧、生命吸干、腐烂、离散、酸液及与怪物相撞致死。带附加效果的死亡会同时核对怪物名和攻击名，例如杰西卡的黏附火焰。伤害数字与需要显示的击退归因保留。无法识别的组件、召唤归因和未处理的失能条件继续保留完整英文死亡段。

`death_description`、成绩原始行和英文文件生成入口保持原样；中文只经显示适配返回。既有死亡笔记带有规范成绩快照时，也可使用本轮新增适配重新导出中文。

## 非致死受伤记录

`HP: 1/21 [frozen (2)]` 是受伤笔记，不能用“冻死”翻译。新受伤记录保存最小规范死因快照，中文显示中把冻伤、灼伤、吸能、腐烂、酸液、窒息、倒刺、镜像伤害、跌下楼梯／传送门与死亡措辞区分，并保留原有伤害数字。

此快照只保存原始死因、来源、攻击名、归因与数值，不调用完整成绩初始化，不改变鉴定、RNG 或计算角色统计。不可见来源仅保存伤害数值，继续隐藏来源身份。笔记的原英文 `name` 保留，附加数据写入已有 `desc`，存档版本不变。

显示前必须能从快照重建整条原英文受伤原因，再使用已审短标签；不支持的额外攻击说明、损坏快照和旧的无快照记录保留整条英文，不从历史英文句子猜测参数。

## 输出与验证

Windows Tiles `crawl.exe` 与原生测试程序编译成功。13 项原生测试共 866 条断言、33 项 Python 本地化检查通过。此前三份英文测试记录逐字节不变。

`.txt`／`.lst` 英文输出、`.zh.txt` 中文文件及中文高分榜的文件回退维持原方案。已有静态 morgue 文件不会自动重写。验证包括用户示例的实际双语冻死记录、非致死措辞、数字、存读往返、伤害专用对象、缺项整段回退、英文记录与 RNG 不变；结果见 [检查记录](morgue-05-checks.json)。
