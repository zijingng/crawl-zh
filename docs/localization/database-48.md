# database 第 48 批：涂鸦复核与随机作者显示

本轮翻译前逐键查询术语表，并对照英文复核 graffiti.txt 全部 58 键、404 个加权候选。这些键此前已经进入已审 TextDB；本轮是旧译校对和实际显示补缺，没有重复计作新增译文。预查记录见 database-48-preflight.json。

## 校对

修正 10 键中的用词、句法及对象关系：魔棒改为魔杖，唤发物品改为可唤发物品，shadow wraith 依术语表改为暗影幽灵，berserk 语境改为狂暴；potion makers 按原义改为药水制作者。调整文字粗细、商品质量及个别评论表达。复仇原因的 them 原先误译为自己，现保留第三人称指代为那人，避免将受害者误作加害者本人。具体前后文见 database-48-data-checks.json。

## 随机作者显示

原实现遇到 @RANDGEN@ 即将整句标为不可翻译，导致有中文模板的署名、广告、改名、信仰评论及复仇消息仍可能显示英文。本轮在装饰消息显示适配器中，按英文原有顺序生成每个名字一次，并将同一个拼写放入对应中文占位符。连续出现的多个占位符仍独立生成姓名，不复用第一个名字，也不增加随机抽取。

译文占位符数量不符、原消息不完整、未知占位符或不支持的人体部位，继续整句回退英文。神名、技能名仍使用原有类型词典，英文路径和随机抽取顺序不变。规范数据、姓名生成池、存档身份及英文原始文件不变；中文正文仍仅维护在 textdb.po，导出文件只含已审条目。

上游 _graffiti_vengeance_ 中不存在的 @graffiti_author_any@ 引用继续保留，遇到它仍回退整句英文。作者个人姓名保留规范拼写不等于句子漏译。58／58 键的数据审核不意味着修复了所有上游数据问题。

## 集中验证

全批修改完成后统一构建 Windows Tiles crawl.exe，并集中验证涂鸦所有键、喷泉引用、神名与技能名、多个独立随机作者、姓名数量不符、缺译、英文切换及后续随机状态。没有运行耗时的全部怪物对白随机矩阵，也没有进行 GUI 目视测试。实际结果见 database-48-checks.json。

构建成功。32 项 Python 工具测试通过；5 项相关原生用例经针对性重跑后均通过。原涂鸦测试要求抽样必须出现英文回退，此断言在显示修复后不再成立，已改为确定性未知引用回退检查。最后重跑 2 项、39746 次断言，耗时约 9.736 秒。
