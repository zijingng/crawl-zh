# 固定专名、先祖与涂鸦署名

## 显示规则

固定名称优先使用 `localization/zh_CN/textdb.po` 中经过校对的译名；查不到时才调用已有的机器音译。音译也无法处理时，沿用现有整句英文回退。英文模式不改变姓名、正文、随机选择或随机数消耗。

`dat/database/monname.txt` 的 52 个键全部纳入导出，覆盖 790 个固定姓名选项（786 个不同拼写）。保留原始引用、选项次序和权重；不修改上游英文库。新增的中文文件由构建工具生成，不另在 `ui.po` 维护姓名副本。

翻译前查询术语表，沿用 `Ignacio＝伊格纳西奥`。固定专名补入术语表；`Wolf` 区分普通怪物“狼”和人名“伍尔夫”。女性姓名表的 `Li` 定为“丽”，这属于本项目选字，不声称能从罗马字唯一恢复原字。日本、韩国等姓名同样采用本项目固定写法；有异体或重名的条目保持一致。

## 覆盖路径

- 兽人使徒：完整名称、头顶标签、使徒菜单、相关动态消息及使徒尸体名称。
- 先祖：新自动生成的姓名、四种先祖形态、相关提示和事件发生时生成的中文 note。
- 涂鸦：普通姓名、先祖姓名、兽人姓名，以及本文件额外的 12 位署名者（含称号）。`@RANDGEN@` 先按原顺序生成英文名，再产生显示音译。
- 武器之灵：欢迎、告别，以及新产生的系统姓名铭文；玩家自行修改铭文后不再翻译该铭文。

姓名字典直接读取同一份中文 TextDB，不生成另一张 UI 姓名表。查字典不执行 Lua、不生成姓名、不消耗随机数；缓存随数据库关闭清理。姓名生成接口显式只读取英文库，存档属性、唯一性比较、Lua 和协议中的规范身份保持英文。

## 手动名称与旧存档

新先祖仅记录一个自动原名标记，不保存怪物或事件快照。玩家改名后删除此标记，输入即使与词库同名也原样显示。旧存档没有可靠来源标记时也原样显示，避免擅自改写玩家名字。其他自定义怪物、玩家幽灵和玩家铭文不进入自动姓名翻译。

新武器之灵自动附加姓名铭文时记录布尔标记；手动编辑铭文后删除标记，只翻译仍然由系统管理的末尾姓名，保留其他铭文内容。

## 验证

Windows Tiles 的 `crawl.exe` 和原生测试程序编译成功。独立运行以下测试，合计 52,773 条断言通过：

- `[monname-reviewed]`：13,614 条；全部姓名选项、52 个键的双语配对、规范生成与随机流、固定译名优先及音译兜底。
- `[monname-owners]`：31 条；先祖形态、手动名保护、系统与手动铭文、英文回退。
- `[orc-apostle-names]`：52 条；使徒实际显示、菜单、标签及规范存档名。
- `Reviewed graffiti colours*`：39,076 条；真实涂鸦与喷泉渲染、随机署名、英文回退和随机流。

TextDB、目录生成、术语审查工具和跨平台源码指纹共 35 项 Python 测试通过。姓名库导出 52/52，涂鸦导出 58/58，无依赖导致的漏导出；已审源码依赖失配为零。

本轮未启动交互游戏做画面检查，也未编译 Linux WebTiles；相关名称适配位于各版本共享的 C++ 显示路径。

## 正文内嵌姓名补漏

补齐 `_graffiti_happened_reason_`、`_graffiti_rumour_`、`_graffiti_short_saying_` 正文直接写出的 Plog，按既有术语统一为“普洛格”。英文正文不变。去掉引用标记、权重和格式标签后，涂鸦中文正文无残留拉丁字母。重新导出 58/58 键，实际涂鸦与英文回退测试 39,076 条断言通过。

## 先祖初次显现提示补漏

`_handle_piety_gain()` 中的生命精华／先祖记忆提示此前将 `mg.mname` 作为原样文本传入，现改用 `ui_ancestor_name_arg()`。例如自动姓名 Rodica 显示为术语表中的“罗迪卡”；玩家手动姓名继续原样显示，英文提示和规范姓名均不变。
