# 锤子外观与寒冰效果移动确认

修改前核对术语表及现有译文：`Frozen Ramparts` / `Ramparts status` 为“冰霜壁垒”，`icy armour` 的既有状态译文为“寒冰护甲”；`hammer`、`scythe` 的既有物品译名为“锤子”“长柄镰刀”。后三项补入术语表。

hammer 是地图或背景使用 `itemname:hammer` 为钉头锤设置的可见外观，scythe 是同类的长戟外观。基础物品译名已存在，但未鉴定路径查的是 `display.item.appearance`，缺项导致整个发现句回退英文。新增两种外观的基础、发光、刻符文等现有修饰组合，共 48 条；不改变物品规范名称、数据库键、鉴定状态、属性和随机行为。自定义未知名称仍保留英文。发现提示、物品列表和其他复用物品显示名的界面共同受益。

移动前确认原先直接拼接 `icy armour` / `frozen ramparts`，未接入翻译。保留原英文字符串的构造，再通过完整模板显示“移动会使你的寒冰护甲和冰霜壁垒失效。继续吗？”。单项效果只显示该项；任何效果名或模板缺译均整句回退原英文。安全判断、默认拒绝、取消移动和效果消失逻辑不变。相邻的倒刺移动确认、传送门确认及实际移动后的消失消息已有翻译，未重复增加目录。

回归用例覆盖两种外观的普通、发光、刻符文、已鉴定名称，发现提示的中英文输出、未知外观回退、未鉴定时不泄露附魔数值；移动确认覆盖两种单项、两项同时生效、未知效果导致整句回退及英文模式。检查随机状态不变。

验证结果：两项原生用例共 80 条断言通过，47 项 Python 检查通过，已审 UI 来源依赖失配为零。Windows Tiles 的 `crawl.exe` 和测试程序均已编译成功。
