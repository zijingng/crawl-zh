# database 第一批续译：施法失误与怪物称号

## 范围

翻译前逐条匹配 `localization/glossary.csv`，保存术语表 SHA-256、每条英文正文哈希和命中记录至 [预查清单](database-01-preflight.json)。本批不改动英文数据库文件。

| 文件 | 本批结果 |
| --- | --- |
| `database/miscast.txt` | 33 / 33 条补译；11 个学派分别覆盖玩家、可见怪物和不可见目标消息 |
| `database/montitle.txt` | 86 / 86 条逐条校对，补齐 5 条缺译，并统一称号中的怪物译名 |

共新增 38 个缺译条目，另校对原有 81 条称号。一个 TextDB 条目通常含多条随机候选，并不等同于一条日志。译文保存于 `localization/zh_CN/textdb.po`，由 `textdb-phase3.json` 导出至 `dat/database/zh/`；供动态显示使用的正文另进入已审核 UI 目录。

补齐的称号包括卡珊德拉、无名氏、斯普罗兹、威格拉夫及扎克克里克西斯。原有称号按当前英文校正，例如 Arachne 的 Outcast 改为“遭放逐的”，Gastronok 的 Ponderous 改为“笨重的”，Terence 的 Veteran 使用“老兵”。首次发现日志与描述页使用同一份校对结果，规范怪物名和查询键保留英文。

## 术语与语境

怪物名以术语表为准，例如阿格尼斯、艾祖尔、阿玛埃蒙、格洛克斯·弗洛克、约瑟菲娜、瓦莎妮娅等。地名使用悲叹河、欣嫩谷、塔尔塔罗斯和魔窟。

施法失误中的普通 fire、ice、air 不采用装备词条的“火焰强化／寒冰强化／空气强化”；Pain 在疼痛语境下使用“疼痛／痛苦”，不套用法术名“痛苦术”。炼金失误中的盐为普通物质“盐”，不采用云类别名称“盐尘”。这些匹配的语境取舍记录于预查清单和本说明，未机械替换术语表命中。

## 英文回退与随机行为

`spl-miscast.cc` 使用现有严格双语配对查询，只选择一次英文加权候选和方括号随机选项。新增 `render_miscast_message` 将原有手部替换、怪物替换和伤害标点保留在原有顺序中。译文复用同一身体部位结果，不再次调用随机身体部位逻辑。没有可用正文、身体部位、怪物名或标点译文时，整句输出原始英文。

怪物所有格占位符本身已提供“的”，译文不重复添加；中文伤害标点使用现有全角句号和感叹号。切回英文后保留上游英文句子、所有格、手部动词变化和伤害标点。

以下为本批完成时的回退边界；随机颜色库已在 [第二批](database-02.md) 补齐：

- 引用尚未翻译的随机颜色库时，该次完整消息回退英文。例如部分妖术、炼金术失误候选；其他不依赖颜色的候选可正常显示中文。
- 无躯体怪物的原有英文会省略身体或皮肤措辞；在相应中文语法尚未审核前，该类目标整句回退英文。
- 上游变更正文或相关渲染代码后，审核哈希不匹配的 UI 译文被排除，旧的中文数据库正文不能绕过严格配对入口复活。

## 验证与剩余范围

检查记录见 [database-01-checks.json](database-01-checks.json)。新增原生测试覆盖全部 33 个失误键，使用玩家及杰西卡、混沌孳生体、火焰之球等目标，在多个随机种子及伤害等级下比较旧英文算法、英文模式、新中文路径和随机状态；另检查缺译及旧中文不能复活、未展开标记和重复“的”。

最终结果：翻译工具 29 项单元测试通过；原生本地化 145 项测试、260,613 个断言全部通过；Windows Tiles 的 `crawl.exe` 编译成功。构建与测试日志保存在工作区 `.term-audit/database-01-final-build.log`、`.term-audit/database-01-final-tests.log` 及 `.term-audit/database-01-python-tests.log`。

本批尚未完成整个 `dat/database`。初始按键覆盖清单保存在预查记录中，后续主要包括 `monspeak.txt`、`decorlines.txt`、`insult.txt`、随机命名库、颜色与涂鸦库，以及已有中文文件的部分遗漏。初始统计只表示中文文件中是否存在同名键；例如部分佐姆消息已有 `x.speech` 运行时译文，不能将未导出的键一概认作游戏内缺译。
