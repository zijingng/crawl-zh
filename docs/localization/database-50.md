# database 第 50 批：剩余顶层命名模板

翻译前逐项查询术语表和已审引用词库，本轮新增 randname.txt 剩余 14 键、184 个加权候选。包括普通武器、防具、首饰、变形护符，特洛戈武器、奥格瓦如武器及防具、佐姆武器及防具和首饰模板。randname.txt 全部 33／33 键完成数据审核，导出范围改为 whole_file；原有 19 键译文保持不变。

正文只维护在 textdb.po；生成目录只含通过审核和来源依赖检查的译文，英文规范键、候选顺序、权重、引用及原文文件均保持不变。大小写别名如 @Okawaru armour@ 保留英文键。

## 动态显示

补齐分支名、神名本身、特洛戈愤怒词组、当前玩家姓名所有格的英勇与厄运词组、动词水果组合，以及佐姆单动词、双动词和形容词称号。分支、神名复用现有类型词典；玩家姓名沿用规范原拼写。

佐姆两处动词分别匹配缓存英文结果，不假定同一个占位符重复出现就一定是同一个词；同时验证两次选择相同词的情形。没有重新生成名称，不增加随机抽取，不修改存档属性或英文生成时的长度筛选。

已有完整称号优先于新增通用拼接：例如 Ceneedgh's Death 沿用完整后缀的“Ceneedgh之死”，避免另一路径拼出“Ceneedgh之死亡”而产生歧义。神名和分支名新增查询只在已有普通路径未命中后进行。缺译、未知词、未知姓名及无法完整匹配的组合保留英文称号，英文模式保持原输出。

## 覆盖边界

目前 dat/database 的 23 份原文文件中，22 份的全部原文键都有已审中文导出；唯一没有中文导出的 monname.txt 为 52 键规范人名生成池，继续保留英文身份。本统计是数据审核覆盖，不等于所有动态形式均已接入显示。

随机书名的固定等级等结构、部分佐姆长神名及复杂神器组合仍需继续接入。armour 原文有一个候选含两行模板，本轮保留它的候选和换行结构，不擅自修正上游数据；无法完整识别时仍按原文回退。不会把这些情况算作动态显示已全部完成。

## 集中验证

Windows Tiles crawl.exe 编译成功。32 项 Python 工具测试、8 项相关原生回归全部通过，共 198,575 次断言，原生用例约 2.38 秒。覆盖分支名、神名、玩家名、佐姆两次动词、真实神器显示、英文切换、原存档名称、未知组件回退，以及十四个生成入口的英文结果和后续随机状态。没有进行 GUI 目视测试。
