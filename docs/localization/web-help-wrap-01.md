# WebTiles 帮助窗口宽度

此前 Ctrl+F 搜索帮助和巫师模式 &m 的 ? 帮助已通过移除 `FS_PREWRAPPED_TEXT` 在本地 Tiles 中自动换行，但 WebTiles 协议未传输该标志，网页仍按 `white-space: pre` 排版，长行将居中窗口撑出视口。

现在 formatted-scroller 消息新增布尔字段 `wrap_text`，与本地相同标志对应。网页仅在该字段严格为 true 时启用 `wrap-text` 类，保留换行符、允许长行与连续字符折行，并将宽度限制为 80ch 和当前视口扣除弹窗边距、内边距及边框后的较小值。小高度视口沿用现有的较小边距。未提供字段的旧服务端，以及地图、表格等预排版窗口仍使用原格式。

没有修改帮助正文、翻译、英语路径或按键语义。服务器需重新编译 WebTiles，并部署对应版本的 `ui-layouts.js` 和 `style.css`，然后刷新网页。

使用无界面 Edge、实际样式和实际 SimpleBar 库，对两份现行中文帮助及连续长词进行了布局验证。774px 视口中，原两窗口宽度为 2238px、2478px，左侧坐标为负；修复后宽度均为 628px，左右边界在视口内。496px 视口下宽度为 410px，正文无水平溢出。Node 测试执行实际 AMD 窗口创建路径，验证 true、false、缺失字段及非布尔值的处理。详细数据见 [检查记录](web-help-wrap-01-checks.json)。本轮未执行服务器 Linux 编译和在线游戏验收。
