# m 开头核心源码显示适配

基线：0.34.1。日期：2026-10-24。

排查范围为核心源码顶层原有 102 个 m 开头 `.cc/.h` 文件，新增 `m-display.h` 后共 103 个。本批接入、校对 2,636 条译文，包含复用的名称与句子片段，并非 2,636 个新增独立画面。

## 术语与覆盖

翻译前按源码提取术语表命中，记录于 `source-m-01-preflight.json`；形态简述补充命中见 `source-m-01-terse-preflight.json`。本轮额外修正的 57 处术语记录于 `source-m-01-term-review.json`，按实际语境区分普通词与法术、能力专名，未机械替换同形词。

覆盖主命令、菜单、宏与按键提示、地图探测与数量、近战及法杖消息、怪物行动与施法、抗性反馈、死亡与复生、物品生成和发现、变异说明与形态/种族特征、怪物列表状态与详细说明。变异涵盖有效等级、数值、临时/压制标记及简述；怪物状态涵盖伤势、属性、装备、缠绕与被缠绕。

“防具、躯干防具、护甲值、闪避值、格挡值”遵守 README 方针；专名和学派使用术语表。逐文件范围、变更情况及源码指纹见 `source-m-01-files.json`，译文与依赖见 `localization/manifests/source-m-01.json`。

## 英文回退与游戏状态

英文生成逻辑保留，中文从相同对象、数量和既有计算结果组成完整句子。必要名称、状态或模板缺译，或源码依赖指纹过期时，整句或完整列表行回退英文。语言切回英文时保留英文语法、名称及措辞。

辅助攻击、变异和法杖的规范描述接口默认英文，由界面调用点显式请求显示译文。Lua 返回值、数据库键、配置、命令标识及存档字段保持原语义。没有全局拦截消息流或任意 Lua 输出。

动态事件复用原有随机结果、已捕获的对象和数值，不重复触发法术、游戏效果或 Lua。怪物缠绕名称只保存在临时显示快照中，序列化仍使用原字段；旧缓存缺少显示元数据时回退英文。共享的能力、描述、输出和目标说明调用点同步接入显示接口。

## 保留范围

调试、向导功能、技术错误与开发诊断、第三方依赖不纳入普通游戏显示覆盖。任意脚本、自定义 TextDB 对白及跨文件传递的规范事件参数沿用原机制；无法取得完整中文组成部分时保留完整英文，不猜译运行时文本。

## 验证

最终构建、原生测试、Python 工具测试、PO/生成目录一致性及全局源码指纹结果见 `source-m-01-checks.json`。回归包括所有有效变异等级、辅助攻击、怪物状态与描述、缺译整句回退、语言切换、随机状态，以及中文显示快照不改变存档字节且不会被读回。

本批未进行游戏内视觉验收；Windows Tiles 使用原 `crawl.exe`。
