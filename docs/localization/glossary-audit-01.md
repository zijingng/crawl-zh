## 多义词回写

在 [glossary.csv](../../localization/glossary.csv) 中补充 **60 条**多义或不同词性、不同对象的译法，词条总数仍为 1,707。保留原规范译名在第一位，其余译法用 `/` 分隔，具体条件写入 Note 列。例如：

| 英文 | Translation | 使用条件 |
| --- | --- | --- |
| manual | 手册/手动 | 技能书籍／操作或训练模式 |
| slug | 鼻涕虫/弹丸 | 生物／手铳射出的弹丸 |
| Shield | 格挡值/盾牌/保护 | SH 属性／装备名词／保护动词 |
| staff | 法杖/工作人员 | 武器／人员集合 |
| Will | 意志/将会/会 | 抗性属性／助动词 |
| Pain | 痛苦术/痛苦 | 法术标题／印记、卡牌或普通感受 |
| Arena | 奥格瓦如竞技场/竞技场 | 分支／怪物模拟模式或普通场地 |
| aptitude | 技能天资/天资 | 独立标签／自然语言描述 |

完整变更与语境说明见 [glossary-senses-01.json](../../localization/manifests/glossary-senses-01.json)。这些译法不能脱离 Note 任意互换。完整专名优先于其中的普通单词，尤其不能把“竞技场”模拟模式认作奥格瓦如分支，也不能把每个动作词都译成带“术”的法术名。

斜杠仅用于术语表表达备选义项，不作为游戏显示文本。运行时仍从 PO 读取完整译文。防具、躯干防具和护甲值的既定区别保持不变，没有将旧译或所有近义词一并列为可接受译法。

## 保留候选的原因

最终 1,717 个候选中，1,514 个由规则归类，174 个补充语境分类，29 个为保留的英文可执行示例或标识符。分类表示本轮保留理由，并不表示这些条目都存在翻译错误。

- 同一单词嵌在更完整的专名中，如卡牌名、神器名或其他法术名。优先使用完整专名。
- 法术名与普通动词、属性名与普通描述重合。中文可调整词性、语序或省略已知对象。
- 引言的文学措辞、历史引文和书目信息不机械套用游戏机制术语。
- Lua 函数、查询键、颜色和条件标签、巫师模式参数及英文搜索示例须保留规范拼写。
- 部分中文通过代词、前文或完整名称表达含义，不要求每次重复英文中的每个名词。

“已归类”是对这一版文本的记录。英文、译文或术语变更后，应重新扫描并复核；不能将这些分类无条件用于未来文本。

## 重复检查

在仓库根目录运行（MSYS2 MINGW64，需 Python 与 GNU gettext）：

```sh
python tools/localization/audit_glossary.py \
  --report localization/manifests/glossary-audit-current.json
```

工具默认读取 UI、TextDB 两份 PO，以大小写不敏感的英文完整词或短语匹配，使用 ASCII 标识符边界，避免把 `Will` 命中到 `willpower` 或下划线标识符内部。读取 Term 列，不自动推导复数、动词变化或 Variants 列别名。Translation 用 `/` 拆为备选项，任意一项出现在中文中即通过本项字面检查。短词命中和不同位置的巧合命中仍须结合上下文判断。

输出保留相互重叠的术语、引言及代码示例，便于审查。工具只生成候选，不自动改译文，也不把候选数量作为构建失败条件。重新运行所得 JSON 不自动继承本轮保留判断。
