# 七处界面漏译与错名修复

日期：2026-10-25。基线：0.34.1。

## 修复范围

1. **开始界面的存档列表与默认存档提示**：新增纯显示摘要，使用存档头部的种族、背景、等级和神祇元数据。当前普通角色显示为 `Ceneedgh，3级牛头人战士`；保留角色专名、文件名、排序、选中结果及原始存档摘要接口。历史／自定义元数据与现行规范名不一致时整行回退英文。巫师徽记保留原标记，以兼容现有徽记拆分逻辑。
2. **Tiles 物品栏鼠标悬停名称**：`InventoryRegion::draw_tag()` 的地面物品与背包／装备物品接入既有物品名称适配；原先只有详细提示已适配，底部短名称仍直接调用英文 `item.name()`。缺译时保持原来的描述级别、物品栏字母及装备注释。
3. **载入欢迎语**：`main.cc` 的正式游戏入口新增使用姓名、种族枚举、背景枚举的中文显示路径。例如 `欢迎回来，Ceneedgh（牛头人战士）。`。缺少整句或角色组件时，继续执行原有英文流拼接。
4. **Tiles 地形悬停短标签**：`get_cell_mouseover_tag()` 接入已知地形、怪物和物品显示接口；记忆地形仍保留方括号，不改变可见性与地图知识。另补齐地图操作提示中的怪物名称。
5. **说明查询中的地形全部显示“战斗”**：原因是 `str_to_skill_safe()` 会把任意无效技能名转换成 `SK_FIGHTING`。显示分类改用失败时返回 `SK_NONE` 的 `str_to_skill()`，使地形继续走地形解析。技能“战斗”的正常查询不受影响，菜单键与过滤键仍使用规范英文。
6. **自动战斗／自动施法的无目标消息**：英文来自 `dat/clua/autofight.lua`、`automagic.lua`。增加显式的 `crawl.ui_translate(context, source)` 接口，并适配视野内无目标、无可接近目标及射程内无目标三条消息。没有自动翻译任意 `crawl.mpr()` 输入；Lua 控制流程及英文消息均保留。
7. **`The tarantella` 等冠词名称混入中文喊声**：喊声保留同一次选择得到的中英文模板，英文路径先按原逻辑展开一次；中文的怪物名称和所有格从原始怪物对象取得。已复核两条蜘蛛腿模板及占位符，例如 `塔兰泰拉的多条腿轻轻窸窣作响。`。无法处理的递归组件、随机片段或其他占位符整句回退英文，不二次运行英文替换或随机选择。

## 术语与回退边界

修改前查询术语表，沿用“牛头人、战士、塔兰泰拉、战斗、物品栏、地下城冲刺”等译法。术语表未修改；命中和基线指纹见 `ui-fixes-01-preflight.json`。16 条新增译文及源码依赖登记在 `localization/manifests/ui-fixes-01.json`。

`player_save_info::short_desc()`／`really_short_desc()`、存档文件名及用于 JSON 的规范英文摘要均保留。不会尝试翻译或音译任意生成的角色专名。

`do_mon_str_replacements()` 保持不变。喊声的声音强度、唤醒、提示和原始英文替换调用保持不变。公共怪物名称适配改为读取 `MILEV_NAME`，避免为显示名字执行威胁／经验等完整信息计算；回归测试验证随机状态不变。
