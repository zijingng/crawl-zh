# l 开头核心源码显示适配

基线：0.34.1。日期：2026-10-23。

已排查游戏核心源码顶层全部 61 个 l 开头 `.cc/.h` 文件。本批接入、校对 296 条译文，其中包括 237 个状态与 20 个被动效果的查询名称。译前术语命中和源码指纹见 `source-l-01-preflight.json`；逐文件范围见 `source-l-01-files.json`；名称校对依据见 `source-l-01-name-review.json`；验证结果见 `source-l-01-checks.json`。译文及依赖清单为 `localization/manifests/source-l-01.json`。

## 说明查询

`lookup-help.cc/h` 补齐查询提示、符号查询和学派查询说明、精确匹配提示、无匹配结果及空白查询提示。查询参数使用原始类型与用户输入，英文冠词和复数仍由原有英文逻辑生成；中文使用完整模板。取消查询用的 `Okay, then.` 是内部流程哨兵，保持原值。

新增显示适配器覆盖技能、能力、卡牌、分支、地形、变异、灾厄、状态和被动效果的结果名称，以及通用说明标题。法术名称复用已有译文；地狱巨蛇的分支标记从怪物类型与分支取得。原有物品、怪物、神祇与云雾显示继续使用其既有适配器。

菜单条目保留规范英文文本与数据库键，中文只通过显示方法提供；菜单筛选同时包含原文和中文。法术菜单不再将中文直接写入条目的规范文本。数据库后缀的处理属于原有规范键解析，没有从拼好的英文描述中反推对象。

237 个状态名称沿用已校对的持续效果、形态名称，并补齐缩写和特殊标记；20 个被动效果按其定义提供名称。术语按命中使用“灼热射线、坟墓之爪、骗子宝珠、犬类使魔、神圣护盾、守护之灵”等。`-GClaw` 表示尚未收集足够死亡能量，使用“坟墓之爪尚未充能”；`Gem (*)` 表示本分支宝石仍完整；水域状态兼容站立、游泳或飞越，不统一误写为身处水中。

名称缺译时保留原来的完整条目。查询语法、数据库键和 `@` 学派匹配规则不变；没有新增中文学派解析或改写正则表达式。

## 分支附加说明

补齐分支入口所在父分支和层数范围、进入或离开所需佐特符文数量、分支/传送门层数、深渊可能进入的深度，以及子分支入口列表。

原有英文构造保留，中文从分支表、数量和原有计算结果取得参数。深渊深度只计算一次后供两种显示使用；缺少父分支或任一子分支名称时，相关完整句子回退英文。噪声与分支符文说明复用已有显示适配。

## 载入画面与 Lua

`loading-screen.cc` 补齐载入完成和三个载入阶段的显示，并用实际显示文本测量最小宽度。共享调用点 `startup.cc` 同步处理消息区，避免画面已中文而同一阶段的消息仍是英文。

`l-item.cc` 在物品移除操作的固定消息边界翻译“回合结束、无效物品、尚未装备”；`l-you.cc` 翻译种族不可用的固定反馈。Lua 函数名、参数、返回的规范名称、错误结构及任意脚本生成的文本保持原语义，没有拦截 `crawl.mpr` 等通用输出函数。

## 其余文件与回退

其余 Lua 绑定、地图生成、视线与射线算法、终端和 GUI 后端、类型声明均逐文件排查。技术诊断、调试/向导功能、Lua 交互解释器提示、配置和存档标识保留英文。`lang-fake.cc` 的可选伪语言替换规则用于处理英文，不改为中文词表。第三方依赖及生成的解析器不属于本批核心源码范围。

英文模式继续执行原有英文生成逻辑。中文所需模板、名称或源码指纹不可用时，整句或独立条目回退英文。显示适配不触发额外游戏效果、Lua 回调或随机选择。
