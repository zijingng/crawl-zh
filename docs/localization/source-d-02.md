# d 开头源码：第二批显示适配

本轮在修改前对 56 个非 `dbg-*` 的 d 开头顶层 C++ 文件查询了术语命中，使用现有 2,268 条术语。事前查询结果见 [术语预查记录](source-d-02-preflight.json)，本轮 192 个唯一目录项及逐条相关术语见 [译文清单](../../localization/manifests/source-d-02.json)。后者记录的短词命中用于人工判断，不是机械替换规则。

## 本轮覆盖

- **技能训练**：当前与基础技能等级、训练目标按钮、100%／当前／假设训练比例下达到目标所需的经验等级。原训练计算只执行原来的一次；中文复用已算出的等级、训练比例与经验差。
- **武器说明**：武器类别、长柄武器攻击距离、斧类横扫、短兵器刺杀优势、不同物种及四臂状态下的握持需求、法杖技能限制、躯干防具造成的攻击延迟。
- **装备比较**：卸下、穿戴、主手换武器、护符变形等比较标题；护甲值、闪避值、格挡值的增减与前后值；施法失败率变化和逐法术详情。使用同一组预览结果与原有排序，不重复执行装备预览。
- **伤害评级**：基础伤害、力量／敏捷倍率、技能倍率、附魔与杀戮加值及部分投射物附加效果。`damage_rating()` 默认返回规范英文，新增可选显示输出；物品详情显式使用显示副本，Lua 调用保持原默认参数。
- **防具与物品说明**：盾牌负担的三个等级、镜面盾反射几率、部分宝珠数值、武器和防具印记标题；同类装置合并、唤发技能与充能恢复、一次或多次充能耗尽后的完整说明、药水和卷轴稀有度、神祇反对使用物品的说明、通天塔光芒强度，以及装备诅咒与受增强技能列表。
- **其他详情面板**：能力显示标题、变异名称与等级的完整标题、厄咒影响的三个技能、持续时间与解除所需经验、龙人鳞片颜色。
- **艾申扎利与牌组**：面板物品名、诅咒名及按显示宽度计算的列对齐；叠放五牌菜单中的卡名；牌组已满时神祇无法继续发牌的完整消息。
- **怪物攻击表**：50 个不同攻击效果短语、攻击方式和附带武器名称、攻击次数、效果最大值、造成伤害后生效和攻击距离。规范攻击效果表、攻击类型和战斗数据不替换为中文。
- **格子环境**：圣域、沉默、光环、暗影光环、液化、魔法光芒、移位能量、伊莱德莱姆努尔领域及酸性黏液组成的完整环境描述。

技能、怪物、卡牌、法术、物品名称优先复用已有显示词条。例如沿用“防具／躯干防具”“护甲值／闪避值／格挡值”“作战球”“子炸弹”“沉默”“厄咒”，不另造一组平行译名。

## 英文与缺译回退

原英文完整构造及其输入保留。类别、握持、装备预览、详细施法失败率列表、诅咒技能列表和环境组合消息，在必要名称或模板不可用时回退对应完整英文段落／消息；独立表格字段可以分别回退。变异名称缺译时，标题与等级后缀一起回退。

伤害评级保持原默认英文接口；原有 Lua 数值和说明不随语言变化。中文显示复用已算出的伤害和倍率，不额外构造攻击、不增加随机抽取。神祇发牌消息也只使用原有随机循环产生的牌组集合。

本轮补正怪物属性表标签宽度、攻击方式和效果列宽度、艾申扎利物品／诅咒列的中文宽度计算。英文 ASCII 字段继续采用原文本与计算。规范名称、数据库键、Lua、存档、解析和诊断信息不汉化。
