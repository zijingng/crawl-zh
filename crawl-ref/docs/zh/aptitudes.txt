技能天资表

以下三张表列出各个种族对各种技能的全部天资。无论明确记住数值，还是凭经验了解
这些天资，都不是赢得 Crawl 的必要条件。想定性了解各个种族擅长什么，还可以：
- 阅读手册的种族部分，了解长处与弱点。
- 查看推荐的种族与背景组合。

 --  无天资，完全无法学习此技能
 -5  极其低下
 -4  很差，学习速度是天资 0 的一半
 -3  非常差
 -2  较差
 -1  稍差
  0  标准
 +1  稍好
 +2  良好
 +3  很好
 +4  出色，学习速度是天资 0 的两倍
 +5  卓越

另有四项特殊数值：生命、魔力、经验和意志。
- 生命表示每个经验等级获得的生命值百分比，以人类的 100% 为标准。
- 魔力表示魔力值的固定加减修正。
- 经验表示升到下一个经验等级所需的经验，以人类的 +0 为标准，数值尺度与技能天
  资相同。
- 意志表示每个经验等级获得的、抵抗许多魔法效果的意志，以人类的 +3 为标准。
