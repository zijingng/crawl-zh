宏与键位映射
==============

什么是宏和键位映射？简单来说：

命令宏把按键变成一串命令。
键位映射把按键变成其他按键。

更详细地说：

多数人需要的是命令宏。它可以让一个按键执行一串命令，例如施放某个法术，
而不必担心改变这个按键在提示框中的含义。例如，你可以把数字或字母设为宏，
却不必担心在丢弃物品时也发生替换。

键位映射用于解决键盘布局和行为问题。例如，把无法识别的数字键盘序列
映射为对应数字，或调整外语键盘布局，让操作更顺手。
楼层地图、选目标模式和确认提示还各有专用映射集，可以只在特定情境下生效。


如何创建宏与键位映射？
========================

最简单的办法是在游戏中操作：按 `~` 或 Ctrl-D，选择 `m` 定义宏，
再选择触发按键，输入命令序列。有些按键或组合键会显示成奇怪的数字，
例如 Return 键显示为 \{13}。这些数字是某些非字母数字键的按键码，
不同系统可能不同。

Crawl 默认已经为多数大小写字母和数字键分配了功能。虽然也可以重新映射，
但最好先用尚未占用的键，例如 Ins 或 F1 至 F12，也可以组合 Ctrl、Shift，
或同时使用这两个修饰键。有些系统还支持 Alt（Meta）。

定义键位映射的方法完全相同：按 `~` 后，不选 `m`，而是选 `k`（默认）、
`x`（楼层地图）、`t`（选目标）或 `c`（确认提示）。

定义后应先测试。如果用起来合适，就保存宏。要保存全部宏与键位映射，
按 `~`，再在提示中按 `s` 保存。


macro.txt 文件
================

宏与键位映射保存在 settings/ 目录的 macro.txt 中。
在初始化文件中设置 macro_dir，可以改变读写此文件的目录，
详情见 options_guide.txt。macro.txt 可以直接阅读和编辑；
但非字母数字键的按键码，可能需要在游戏中试验或借助外部工具确定。

以 `#` 开头的行是注释，会被忽略。请注意，Crawl 将宏与键位映射写回
macro.txt 时，不一定保留你的注释。

每个宏定义恰有两行。第一行定义触发键，由 "M:" 加该键的字符或按键码组成。
例如，A、Shift-A 和 Tab 可分别写成 'a'、'A' 和 \{9}。
第二行定义宏动作，由 "A:" 加关联的命令序列组成，例如 "zap" 表示
对上一个目标施放 a 栏位的法术。不同宏定义之间应以空行分隔。

定义键位映射时，将第一行的 "M:" 替换为以下前缀之一：
"K:"  默认映射，
"K1:" 楼层地图，
"K2:" 选目标，或
"K3:" 确认提示。


示例
======

下面的例子展示宏与键位映射的一些用途。为了完整，同时列出触发键行和
命令行；这些按键不一定适用于你的系统，实际使用时可能需要换成自己的键。


某些键盘布局默认无法正确输入 '@'。下面的映射把 '@' 映射到 '@'，
应能解决这个问题。

# @: display character status
K:\{17}
A:@


召唤师经常需要连续多次施放同一法术，每次又要按好几个键，可能有些烦人。
下面的宏用一个按键施放 'a' 栏位的法术。按 '=' 可以重新指定法术栏位。
再次提醒，F1 在你的系统上可能对应不同按键码。

# F1: cast spell 'a'
M:\{368}
A:za


解决了召唤，还需要指挥召唤物。下面的宏也能简化这项操作。
它假定 default_target 为 true；默认确实如此，详情见 crawl_options.txt。

# Tab: Order allies to attack your previous or the nearest target
M:\{9}
A:ta.


塑能师的施法宏略有不同，因为需要用 '.' 或 Return 确认发射。
这个宏同样假定 default_target 为 true。

# F1: cast spell 'a' at your previous or the nearest target
M:\{368}
A:za.


不过，塑能师也并非总想攻击上一个目标。下面这组宏可以施放 'a' 栏位的法术，
用同一个键循环选择目标，再用上例中发射法术的那个键确认。
本例也展示如何利用同一按键在不同映射集中可以具有不同功能的特性。

# Shift-F1: cast spell 'a'
M:\{1392}
A:za

# Shift-F1: cycle through targets when in targeting mode
K2:\{1392}
A:+

# F1: fire at target when in targeting mode
K2:\{368}
A:.
