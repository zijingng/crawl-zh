
注意：若图形版 Dungeon Crawl Stone Soup 明显变慢或卡顿，请阅读文末的性能说明。



图形版专用操作
--------------

你可以用键盘命令或鼠标与周围环境交互。

屏幕右侧可点击的标签页能方便地打开物品栏、法术或常用命令面板。

根据屏幕分辨率，可能同时显示一个或多个面板。点击标签图标，可以暂时把物品栏面板
切换为其他图形面板。

修改 settings 目录中 init.txt 的 tile_layout_priority 选项，可以调整控制面板
的优先顺序。


移动
----

可用方向键、vi 按键或数字小键盘移动。小键盘可尝试开启或关闭 Numlock。

小键盘：  7 8 9     vi 按键： y k u
           \|/                \|/
          4-.-6              h-.-l
           /|\                /|\
          1 2 3              b j n

按住 Shift 再按方向键，可以向同一方向连续行走。

也可以用鼠标点击地图或小地图上的位置。如果该位置可以到达，且视野内没有敌对怪
物，就会自动前往。如果视野内有敌对怪物，则每次只会迈出一步。

按 o 或点击右侧命令面板中的自动探索图标，即可自动探索。与点击地图旅行一样，
视野内有敌对怪物时不能使用。


获取信息
--------

右键点击主地图或控制面板上的地形设施、怪物或物品，会打开其说明界面。

将鼠标移到相应位置，通常也会在消息区显示相同说明，或显示消息区容得下的部分。

将鼠标在地形设施、怪物或物品上停留片刻，通常会出现列出适用命令的提示框。


攻击怪物
--------

使用方向键朝怪物移动，或用鼠标点击怪物，即可进行近战攻击。

进行远程攻击（包括法术和魔杖）时，可把鼠标移到怪物上并等待提示框出现。也可以
点击法术面板的法术图标施法，或点击物品栏面板中的投掷物、魔杖进行发射或发动。

命令面板中还有名为 Autofight（自动战斗）的图标。点击它会近战攻击相邻怪物；若
没有相邻怪物，则向最近的怪物迈出一步。


使用物品
--------

最方便的方法是在物品栏面板中点击物品。悬停提示会说明点击的效果，以及执行相同动
作的键盘命令。

也可以按 i 打开物品栏，选择物品，再按操作提示中相应的按键。

拾取地上物品时，可以在物品栏面板的地面区域逐个点击，也可以点击角色图标，打开物
品选择菜单。后者按 Enter 确认选择并开始拾取。

丢弃物品的方式类似：在物品栏面板中点击单件物品，或按 d 后在菜单中选择物品。


与地下城交互
----------

将鼠标移到主地图上的楼梯、门等地形设施，同样会显示如何与其交互。


角色状态
--------

右键点击角色图标，可以打开角色概览，查看装备、抗性和属性数值。

点击命令面板中的相应图标，可以查看角色各方面的详细信息。


角色外观
--------

按 - 打开角色外观编辑器。按 m 切换模式：Equip（装备）会根据穿戴物品动态更新
外观；Default（默认）使用由种族和背景决定的图像；Custom（自定义）允许逐个调
整外观部件。

用数字键切换自定义外观槽位，用方向键修改各个部件。按 Ctrl-S 保存修改和当前选
择。


若游戏明显变慢或卡顿……
--------------------------

Crawl 使用 OpenGL 和 SDL 绘图，需要硬件加速才能流畅运行。Windows 用户应更新
显卡驱动；Linux 用户应确认正在使用 DRI。

游戏曾在 i865 等较老显卡上成功运行；但已知 i810 的运行速度较慢。这种情况下，
通常只能改用字符版或换一台机器。

可尝试调整 settings 目录中的 init.txt，观察下列选项能否改善性能：

travel_delay = -1
    旅行结束或中断之前不重绘画面。

tile_update_rate = 1000
    默认至少每 1000 毫秒重绘一次；执行改变画面的动作时会更频繁。
    可以尝试增大此值，但可能导致画面更新不够及时。

tile_runrest_rate = 17
    连续行走或休息时，每 17 毫秒重绘一次。
    若行走或休息时卡顿，可增大此值。

tile_tooltip_ms = 0
    关闭悬停提示，减少每次需要绘制的内容。

clear_map = false
    不重绘视野外记忆中的怪物，可减少重绘负担。

tile_window_width   = 1024
tile_window_height  = 768
    地图区域越大，每回合需要重绘的格子越多。
    若大屏显示的地图远大于所需的 17x17 格，可以尝试降低分辨率。
